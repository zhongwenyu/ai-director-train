# 《九百六退房费》全剧故事引擎与分集大纲

## 一、项目定位

- **题材赛道**：现代都市情感 / 托举者抽梯 / 专业反套路与商业切割（赛道 A + B 融合）
- **集数与体量**：共 52 集，单集 1.5～2.5 分钟
- **核心一句话钩子**：姐姐花两百五十万全款买房装修成网红民宿免费给失业弟弟一家经营，国庆回家睡两晚储物间竟被弟媳按计算器收九百六房费、父母帮腔逼付，姐姐当场扫码结清拿到收据，转身全款折价卖掉民宿，将算计变成一纸退不回的买卖合同。
- **主要情绪承诺与尺度**：
  - **情绪承诺**：被习以为常吞没的巨大托举终于用真金白银算清账目；别人试图用亲情道德绑架、用蝇头小利羞辱她，她却按对方定下的“亲兄弟明算账”规则把整张桌子合法收走，拿回人生与事业的全部选择权。
  - **尺度边界**：全程依托真实产权、商事合同、税务与平台规则博弈，不搞法外暴力、不安排无脑下跪求饶，也不让主角为等报应故意放任民宿发生安全事故伤害住客。主角有疲惫、有对旧情的最后体面，但每一次切割都不可逆。
- **为何能支撑 52 集篇幅**：
  “卖掉民宿”只是第一阶段对房产产权的直接处分，而非全剧终点。围绕两百五十万民宿的剥离，天然生长出四层递进且不可逆的现实事件链：
  1. **产权与经营权剥离（1～12集）**：从“收960元房费”触发产权核验、折价全款卖房给本地连锁酒店老板，到解决“买卖不破租赁”的占有抗辩、平台收款账户解绑与客诉危机。
  2. **家庭寄生托举全面断供与债务显影（13～26集）**：民宿断奶后，弟弟一家的车贷、私立学费及弟媳私签的旅行社包房违约金全面爆雷；父母试图用老宅拆迁份额、赡养舆论及至主角公司的客户关系逼姐兜底，迫使主角完成家族资产与个人信用的彻底隔离。
  3. **品牌剽窃与商业反击（27～40集）**：弟媳联合被主角辞退的前助理，盗用主角当年为民宿原创的空间设计图与“栖云”主理人故事，拉拢本地文旅投资人另起炉灶并反咬主角“抢夺弟弟心血”，争点从家庭房产转向知识产权、商业声誉与文旅项目竞标。
  4. **旧案真相与人生新局（41～52集）**：追查早年父母宣称“为供姐姐读大学卖掉老铺、姐姐亏欠弟弟”的道德枷锁真相，揭开当年老铺实为替弟弟赌债/创业烂账抵债的旧账，彻底瓦解父母最后的道德筹码；弟弟一家为各自利益内讧解体，姐姐完成个人建筑空间工作室的独立品牌落地。

## 二、戏剧引擎

### 1. 初始困境与核心矛盾
女主沈知意（32岁，独立商业空间设计师）三年前见弟弟沈耀宗失业抑郁、父母终日以泪洗面，拿出自己打拼八年的积蓄 180 万全款在老家古镇核心区买下一栋带院落的小楼，又投 70 万亲自设计装修成“栖云小筑”精品民宿，连同自己跑通的 OTA 平台账号、客源渠道一并免费交给弟弟沈耀宗与弟媳周莉莉经营，未收一分租金，连房产证都放在父母老宅保险柜里让父母安心。
三年后民宿年入逾四十万，弟弟一家换了新车、将儿子送进贵族幼儿园，全家人却在自我洗脑中把民宿当成了沈耀宗“靠本事盘活的产业”。国庆黄金周沈知意回乡探亲兼测绘邻近古建项目，因满房被安排睡一楼潮湿杂物间改造的临时铺位，住了两晚临走时，弟媳周莉莉竟当众按响计算器，按国庆挂牌价打八折向她索要 **960 元房费**，父母不仅不阻拦，反而帮腔说“莉莉管账不容易，你做姐姐的不差这点钱，别坏了店里规矩”。

### 2. 主角优势、限制与代价
- **主角优势**：
  1. **绝对物权**：涉案房产（古镇南街18号）系沈知意婚前个人全款购买，不动产权证单独所有，购房款与70万装修款均有她个人银行卡对公转账、设计图纸底稿及施工合同留痕。
  2. **专业与行业资源**：深耕精品商业空间与民宿改造十年，手握本地实力雄厚的连锁文旅收购方（郑总，曾多次求购南街18号未果），熟悉民宿特种行业许可、消防审验与 OTA 平台店铺主体变更规则。
  3. **性格底色**：一旦看清交易本质便彻底放弃情绪争辩，顺着对方的“明算账”逻辑把账算到底。
- **限制与真实代价**：
  1. **折价损失**：为在国庆期间迅速锁定确定性买方、不给家里留出闹事搅黄交易的周期，沈知意以 **215 万全款一次性付清、买方自行承担后续清场配合成本** 的条件折价出售给隔壁急于扩店的连锁民宿老板郑重，直接账面折损 35 万。
  2. **客户与声誉牵连**：民宿部分长期协议客源与本地文旅局示范点申报曾挂靠沈知意个人设计师口碑，仓促易主与家庭撕破脸让她在本地文旅改造竞标中一度面临“家庭纠纷影响项目履约”的质疑，需付双倍履约保证金自证。
  3. **住客保护底线**：国庆期间民宿仍有在店住客与已付款预订客，沈知意不能采取断水断电锁门等伤及无辜住客的手段，必须在妥善安置住客、赔付差价的前提下剥离弟弟一家的控制权。

### 3. 双方控制资源对比
- **沈知意控制**：南街18号单独所有权；原始购房装修发票与转账流水；“栖云”空间设计全套 CAD 源文件与美术作品登记底稿；早期为民宿垫付水电物业及父母医疗商业险的代扣账户；隔壁收购方郑重的即时全款资金。
- **弟弟一家与父母控制**：
  - 民宿现场实际占有与门锁密码；
  - 以沈耀宗为经营者注册的个体工商户营业执照、特种行业许可证及绑定周莉莉个人卡的 OTA 收款子账号；
  - 锁在父母老宅柜子里的房产证原件（误以为扣住红本就能阻止卖房）；
  - 宗族亲戚舆论、“当年供你读书全家砸锅卖铁”的历史叙事，以及沈知意工作室一名正在做本地文旅对接的老乡助理。

### 4. 核心专业机关与因果核验
- **机关一：960元房费收据破除“借用/赠与/合伙”混同抗辩**
  - **归属与触发条件**：沈知意没有拒付吵架，而是当场微信转账960元，并要求周莉莉开具盖有民宿个体户发票章/收款章的《住宿费收据》（载明房号、入住人沈知意、两晚房费960元）。
  - **证据作用**：该收据直接固定了沈知意作为“普通付费住客”而非“合伙经营人”的身份，同时结合此前三年零分红流水，彻底堵死周莉莉事后改口称“250万是姐弟合伙投资款，不能单方撤资卖房”的口径；无书面租约、无租金支付记录，双方仅构成**不定期无偿借用关系**，所有权人可随时通知终止借用并要求返还房屋。
- **机关二：无房产证原件情况下的补证与全款过户路径**
  - **对手最强反驳**：父母死死锁住老宅里的房产证原件，周莉莉笃定“没房本神仙也卖不了房”，甚至连夜补签一份沈耀宗左手倒右手的“十年低价长租合同”企图用“买卖不破租赁”卡死新买主。
  - **执行路径与专业核验**：
    1. **挂失补证**：不动产权人本人持身份证到不动产登记中心，可依法申请原产权证遗失作废公告并补发新证/电子不动产权证（*注：各地不动产遗失补证公告期与即时办理细则存在地方差异，实拍台词中涉及具体工作日与线上电子证照互认流程【待核】*）。
    2. **击穿倒签假租约**：针对周莉莉与表弟临时倒签的“十年租约”，新买主郑重与沈知意并非靠嘴硬宣称无效，而是调取：① 合同所用纸张批次/打印墨迹时间与无租金银行流水事实；② 民宿特种行业许可备案及近三年社区网格登记中从未有该“承租人”记录；③《民法典》第705条及相关司法解释：租赁物在承租人按照租赁合同占有期限内发生所有权变动的，才适用买卖不破租赁——倒签合同无实际占有与租金流水支撑，且恶意串通损害所有权人利益，面临虚假诉讼风险。郑重作为本地酒店老手，拿着虚假诉讼报案材料与正规清退函进场，迫使对方撤回假租约。
- **机关三：OTA 平台房源下架与品牌空间著作权切割**
  - **归属与执行**：个体工商户营业执照虽在沈耀宗名下，但平台房源认证必须提供合法场地使用证明（产权证+产权人授权书）。沈知意与新产权人郑重向各 OTA 平台提交《产权变更证明》及《撤销场地授权声明》，平台依规冻结原店铺新增房晚预订功能，仅保留存量订单履约结算，直接切断周莉莉继续用该房源预售圈钱的路径（*平台具体审核冻结时效按主流OTA规则约1～3个工作日【待核】*）。

### 5. 动态信息差与接棒问题
- **第1～4集信息差**：周莉莉与父母以为沈知意爱面子、重亲情，收她960元是立威试探（服软了以后连民宿产权都能慢慢过户给侄子）；观众与沈知意清楚她已在扫码付款那一刻启动资产评估与买家洽谈。
- **第5～8集信息差**：父母藏起房产证原件，周莉莉以为拿捏住了命脉，还在朋友圈晒国庆营收并张罗用民宿流水再订一辆四十万的商务车；不知沈知意已办妥不动产遗失声明补证，并与隔壁郑重签下215万全款买卖协议完成网签过户。
- **第9～12集身份/产权变更公开后的接棒问题**：当新房东郑重带着过户回执与装修队进场打通两栋院墙时，“会不会卖房”的悬念彻底终结，无缝接棒下一个核心危机——**周莉莉此前私自收了外地旅行社15万包房定金（签了两倍违约赔偿条款），且全家的车贷、信用卡和父母养老商业险全靠姐姐托底，没了民宿现金奶牛与姐姐兜底，这笔即将爆雷的连环债谁来背？**

## 三、核心人物

### 1. 沈知意（32岁，女主｜独立商业空间设计师，“知意营造”工作室创始人）
- **身份前史**：小城做题家出身，大学读环境艺术设计，毕业后在沪杭熬夜画图、驻扎工地八年才攒下第一桶金与行业口碑。总被父母灌输“当年家里卖了老卤味铺才供出你一个大学生，弟弟没读好书都是替你牺牲”的亏欠感，因此三年来对家里有求必应。
- **欲望与软肋**：渴望拥有一间真正属于自己审美理想、不受甲方和家庭拖累的独立建筑改造事务所；早期软肋是对“一家人整整齐齐”的执念，以及对母亲高血压病史的心软。
- **控制资源**：南街18号绝对产权、215万售房回笼现金、空间设计版权、本地文旅局专家库入库资格。
- **自我辩护与成长弧光**：过去她以为“给钱给产业就能换来家人的尊重与安宁”，960元房费敲醒她——无底线的免费托举只会把亲人喂成仇人。她的成长不是变成冷血复仇机器，而是学会把每一份善意明码标价、把不属于自己的因果如数奉还。
- **怕被谁看见**：不怕亲戚骂她绝情，最怕自己工作室那群跟着她干的年轻设计师因为她的家事烂摊子丢掉辛苦竞标的项目。
- **说话策略**：语速平稳，从不骂街或翻抽象旧情，专挑对方话里的数字、票据、日期往死里核对，对方越撒泼她越像在审工程预算表。
- **情境化代表台词**（第1集，看着周莉莉手里的计算器，平静打开付款码）：“八折九百六是吧？行，我扫给你。麻烦把收据开一下，抬头写我本名，备注南街18号一楼杂物间两晚——毕竟亲姐弟明算账，少一张票，以后这栋楼的账不好平。”

### 2. 周莉莉（28岁，反派核心｜弟媳，前微商团队长，现自封“栖云民宿主理人”）
- **身份前史**：做微商起家，精于朋友圈人设包装与小账算计。嫁给沈耀宗时男方正失业，见大姑姐全款拿出装修好的民宿给他们经营，迅速接管财务大权。
- **欲望与软肋**：极度渴望跻身本地“名媛创业女老板”圈层，想把民宿彻底变成自己夫妻名下的婚内财产，再开分店割加盟商韭菜；软肋是虚荣心极强、法律常识半瓶水晃荡，且私下挪用民宿预收款给娘家弟弟填了网贷窟窿。
- **控制资源**：民宿收银账户、OTA后台密码、沈耀宗的言听计从、旅行社私单渠道、社交媒体短视频账号。
- **自我辩护**：“房子空着也是空着，要不是我起早贪黑拍小红书、盯保洁，她那破院子能一年赚四十万？收她九百六怎么了？她在上海赚大钱，占自家人便宜还好意思！”
- **怕被谁看见**：最怕婆家知道她偷偷拿民宿收款补贴娘家20万，更怕本地贵妇圈看穿她只是个借住大姑姐房子的打工二道贩子。
- **说话策略**：茶言茶语夹杂网红创业黑话，占便宜时讲“一家人别计较”，自己出钱时讲“现代企业财务制度”。
- **情境化代表台词**（第1集，手指敲着计算器屏幕笑眯眯对沈知意说）：“姐，不是弟妹小气，国庆咱们店一房难求，你睡那间虽然小，可水电布草保洁哪样不要成本？我给你抹了零还打八折，才收九百六，你在大城市当总监的人，不会连这点店规都不懂吧？”

### 3. 沈耀宗（29岁，弟弟｜名义民宿老板，巨婴投机者）
- **身份前史**：大专肄业后换过七八份工作，三年前创业搞剧本杀赔光父母养老钱后在家躺平，靠姐姐全款建好的民宿翻身，出门逢人便吹自己“极具文旅商业嗅觉”。
- **欲望与软肋**：想不劳而获维持“沈老板”的体面生活（豪车、牌局、朋友吹捧）；软肋是毫无独立抗风险能力，既怕老婆闹离婚分钱，又在真出大事时本能指望姐姐擦屁股。
- **控制资源**：民宿个体工商户法人身份、父母无条件的偏心护短。
- **自我辩护**：“我姐一个大龄单身女青年，钱赚再多以后还不是留给我儿子的？我帮她守着老家产业，收点成本费磨磨她那高高在上的脾气怎么了？”
- **怕被谁看见**：最怕酒肉朋友和车友会老板们知道他连民宿房产证名字都不是自己的，车都是首付贷款买的。
- **说话策略**：顺风时摆老板谱和事佬腔调，逆风时立刻装委屈、砸东西逼父母出头向姐姐施压。
- **情境化代表台词**（第6集，得知民宿真在办交接时涨红了脸吼）：“沈知意你疯了吧！为了九百六十块钱你卖我的店？！这三年老子在店里端茶倒水的时候你在哪儿？传出去别人只会戳你脊梁骨说你容不下亲弟弟！”

### 4. 刘桂芳 & 沈建国（58岁 / 60岁，母亲与父亲｜偏心大家长与旧账隐瞒者）
- **身份前史**：退休小市民，重男轻女观念根深蒂固，却极擅长用“为你好”“一碗水端平”包装剥削。早年经营老街卤味铺，十年前突然卖铺，对外对女儿宣称是“凑知意读大学和去上海租房的钱”。
- **欲望与软肋**：核心目标是确保儿子沈耀宗后半生衣食无忧、孙子延续香火；软肋是极看重宗族邻里体面、害怕晚年养老无人管，更怕十年前卖掉老卤味铺的真实账目败露。

### 第 2 集：谁才是房东
- **建议时长**：2分00秒
- **核心场景与人物**：隔壁“枕水居”二楼露台茶室（俯瞰南街18号院落）、父母老宅客厅；沈知意、郑重、刘桂芳、沈建国、周莉莉。

  - *进入状态*：周莉莉企图金蝉脱壳把30万旅行社债务全甩给沈耀宗一人背负，自己靠赵乾的新店洗白上岸；另一边部分买了周莉莉99元房券的网友跑到沈知意工作室账号下刷恶评。

- **集尾未决问题与承接**：被老婆甩脸、又收到法院拍卖爱车通知的沈耀宗彻底红了眼，趁夜翻进父母卧室撬开那个装过废房产证的铁皮柜，竟偷走了父母藏在夹层里的老街祖宅房产证原件，直奔地下小贷公司！第15集承接家族借贷连环崩盘与山寨工地危机。

### 第 15 集：铁柜夹层里的老铺旧账
- **建议时长**：2分15秒
- **核心场景与人物**：地下车抵/房抵中介行、古镇二期样板工地、父母老宅；沈耀宗、刘桂芳、沈建国、沈知意、陈老四。
- **开场画面与观众问题**：老宅内铁皮柜锁头被砸烂在地上，刘桂芳看着空空如也的柜底瘫软嚎哭，沈建国却脸色铁青扑过去翻看夹层最底下的一张泛黄收条还在不在——镜头扫过那张十年前的纸角，上面隐约写着“兹收到陈老四老铺抵债款叁拾捌万元，用于结清沈耀宗……”！——**父母比丢了老宅房本还恐惧的那张十年前收条，究竟藏着什么惊天谎言？**
- **目标与主要交锋**：
  - *进入状态*：沈耀宗拿着父母老宅房本准备做民间抵押赎回自己的豪车并报复周莉莉；周莉莉与林小曼为省成本向赵乾交差，在对街茶楼强行按偷来的“废稿”拆改二楼承重木梁。
  - *交锋过程*：刘桂芳和沈建国找不到儿子，竟又厚着脸皮跑到二期工地找沈知意：“你弟把老宅房本偷去借高利贷了！那老宅以后拆迁有一百多万呢，你快拿三十万去把你弟拦下来，不然爸妈老了没地方住就搬去你工作室睡！”沈知意戴着安全帽正在核对木构榫卯，头也不抬递过手机：“高利贷归警察管，偷拿父母房本没有产权人本人到场签字办不了正规抵押；至于你们老了住哪儿——我每月打进社保卡的基础赡养费够租单间，想进我工作室大门，门禁认识你们是谁吗？”恰好路过来送老木料样品的街坊表叔陈老四听不下去，当场冷哼一声：“老沈嫂子，你们还有脸找知意要钱？十年前你们把老卤味铺卖给我救急的时候，嘴上哄丫头说是供她读大学，那三十八万当天晚上送到哪个地下赌场赎人，真当老街没人记得？”
  - *退出状态*：沈建国慌忙冲上去捂陈老四的嘴，拉着刘桂芳仓皇逃离工地；沈知意站在原地怔住，十年来压在她心头最重的那块“卖铺供读亏欠全家人”的巨石，第一次裂开了一道刺眼的缝隙！
- **爽点/情感收获及阻力代价**：正面硬刚父母“赖住工作室”的无赖威胁，同时由见证人陈老四正式撕开第四卷终极真相的一角，将全剧长线悬念推向深水区。
- **集尾未决问题与承接**：沈知意看着父母落荒而逃的背影，吩咐法务调取自己当年大学助学贷款档案与老街十年前的铺面转让底档；而街道对面传来沉闷的木梁开裂声——林小曼与周莉莉按偷来的废稿锯断茶楼副梁后二楼地板明显下沉，恰好遇上古镇住建与消防联合巡查组推门而入！第16集起无缝衔接对街违规施工被依法查封、周莉莉与赵乾反目互撕及旧案追查的后续全卷主线。
