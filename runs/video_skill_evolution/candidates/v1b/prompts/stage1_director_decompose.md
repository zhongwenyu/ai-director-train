# Stage 1：戏剧段落分镜拆解与蒙太奇节奏规划指南

将输入的戏剧段落拆分为 `2` 到 `5` 个连续子镜头（`clips`），以精准的时长配平、正反打景别阶梯与反应声桥构建电影级剪辑节奏：

## 1. 时长动态配平与防截断留白
- **整数镜长严配总时长**：每个子镜头 `duration_s` 必须为整数秒（`2` 到 `8` 秒），所有子镜头 `duration_s` 之和严格对齐 `target_duration_s`（四舍五入至最近整数秒）。
- **紧凑语速与尾句保护**：按自然戏剧语速（每秒约 `3.5`–`4.2` 个中文字，含标点换气气口）估算台词时长，计入 `0.2s` 起音前导与至少 `0.4s` 镜尾收束余量；**严禁单镜时长注水导致人物前摇发呆，更严禁末镜时长卡死导致尾句音画被提前生硬截断**。
- **紧凑快切破拖沓**：常规对白与反应单镜优先控制在 `2s`–`4s` 紧凑区间，避免将多句转折长台词塞入单一冗长中远景镜头。

## 2. 防跳切正反打语法与无声反应声桥
- **严禁同人同轴跳切（No Jump Cuts）**：禁止相邻两个子镜头连续拍摄同一角色且景别或机位近似。若同一角色连续发表长句或经历潜台词转折，必须在转折气口处**穿插 `2s` 左右的无声倾听方反应近景/特写镜**，或采用跨越 `30°` 以上机位变化配合显著景别阶梯跳跃（如双人过肩中景切单人特写）。
- **主动织入无声反应镜（Silent Reaction Cut）**：在关键信息抛出、情绪刺痛或悬念转折处，主动规划无台词倾听反应子镜头（`visible_role_ids` 含倾听反应者，`speaking_role_ids` 设为 `[]`），捕捉倾听方即时眼神与微表情变化，打破“谁说话只拍谁”的机械切镜。
- **L-Cut 声画叠化声桥（`lcut_audio_hold_over_next_s`）**：当说话子镜头的下一个镜头为无台词倾听反应镜（或需话音尾韵延入下一镜触发对方神态转折）时，将当前说话镜的 `lcut_audio_hold_over_next_s` 设为 `0.3`–`0.8`，让画外尾音自然覆叠于反应画面起幅之上；其余常规切镜默认填 `0.0`。

## 3. 景别阶梯递进与运镜指标管制
- **过肩前景锚定与高潮收紧**：关系建置与对话交锋优先使用带前景搭档肩廓锚点的过肩镜（`Over-the-shoulder, OTS`）或双人中近景确立空间轴线；随戏剧张力递进逐步收紧至中近景（`MCU`）与特写（`CU`）。**段落情绪最高潮与收束点睛句必须落于紧凑的 `MCU` 或 `CU`，严禁在情绪顶点退回松散全景**。
- **固定机位主导与单次动机运镜**：常规正反打与反应切镜一律规划为三脚架固定机位（`Locked-off static camera`），严禁多镜连续推拉；**全段最多仅允许 `1` 个子镜头触发动机化运镜**——仅限角色发生跨空间走动位移时采用跟摇（`Tracking / Pan`），或在全段唯一核心悬念揭示/情绪爆发极点的关键镜头上执行单次平稳光学推近（`Measured optical push-in`）。

## 4. 角色出镜与心声隔离标注规范
- 准确标注每个子镜头画面实际出镜可见的角色 ID（`visible_role_ids`；过肩镜含前景搭档轮廓时一并列入，干净单人近景特写仅列画内单人）与画内开口说话的角色 ID（`speaking_role_ids`；纯反应镜填 `[]`）。
- 若某句属于内心独白或画外音（`mode == "inner_os"`），优先独立成镜，**严禁将该角色放入 `speaking_role_ids`**，须填入该镜头的 `inner_os: {"speaker_id": "...", "text": "...", "start_s": 0.2, "mode": "inner_os"}`，画面聚焦角色闭唇思绪流转或聆听反应。
