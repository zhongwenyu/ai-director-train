# Stage 1：戏剧段落短原子分镜与声画时序规划指南

将输入的 `8.5s–12.5s` 戏剧段落拆解为 `3` 到 `6` 个紧凑连续的原子子镜头（`clips`），彻底消除冗长单镜、切镜吞字与同向跳切：

## 1. 长台词短原子拆切与总时长零超标铁律
- **严禁单镜堆砌多句台词**：凡遇到多句交锋、单句超过 `14` 个汉字，或句内含明显语义转折、停顿追问与情绪递进时，必须按语义气口切分为多个紧凑单动作子镜，或在分句间穿插听者反应镜，严禁一镜到底硬念长段台词。
- **子镜头时长（`duration_s`）规范**：取紧凑整数秒，常规单动作/单气口对白子镜控制在 `2`–`4` 秒，无台词反应插切子镜锁定 `2` 秒（对应 `1.5–2.5s` 短促反应节拍）；仅当单句语义不可强拆且字数密集时上限可设 `5` 秒，严禁出现 `6` 秒及以上拖沓镜头。
- **总时长严贴 `target_duration_s`**：所有子镜头 `duration_s` 之和必须紧贴 `target_duration_s`（偏差不超过 `0.5` 秒；遇半秒目标值时优先向下取整或微调子镜排布，宁紧勿超，严禁总时长超标注水）。
- **音节容量防吞字核算**：按中文自然戏剧语速（约每秒 `3.8`–`4.2` 字，另留 `0.2s` 起口与 `0.4s` 句尾收唇余量）精确匹配字数与镜长：
  - `2` 秒镜：限 `1`–`6` 字短促反问、惊叹或核心短句；
  - `3` 秒镜：适配 `7`–`11` 字紧凑分句；
  - `4` 秒镜：适配 `12`–`15` 字完整分句（超长即拆镜）。严禁将过多字数硬塞入短镜导致切镜腰斩吞字，亦严禁给极短台词分配长镜造成片尾发呆空耗。

## 2. 关键情绪落点无台词反应插切与 L-Cut 声画缝合优先
- **强制插入听者/旁观者无台词反应镜**：每段戏必须在戏剧转折点、交锋刺痛处、悬念抛出或高张力句尾，切入至少 `1` 个（密集交锋段可设 `2` 个）时长 `2` 秒的对手或关键在场旁观者**无台词神态反应镜头**（`speaking_role_ids` 置空 `[]`，专拍眼神震动、呼吸顿挫或微姿态绷紧/退缩）。
- **`lcut_audio_hold_over_next_s` 优先与归零准则**：
  - **优先开启**：当且仅当**当前子镜有画内开口对白**（`speaking_role_ids` 非空），且**紧邻下一镜为纯无声反应镜头**（下一镜 `speaking_role_ids` 为空且无 `inner_os` 语音占用）时，优先设为 `0.4`–`0.8`（`2` 秒说话镜宜设 `0.4`，`3`–`4` 秒说话镜宜设 `0.5`–`0.8`）。当前说话镜自身 `duration_s` 仍须足额容纳整句发音，确保**核心重音词唇形完整留在说话人画内**，仅让句尾余音自然覆盖下一镜听者的第一瞬反应画面，严禁过早切走核心重音词。
  - **严格归零**：若下一镜含画内对白或 `inner_os`、当前镜无画内对白，或当前镜为末尾最后一镜，`lcut_audio_hold_over_next_s` 必须填 `0.0`。

## 3. 角色出镜、画内开口与 `inner_os` 零口型通道
- **出镜与开口角色精确分离**：`visible_role_ids` 仅填本镜画面实际可见的角色 ID（过肩镜须同时列入前景肩背角色与主拍角色；单人近景/特写仅列该角色）；`speaking_role_ids` 仅填本镜画内实际张口说台词的角色 ID。
- **心声与画外音独立通道**：凡 `mode == "inner_os"` 的内心独白或画外音，**严禁放入 `speaking_role_ids`**（画内无人开口则 `speaking_role_ids: []`），必须填入该镜 `inner_os: {"speaker_id": "...", "text": "...", "start_s": 0.2, "mode": "inner_os"}`，并保证该镜 `duration_s` 足以播完独白全文（每秒约 `4` 字加 `0.5s` 余量）不截断尾字。

## 4. 蒙太奇防跳切、景别向高潮收紧与动作因果规划
- **禁绝同向跳切**：相邻两镜严禁对同一角色维持相近景别与相近机位直接硬切；切镜须切换主拍人物（正反打/反应切镜），或同步拉开景别级差与至少 `30°` 机位角变化（全程严守同一 180° 轴线侧）。
- **景别递进收紧铁律**：全段以过肩镜（`Over-the-shoulder`）、中近景（`Medium close-up`）、近景特写（`Close-up`）为主导常态；仅首镜确需交代多人肢体关系时可用一次中景（`Medium shot`），随情绪升温至高潮或收尾重锤，景别必须逐级收紧至中近景或特写，**严禁在情绪高潮或反应落点退回中远景**。
- **跨镜物理因果延续**：规划分镜时同步追踪关键道具与肢体接触状态；前镜一旦发生触碰、递接、取放或位移，后续子镜必须沿袭改变后的最新空间与持握状态，严禁跨镜复原或动作断层。
