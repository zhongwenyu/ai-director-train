# 通用短剧视频生成技能 (`hit-video`)

面向现代、年代、古装、悬疑等全题材戏剧段落，依据输入任务卡（环境设定、在场站位关系 `initial_blocking`、角色外观设定、关键器物、对白与 `subtext_intent` / `inner_os` 序列），先确立锁死全场拓扑与视线轴线的空间母版（`master_blocking_prompt`），再拆解为节奏凝练的子镜头序列（`clips`），依次编译静态起幅首帧（`keyframe_prompt`）与潜台词驱动的动态表演及对白提示词（`detailed_action_and_dialogue`），合成声画严丝合缝的高张力戏剧片段。

## 四大跨题材底层核心铁律
1. **母版锁轴与贴视线浅景深近景主导**：通过 `master_blocking_prompt` 锁死全场相对落座/站位拓扑、背景分区与唯一 `180°` 视线轴线。说话与核心反应镜头摒弃平庸远景与纯正侧脸平铺，优先采用贴近镜头光轴（`10°–20°` 微偏角）的大光圈浅景深中近景（`Medium close-up`）与特写（`Close-up`），完整呈现双眼眼神光与五官细节；戏剧高潮景别只进不退。
2. **紧凑声画节拍与零吞字零尾噪**：单镜短促凝练（以 `2s–3s` 为常态），总时长紧贴 `target_duration_s` 绝不超标拖沓；按语速精准预留 `0.20s` 立即起音与句尾 `0.30s–0.45s` 收唇定格缓冲，穿插听者无声反应切镜与适度 `L-cut` 延音，根除切镜腰斩吞字与片尾废口型杂音。
3. **舒展起幅与潜台词双拍微表情弧光**：静态 `keyframe_prompt` 保持五官自然舒展零夸张，柔光护骨相且暗部唇形清晰；动态 `detailed_action_and_dialogue` 严循每句 `subtext_intent` 真实情绪极性（喜感、悲恸、冷峻压迫、慌乱或隐忍等），驱动眉眼口周完成“初态发声—受激/转折递进—平稳收势”的鲜活弧光，兼具真实气息潜台词层次。
4. **物理因果闭环与真实手部支点**：建立跨镜器物与姿态连续账本，肢体触碰施力必引发目标可见位移或形变且后续镜头严禁凭空复原；双手全程依托案几桌面、扶手、衣袖或随身器物等自然支点，消除木讷悬停与切镜瞬移。

## 三阶段协同工作流
1. **分镜节奏与声画时序规划**：遵循 `prompts/stage1_director_decompose.md`，确定子镜头切分、整数秒时长（总和紧贴 `target_duration_s`）、景别递进、听者反应切镜、`L-cut` 衔接及出镜/发声角色分流。
2. **空间站位母版与浅景深首帧编译**：遵循 `prompts/stage2_keyframe_prompting.md`，先编写锁定全员相对方位与 `180°` 轴线的 `master_blocking_prompt`，再为各子镜头编写贴视线浅景深、柔光护骨相且状态连续的静态 `keyframe_prompt`。
3. **潜台词微表演与精准声画编译**：遵循 `prompts/stage3_motion_acting_prompting.md`，编写贴合 `subtext_intent` 的眉眼微表情递进、物理因果手部动作、`<d>[Chinese] 台词</d>` 精准口型同步（心声通过 `inner_os` 独立分离且画面闭唇）与纯净 `soundscape`。

## 全局一致性门禁
- **占位符隔离**：Stage 2 仅用 `[Scene]` 与 `[CHR_1]`、`[CHR_2]`；Stage 3 仅用 `<CHR_1>`、`<CHR_2>`，严禁混用或泄露具体角色名。
- **纯净实拍画面**：全流程零文字、零字幕、零水印，严禁跨越 `180°` 轴线翻转背景，严禁在 `soundscape` 中混入背景音乐或乐器。
