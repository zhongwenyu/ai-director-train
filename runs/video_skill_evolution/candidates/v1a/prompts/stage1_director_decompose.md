# Stage 1：戏剧段落分镜、节奏与机位规划指南

将输入的 `8.5s–12.5s` 戏剧段落拆解为 `3` 到 `5` 个节奏紧凑、快慢错落的连续子镜头（`clips`；仅极简短对白段落可拆为 `2` 镜），构建兼具空间连续性、反应留白与动机运镜的分镜方案：

## 1. 时长测算、戏剧气口与尾句安全垫
- **整数秒与总长紧贴**：每个子镜头 `duration_s` 为整数秒（`2` 到 `8` 秒），常态以 `2s–4s` 敏捷镜头为主导，严禁长镜死守单一中远景拖慢节奏；所有子镜头 `duration_s` 之和必须紧贴 `target_duration_s`。
- **真实语速与防截断余量**：按包含自然戏剧停连与换气气口的真实语速估算每句台词发音时长，杜绝前摇发呆与时长注水；同时每个含画内台词的子镜头必须在台词发声结束后预留 **`0.4s–0.6s` 的尾韵收束安全垫**（全段最后一个收尾镜头须预留至少 `0.5s` 神态收束余量），严防切镜或片尾音画提前截断导致尾字丢失。

## 2. 转折切镜与无声倾听反应镜布局
- **关键转折必有反应切镜**：严禁全程仅跟随说话人切镜。在潜台词反转、言语试探、秘密揭晓或情绪暗涌的核心转折点，必须主动规划至少一个 **`2s`（或 `3s`）无台词倾听方反应短镜**（优先采用 `Close-up` 特写或带虚化过肩前景的 `Over-the-shoulder MCU`），精准捕捉听者眼神骤凝、呼吸微滞或克制隐忍的即时心理反应。
- **长台词拆解切分**：遇较长独白或重头交锋台词时，拆分为“起势发声镜 → 听者无声反应短镜（叠入前镜 L-cut 尾音） → 说话人重音收束近景/特写”，打破平铺直叙。

## 3. 景别递进、30° 防跳切与动机运镜规划
- **过肩前景锚定与景别呼吸**：正反打中合理穿插带浅景深前景肩颈轮廓的过肩镜头（`OTS MCU` / `OTS MS`）以稳固双人空间拓扑，在情绪重音与心理转折处果断推进至单人近景（`MCU`）或特写（`CU`）。
- **30° 机位跃迁铁律**：相邻镜头切向同一主体或相近轴向时，必须同步改变机位水平角度（大于 30°）并跨越至少一级景别，严禁同轴微幅生硬跳切或无故丢失过肩前景关系。
- **动静结合的动机运镜分配**：常规快速问答对切以三脚架固定机位（`Locked-off static camera`）为稳固基底；但**每个戏剧段落必须围绕潜台词揭示、关键无声反应短镜、`inner_os` 心声或情绪凝结点，明确安排 `1`–`2` 个带清晰戏剧动机的运镜子镜头**——优先配置朝向角色眼神的克制慢推（`Controlled slow push-in`），或根据空间张力与人物动作选用过肩微横移视差（`Subtle lateral parallax`）、随身体转向/位移的平滑跟摇（`Motivated pan / tracking`），消除全片静态锁死的呆板感。

## 4. 角色标注、心声分离与声画叠化（L-cut）规范
- **`visible_role_ids`**：完整列出该子镜头画内可见的所有角色 ID（过肩镜中以虚化肩颈背影出镜的前景角色亦须列入，确保空间轴线与站位连续）。
- **`speaking_role_ids`**：仅填入该子镜头画内实际张口发声的角色 ID；纯倾听反应镜与纯心声镜均填 `[]`。
- **`inner_os`（心声与画外音分离）**：若台词满足 `mode == "inner_os"`，**严禁放入 `speaking_role_ids`**，须填入该镜头的 `inner_os: {"speaker_id": "...", "text": "...", "start_s": 0.2, "mode": "inner_os"}`，画面聚焦该角色双唇闭合下的眼神变化与潜台词微反应。
- **`lcut_audio_hold_over_next_s`（声画叠化）**：凡下一子镜头为无台词倾听反应镜、`inner_os` 心声镜或情绪余韵镜时，**优先设为 `0.3`–`0.8`**，让当前说话人的尾音自然延入下一镜听者微表情起幅，实现顺滑声画缝合；其余常规对白硬切镜填 `0.0`。
