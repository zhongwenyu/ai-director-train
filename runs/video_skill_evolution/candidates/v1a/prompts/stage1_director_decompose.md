# Stage 1：戏剧段落分镜节奏与声画时序规划指南

将输入的 `8.5s–12.5s` 戏剧段落拆分为 `2` 到 `5` 个连续子镜头（`clips`），构建紧凑、有呼吸感且物理状态严密连续的分镜蓝图：

## 1. 镜数节奏与总时长刚性对齐（杜绝拖沓超标）
- **凝练短镜主导**：针对 `8.5s–12.5s` 段落，优先拆分为 `4` 到 `5` 个紧凑子镜头。每个子镜头 `duration_s` 为整数秒（架构范围 `2`–`8` 秒，实操以 `2`–`3` 秒为常态主导，常规单镜不超过 `4` 秒；仅当单句不可拆分的连续长台词确需完整容纳时方可取 `5` 秒，严禁排布发呆注水长单镜）。
- **总时长零超标**：所有子镜头整数秒 `duration_s` 之和必须紧贴 `target_duration_s`（优先四舍五入对齐最近整数秒，上限严禁超出 `target_duration_s + 0.5s`）。

## 2. 台词声学测算与零吞字拆句法则
- **精准时长核算**：按自然偏紧凑戏剧语速（每秒约 `4.0–4.5` 个汉字，句中停顿标点计 `0.2s–0.3s`）测算净语音时长，必须满足：`duration_s >= 0.20s（起音预留）+ 净语音时长 + 0.35s（句尾收唇缓冲）`，同时镜尾无台词空耗留白不超过 `0.6s`。
- **一镜一主讲与长句拆切**：优先采用“一镜一主讲或一反应”。若单句台词加上首尾缓冲超过 `3.5s–4.0s`，优先在语义转折或分句处拆分为两个景别递进的子镜头，或在句间切入 `2s` 听者反应镜头，严禁将超长台词硬塞进短镜头导致切镜处腰斩吞字。

## 3. 景别张力递进与防跳切调度
- **景别只进不退**：段落开场可用紧凑 `Medium shot` 或 `Over-the-shoulder` 快速确立空间对峙关系，随即推进至贴视线 `Medium close-up` 与 `Close-up` 主导对话交锋；**在潜台词反转、受挫承压或情绪高潮节点，必须推至 `Close-up` 或紧凑 `Medium close-up`，严禁退回中远景削弱面部戏剧张力**。
- **30°防跳切铁律**：若连续两个子镜头拍摄同一角色或同向方位，机位水平角度必须变化至少 `30°` 且景别跨跃至少一档；否则必须切入对向角色正反打或听者反应镜头，杜绝同向同景别生硬跳切。

## 4. 听者无声反应切镜与 L-Cut 延音衔接
- **主动插入反应切镜**：在博弈施压、试探揭穿或互动受挫节点，主动规划 `2s` 的听者无台词反应近景/特写（`speaking_role_ids` 置空），捕捉眼神震动、隐忍或冷峻审视等即时情绪转折，打破单调轮流说话。
- **L-Cut 自然过渡**：`lcut_audio_hold_over_next_s` 默认填 `0.0`；仅当**下一个子镜头既无画内对白也无 `inner_os`**（即纯无声听者反应镜头）时，优先设为 `0.3`–`0.6`（上限 `0.8`），让上一句尾音重音完整延入听者表情画面，兼顾防吞字与剪辑呼吸感。

## 5. 出镜、发声与内心独白（`inner_os`）严格分流
- **角色列表精准匹配景别**：`visible_role_ids` 仅填写该镜头画面内实际可见的角色 ID（单人贴轴 `Medium close-up` / `Close-up` 仅填该单人 ID；双人同框或 `Over-the-shoulder` 填可见双人 ID）；`speaking_role_ids` 仅填写画内张口出声的角色 ID。
- **心声分离规则**：凡 `mode == "inner_os"` 的内心独白或画外音，**严禁放入 `speaking_role_ids`**，必须填入该镜头的 `inner_os: {"speaker_id": "...", "text": "...", "start_s": 0.2, "mode": "inner_os"}`。

## 6. 跨镜物理状态连续账本
- 规划切镜点时同步维护器物与肢体状态账本：上一镜头中发生拿取、放下、推移或姿态改变的器物与手势，下一镜头必须直接承接改变后的结果状态；避免在复杂肢体交互半途生硬切断，杜绝跨镜状态回退或悬空断层。
