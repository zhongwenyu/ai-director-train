# Stage 1：戏剧段落短原子分镜与声画节奏规划指南

将输入的戏剧段落（通常 `target_duration_s` 为 `8.5s–12.5s`，随任务卡自适应）拆解为一组高密度、强因果的连续短原子子镜头（`clips`，常规段落拆分为 `4`–`6` 个子镜头）：

## 1. 长台词短原子拆切与总时长严控
- **拒绝多句堆砌长镜**：严禁将多句台词、多轮交锋或多次情绪转折塞入单一冗长固定镜头。遇到较长台词或密集交锋时，按自然语义气口、标点停顿或潜台词转折点拆切为**单镜头单核心动作**的紧凑子镜（保持原剧本台词字句完整守恒，不漏字、不改词、不跨镜重复）。
- **紧凑整数秒镜长约束**：每个子镜头 `duration_s` 取整数秒，严格控制在 `2`–`4` 秒区间（严禁 `5` 秒及以上拖沓长镜）：
  - **短句交锋镜（约 1–8 字）与无台词反应镜**：优先锁定 `2` 秒短促切入（若底层 Schema 显式采用半秒步进浮点数，无台词反应镜可取 `1.5`–`2.5` 秒；整数秒规范下统一取 `2` 秒）。
  - **中等分句镜（约 9–14 字）**：取 `3` 秒。
  - **不可拆分的紧凑长分句（约 15–20 字）**：上限 `4` 秒；超出时必须在语义气口处拆镜或穿插听话人反应镜分流。
- **总时长紧贴与防截断核算**：按紧凑戏剧语速（中文约每秒 4.5–5.5 字）叠加 `0.20s` 起口与至少 `0.35s–0.50s` 句尾落音余量核算每镜时长，确保画内台词与 `inner_os` 均在镜内完整收尾零吞字。全段所有子镜头 `duration_s` 之和必须紧贴 `target_duration_s`（偏差不超过 `0.5s`，宁紧勿超，彻底砍除片头呆滞与片尾空耗留白）。

## 2. 关键落点无台词反应插切与 L-Cut 声画缝合
- **听话人/旁观者无声反应切镜**：当在场存在对手角色或旁观者时，每逢戏剧转折、锋芒质问、秘密揭露或高张力句尾，必须切入 `2` 秒对手或关键旁观者的**无台词眼神/神态反应镜头**（`speaking_role_ids: []`），直观呈现受激瞬间的瞳孔震动、神色骤变或潜台词肢体反应；若全场仅单人独角戏，则在情绪转折处切入主体自身的无台词特写反应停顿镜。
- **`lcut_audio_hold_over_next_s` 精准启闭规则**：
  - **默认填 `0.0`**：凡下一镜包含画内开口台词、包含 `inner_os` 独白，或当前镜为全段最后一镜时，一律填 `0.0`，防止人声叠压混浊。
  - **反应镜前优先开启（`0.4`–`0.8`）**：**仅当当前镜为画内说话镜且紧邻下一镜为无台词受话人/旁观者反应镜头时**，将当前镜 `lcut_audio_hold_over_next_s` 设为 `0.4`–`0.8`，使说话人句尾情绪余音自然延伸覆盖至下一镜反应画面，实现电影级声画缝合。

## 3. 景别推进、高点锁镜与反跳切机位调度
- **紧凑叙事景别主导**：全段以 `Medium close-up`（中近景）、`Close-up`（近景/特写）及紧凑 `Over-the-shoulder`（过肩近景）作为叙事常态，仅在确立关键全身空间交互时按需使用 `Medium shot`，保障说话口型与眼神交锋清晰可辨。
- **情绪高点严禁退远或早切**：在核心冲突爆发、含泪/震惊/反讽等情绪峰值、无声受激反应及关键心声时刻，必须推至 `Close-up` 或紧凑 `Medium close-up` 稳住情绪落点，严禁在戏剧顶点误配中远景（`Wide` / `Medium-wide`）或话音未落提前切走造成反高潮。
- **守轴正反打与 30° 防跳切**：全场恪守同一 180° 轴线走廊；若相邻两镜连续拍摄同一角色或同一空间侧，必须同步产生显著景别跨越（如 `Medium shot` 切入 `Close-up`）或至少 30° 水平机位角度变化，杜绝同向同景别生硬跳切。

## 4. 角色显隐、心声零口型通道与跨镜状态接力
- **`visible_role_ids` 与 `speaking_role_ids` 精确对齐**：`visible_role_ids` 仅填写本镜画面实际入画角色（单人正打特写仅填该主体 ID；过肩镜 `OTS` 须同时填入前景肩廓参考角色与对向焦点角色 ID）。常规单镜最多安排 `1` 名画内开口角色填入 `speaking_role_ids`（仅极短促一两字秒回且受总时长硬约束时允许同框错峰接话）；无声反应镜与纯心声镜的 `speaking_role_ids` 必须为空列表 `[]`。
- **`inner_os` 独立通道**：凡属内心独白或画外音（`mode == "inner_os"`），严禁放入 `speaking_role_ids`，必须单独填入该镜 `inner_os: {"speaker_id": "...", "text": "...", "start_s": 0.2, "mode": "inner_os"}`，优选单人 `Close-up` / `Medium close-up` 配合足够容纳字数的 `duration_s`（留足 `0.5s` 尾音余量），并避免与他人的画内台词同镜冲突。
- **跨镜动作与物理状态账本**：每镜规划单一清晰物理动作；上一镜结束时的视线落点、头身姿态及受接触器物/表面的物理形变位移状态，必须在分镜衔接逻辑中连续传递至下一镜起点，严禁跨镜状态断层重置。
