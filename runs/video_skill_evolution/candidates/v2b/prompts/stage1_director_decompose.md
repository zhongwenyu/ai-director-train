# Stage 1：戏剧段落分镜与蒙太奇节奏规划指南

根据输入的戏剧段落任务卡与目标总时长 `target_duration_s`，将段落动态拆解为一组紧凑连贯的子镜头序列（`clips`）。

## 1. 动态拆镜与 `target_duration_s` 总长精准配平
- **面向通用总长动态拆解**：严禁套用固定时长段或固定镜头数模板，须依据输入 `target_duration_s` 及对白/动作信息密度动态规划子镜头数量，确保全部子镜头的整数秒 `duration_s`（单镜合法范围 `2`–`8` 秒）累加之和紧贴 `target_duration_s`（误差控制在最小整数取整范围内，严禁前松后紧或总时长溢出）。
- **语速核算与紧凑单镜常态**：按自然紧凑的戏剧口语节奏（中文常态约每秒 4–4.5 字，计入情绪换气停顿与句尾 `0.35s–0.50s` 防吞字余量）核算每句有声台词所需时长。单镜时长以 `2s–4s` 紧凑切镜为主导常态；除非单镜内包含不可拆分的连续大幅度肢体调度或高速密集对话交锋，否则严禁开出 `5s` 以上的静态单人长镜头，彻底根除前摇发呆与句尾注水。

## 2. 防跳切铁律（Anti-Jump-Cut）与正反打反应交织
- **严禁同说话人相邻单人跳切**：绝对禁止将同一说话人的连续有声台词直接切分为两个相邻的该角色单人镜头（同主体机位硬跳或单人景别微调均会造成生硬跳切割裂）。
- **“发声推动—反应承接—回应升级”蒙太奇范式**：
  - 遇到单人多句长台词、明显语义转折或情绪冲击落点时，优先穿插 `2s–3s` **听话人/在场旁观者的无台词静默反应镜头**（`speaking_role_ids: []`），捕捉听者的眼神骤变、笑意浮现、错愕怔住、反讽或动容，再切回说话人或转入对手反击；也可通过双人镜头（Two-shot）与过肩镜头（OTS）切换自然转移视觉焦点。
  - 空间建立力求凝练，进入戏剧核心与情绪交锋节点后，优先运用中近景（MCU）、近景/特写（CU）及过肩正反打（OTS）强化心理冲击力，避免全程停留在松散远景。

## 3. 出镜角色、画内发声与 `inner_os` 通道严格分流
- **`visible_role_ids`**：准确列出本子镜头画面中实际露面的全部角色 ID（过肩镜头中前景清晰入画的肩背角色须一并计入；纯净单人镜头仅填该单人角色 ID，与 Stage 2/3 引用标记严格一致）。
- **`speaking_role_ids`**：仅列出本子镜头中**画内张嘴发出有声对白**的角色 ID。无台词静默反应镜头、纯动作镜头或仅有心声独白的镜头，必须设为空数组 `[]`。
- **心声/画外音（`mode == "inner_os"`）独立隔离**：
  - 凡输入标注 `mode == "inner_os"` 的心声或画外音，**严禁**因该句心声将其说话人归入 `speaking_role_ids`。
  - 必须将其独立写入该镜头的 `inner_os` 字段：`{"speaker_id": "...", "text": "...", "start_s": 0.2, "mode": "inner_os"}`，让画面专注于该角色自然闭唇状态下的鲜活眼神与微姿态反应。

## 4. `lcut_audio_hold_over_next_s` 声桥平滑衔接策略
- **对白切入静默反应镜时优先开启声桥**：当本子镜头包含画内有声对白，且**紧接的下一个子镜头为无台词静默反应镜头或无对白动作过渡镜**（且无即时心声起音冲突）时，优先将本镜头的 `lcut_audio_hold_over_next_s` 设为 `0.3`–`0.8` 秒，让说话人尾音余韵自然延展叠化在听者的即时表情反应之上，增强正反打戏剧咬合度并消除切镜声学硬截断。
- **防人声重叠归零条件**：若紧接的下一个子镜头起始即有角色画内开口说话、起始即触发 `inner_os` 语音（除非将下一镜 `inner_os.start_s` 顺延避开声桥尾音），或本镜头已是段落末镜，则 `lcut_audio_hold_over_next_s` 必须填 `0.0`。

## 5. 分镜输出前必核清单
1. 全部 `clips` 的整数 `duration_s` 之和是否严格对齐 `target_duration_s`，且彻底消除了冗长站桩镜头？
2. 是否完全杜绝了同一说话人相邻两个单人有声镜头的跳切（Jump Cut）？
3. 长台词拆分与情绪交锋处是否穿插了紧凑无台词反应切镜，并合理配置了 `0.3`–`0.8` 秒 `lcut_audio_hold_over_next_s` 声桥？
4. 所有输入对白与 `inner_os` 是否按序全量覆盖、零遗漏零改词，且 `inner_os` 严格排除在 `speaking_role_ids` 之外？
