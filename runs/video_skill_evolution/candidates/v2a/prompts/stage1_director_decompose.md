# Stage 1：戏剧段落分镜、节奏与声画窗口规划指南

将输入的 `8.5s–12.5s`（或给定 `target_duration_s`）戏剧段落拆分为 `2` 到 `5` 个连续紧凑的子镜头（`clips`），从源头锁死短镜快切、防吞字时间窗、反应叠化与跨镜连续性：

## 1. `2s` 基准短镜快切与总时长硬封顶（反拖沓与反片尾空耗）
- **多镜短促切分**：常态优先拆分为 `4`–`5` 个连续子镜头（短段落不少于 `3` 个）。每个子镜头 `duration_s` 为整数秒（Schema 允许范围 `2`–`8` 秒，实操以 **`2s` 为默认起配基准，`2s`–`3s` 为主导常态**，仅不可拆分的密集长句可用 `4s`，严禁排布 `5s` 及以上拖沓长镜）。
- **总时长宁紧勿超**：所有子镜头 `duration_s` 之和必须严格紧贴 `target_duration_s` 的四舍五入整数秒，严禁累加超标导致整段拖沓。
- **片尾即刻收束**：末镜在最末音节收音或终局反应落定后仅留 `0.35s` 即刻切出，严禁在片尾留置无信息量的空耗时长。

## 2. 字数-镜长精确核算与切镜零吞字铁律
- **原词逐字保全**：画内对白与 `inner_os` 文本须原封不动保留输入原文，严禁删字改词。
- **按语速精准配秒**：按紧凑自然戏剧语速（每秒约 `4.0`–`4.5` 个汉字，含潜台词气口停顿）核算单镜时长：
  - 无声反应镜，或 `1`–`7` 字短句/反问/惊叹 → 配 **`2s`**；
  - `8`–`13` 字中等长度句子 → 上调配 **`3s`**；
  - `14`–`18` 字不可拆单句 → 上调配 **`4s`**。
- **镜内安全收音缓冲**：无论当前镜是否开启 `L-cut`，单镜内的画内台词或 `inner_os` 独白都必须在该镜自身 `duration_s` 结束前至少 **`0.35s`** 完整收尾（预计结束秒数 `<= duration_s - 0.35s`），绝不允许语音跨过 `duration_s` 边界被硬截断吞字。

## 3. 受话方无声反应切镜与 L-cut 声画叠化常态化
- **插入无声反应特写**：打破“甲说完硬切乙开口”的平庸乒乓节奏。凡遇施压逼问、关键秘密揭露、刺痛反击或潜台词转折，优先插入一个 **`2s` 受话方无声反应特写镜头**（`speaking_role_ids: []`，仅受话方入画），捕捉其听闻瞬间瞳孔、眉眼与呼吸的即时受激变化。
- **L-cut 尾音叠化协同**：`lcut_audio_hold_over_next_s` 默认填 `0.0`；**凡下一镜为无台词听话人反应镜或静默情绪转折镜时，当前说话镜优先设为 `0.3`–`0.6`**，使说话方尾音与余息自然叠入受话方特写起幅，实现流畅声画咬合。

## 4. 景别阶梯、情绪高点锁特写与反跳切规则
- **近景特写主导**：所有说话镜、无声反应镜及 `inner_os` 镜优先规划为贴近视线轴线的浅景深中近景（`MCU`）或特写（`CU`，可穿插少量浅景深 `OTS` 强化对峙空间），严禁对说话人使用远景或纯正侧脸。仅当首镜确需交代在场多人落座/站位起始关系时，方可用一次 `2s` 紧凑中景（`MS`）并立即切入近景。
- **情绪高点锁死单人特写**：识别全段戏剧张力峰值（核心潜台词爆发、冷冽施压顶点或悲喜决堤瞬间），必须完整锚定在贴视线单人 **`CU`（特写）** 内走完峰值弧光，严禁在高点中途提前切走，严禁错配中远景造成反高潮。
- **跨档防跳切**：优先保持一镜一主讲人；若同一角色连续两镜出镜，必须跨越至少两档景别跃迁（如 `MS` 直切 `CU`），严禁同角色同景别近似机位硬切。

## 5. 角色可见性、心声分离与跨镜物理连续性交接
- **精准角色绑定**：`visible_role_ids` 仅填写本镜画面实际可见角色 ID（干净单人 `MCU`/`CU` 仅填该单人 ID 以最大化面部保真度；仅双人同框或带前景虚化肩廓的 `OTS` 填双人 ID）；`speaking_role_ids` 仅填本镜画内张口说话的角色 ID。
- **`inner_os` 独立封装**：凡 `mode == "inner_os"` 的内心独白或画外音，**严禁放入 `speaking_role_ids`**，须填入 `inner_os: {"speaker_id": "...", "text": "...", "start_s": 0.2, "mode": "inner_os"}`，并配给该角色贴视线单人 `CU` 展现眼神潜台词。
- **跨镜状态追踪**：逐镜追踪角色躯干倾角、手部支点与道具受作用后的物理终态，确保下镜首帧与动态无缝继承，杜绝穿帮断层。
