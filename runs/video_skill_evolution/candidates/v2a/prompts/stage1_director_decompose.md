# Stage 1：戏剧段落分镜与节奏规划指南

将输入的 `8.5s–12.5s` 戏剧段落拆解为 `2` 到 `5` 个紧凑连续的子镜头（`clips`），兼顾戏剧交锋张力、反应留白与精准时长控制：

## 1. 镜长控制与台词防截断核算
- **整数秒与总长对齐**：每个子镜头 `duration_s` 取整数秒（合法范围 `2`–`8` 秒，**常态严格控制在 `2`–`5` 秒**），所有子镜头 `duration_s` 之和必须紧贴 `target_duration_s`。严禁安排无戏剧递进的 `5` 秒以上冗长静止单镜，杜绝前段温吞发呆导致总时长溢出。
- **紧凑语速与尾音安全垫**：按自然紧凑的戏剧语速（约每秒 4 至 4.5 个汉字，计入潜台词气口微顿）估算每句台词净发声时长。说话镜必须为句首留出约 `0.20s` 吸气起势，并为句尾预留至少 `0.35s–0.50s` 的尾音衰减与神态收束缓冲，严禁将过长台词硬塞入过短镜头导致成片尾字被截断。

## 2. 交锋切镜、反应镜头与景别律动
- **长句拆解与静默反应镜插入**：常态优先拆分为 `3`–`5` 个节奏错落的子镜。遇到长台词转折、话里有话试探、情绪施压或悬念揭示节点，主动在语义气口处切镜，优先插入 `2s`（或 `2–3s`）的**对手方静默反应镜头**（`speaking_role_ids` 置空），捕捉听者眼神暗流、微表情反差或克制呼吸，打破“一人从头念到尾”的单调感。
- **景别张力配置**：对话交锋与心理博弈以紧凑景别为主导（`Medium close-up`、`Close-up`、`Over-the-shoulder`），精准放大眼神与面部潜台词；仅在交代人物空间关系、姿态转换或关键器物交互时使用中景（`Medium shot`）。相邻子镜切换须具备明确的景别或机位角度反差，避免同机位同景别跳切。

## 3. 出镜角色与对白/心声严格分流
- `visible_role_ids`：仅填入该子镜头画面内实际可见的角色 ID（过肩镜头 OTS 中若前景角色露出明确肩颈发髻轮廓，亦需计入以确保空间与外观锚定一致）。
- `speaking_role_ids`：**仅填入画内张口发声说出台词的角色 ID**；静默反应镜此列表必须为空 `[]`。
- **内心独白隔离契约**：凡标注 `mode == "inner_os"` 的心声或画外音，**严禁放入 `speaking_role_ids`**，必须单独填入该镜头的结构化字段：
  `inner_os: {"speaker_id": "...", "text": "...", "start_s": 0.2, "mode": "inner_os"}`
  心声优先承载于角色近景或特写静默镜头，靠眼神与微神态传递潜台词。

## 4. L-Cut 声画交叠缝合（`lcut_audio_hold_over_next_s`）
- 当当前说话子镜头的**下一个子镜头为无台词听话人静默反应镜头**（或紧凑情绪承接镜）时，优先将当前镜头的 `lcut_audio_hold_over_next_s` 设为 `0.3`–`0.7`（最大不超过 `0.8`），使说话者尾音余韵自然漫入下一镜听者的微表情起幅，消除切镜生硬顿挫。
- 若下一镜头紧接另一角色立即开口抢白，或已至全段末尾镜头，则填 `0.0`。
