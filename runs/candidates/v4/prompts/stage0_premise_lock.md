# Stage 0.5：极简创意 → 常识动机与前三集连环爽点立项锁（`00_premise_lock.json`）

在动笔写任何长篇大纲或分集剧本之前，你必须先把用户输入的简短创意过一遍**最严苛的「现实生活常识 × 短剧小白观众爽感」压力测试**，把人设、危机根源与前 3 集爽感闭环焊死！

## 四条不可违背的立项铁律

1. **【身份—行为常识自洽锁】（彻底消灭“985大学生无故当厨工/学徒”式违和！）**
   - 拷问：主角干这件事（掌勺熬汤、修车捡漏、制衣裁剪、行医正骨、摆摊致富……），他的**社会身份、学历背景与家庭前史**在现实生活常识里是否 100% 严丝合缝？
   - **绝对红线**：严禁为了贴标签给一个“亲手下后厨颠勺/在街边干手艺活”的主角强安 **985/名校在读大学生、海归精英** 等与底层手艺工种天然割裂的身份！（除非他完全不亲手干杂活，而是纯粹出配方/资金雇佣老师傅当幕后老板）。
   - **黄金解法**：让主角的身份本身就长在痛点上——例如“老字号手艺传人遗孤，当年为供青梅女友上重点大学，自己放弃学业在女方家小馆后厨白熬了四年汤养活她全家”。一句话同时焊死：**为什么一身绝活、为什么前任考上大学后看不起他、为什么撤回秘方最解气**！零解释成本，小白观众 1 秒信服心疼！

2. **【危机同源锁】（彻底消灭“手伤五天+临时工勒索九千+突然倒闭”式假巧合！）**
   - 拷问：第 1～2 集盟友/新阵地遭遇的生存危机，**为什么发生？**
   - **绝对红线**：严禁编造“盟友父亲恰好前几天扭伤手腕 + 60块一天的临时工突然坐地起价要预支九千 + 正常开着的店五天就欠租倒闭”这种一眼假的巧合拼盘！
   - **黄金解法**：**盟友的危机必须直接由第 1 集的核心反派（前任/奸夫/黑心亲戚）造成！** 例如：核心反派为了扩建新店或垄断客源，用卑劣手段恶意退单、截胡包席、断供原料或挖走大客户，逼盟友的铺子绝境低价转让。这样主角帮盟友救场的**每一招，都是在正面抽第 1 集核心反派的脸**！主线仇恨 100% 咬合不断档！

3. **【零支线路人锁】（前 3 集火力 100% 集中，严禁一次性小喽啰水戏！）**
   - **绝对红线**：前 3 集严禁冒出“老王”“混混甲”“恶房东”等与主线仇人无关的一次性路人反派抢走整集戏份！前 3 集的所有交锋对手，只能是**第 1 集立下的核心仇人阵营**（及其直接派出/勾结的人）。

4. **【盟友痛快信任锁】（严禁救场后盟友冷脸审讯、内耗添堵！）**
   - **绝对红线**：主角出手救场或掏出真金白银/绝活入伙后，严禁让女主/盟友冷着脸质问“你是不是跟前任赌气、拿我家救命钱当筏子？”这种让观众憋屈划走的“内耗钩子”！
   - **黄金解法**：盟友必须**拎得清、信得快、双向奔赴**（可因长辈旧恩、亲眼见证绝活或同仇敌忾而当场拍板立契）；集尾钩子必须来自**核心反派迎面压上的下一轮实质打压或当面对垒**，绝不靠自己人猜忌凑悬念！
