# 四大核心赛道专属戏剧打法（Track Playbooks）

不同题材的观众爽感来源完全不同！**严禁拿“都市抓手腕吵架”去套所有赛道**。动笔前先对号入座本剧所属主赛道：

---

## 赛道 A：都市情感 / 隐退大佬 / 追悔火葬场（如《离婚后我收回一切》《装穷提亲》）

- **核心爽感引擎**：**“托举者抽梯子” + “眼瞎者自我毁灭”**。主角曾默默付出真金白银、核心资源或救命之恩，对方却把主角当软饭男/免费保姆/寒酸亲戚，转头讨好假贵人（白月光/势利亲家）。
- **最佳开局抓手**：
  - **并行对比开场**：一边是主角掌控全局的顶级底牌（百亿门店开业幕后批示 / 整排豪车彩礼待命），另一边是家里或宴席上主角（或主角守护的女儿/善良女主）遭受刺骨的轻视与双标对待。两相碰撞，前 15 秒压迫感与期待感瞬间拉满！
- **中段推进关键**：不要一次亮明全部身份，而是**一件件撤回托举**（停掉副卡、收回关键专利/药方、撤掉大客户订单、收回婚房居住权），让反派在不知不觉中一步步踩空，每次还嘴硬以为“离了你我照样行”，直到公开大场合彻底崩盘。
- **台词质感**：克制、体面、一针见血。主角越平静淡漠（“行，如你所愿”“签好了，祝你们锁死”），反派后期的崩溃越解气。

---

## 赛道 B：人间清醒 / 反套路轻喜爽剧（如《吃火锅不烧心》《风骚律师》）

- **核心爽感引擎**：**“预期违背” + “精神状态遥遥领先”**。别人按虐文套路出牌（豪门婆婆甩支票羞辱、渣男拿白月光刺激、奇葩当事人道德绑架），主角偏按喜剧/搞钱/专业降维打击出牌！
- **最佳开局抓手**：
  - **反差人设金句 + 丝滑变脸**：表面温顺乖巧演深情/演弱势，背过身立刻暴露清醒搞钱或毒舌本色（必须通过**自然动作反差 + 简短精辟 `[VO]` 内心吐槽**呈现，严禁一个人在空房间大声自言自语念台词！）。
- **中段推进关键**：节奏轻快灵动，每集一个反套路拆招——对手想看主角嫉妒发疯，主角顺手把对手送的礼折现凑够小目标；对手想拿规矩压人，主角翻出规则漏洞连本带利讨回来。
- **台词质感**：机锋、幽默、四两拨千斤，充满生活烟火气（火锅、记账单、二手折现、冷幽默法条）。

---

## 赛道 C：年代乡村 / 重生改命 / 赶山赶海致富（如《重回93》《激活空间1958》《赶山救母》）

- **核心爽感引擎**：**“时代稀缺红利” + “护短养家烟火气” + “极品亲戚眼红吃瘪”**。
- **最佳开局抓手**：
  - **生死节点重生 / 金手指觉醒 + 紧迫行动**：重回悲剧发生前半小时（拒让录取通知书、拦住卖妻女的赌鬼前身、抢在灾变/下乡前囤空物资），一睁眼立刻干脆行动，用鲜活接地气的年代口语立住人物！
- **中段推进关键**：
  - **看得见的物质改善（强视觉爽点）**：白面馍馍、大肥肉、野生大黄鱼、百年老山参、第一台彩电、万元户存折——每一集都要有具象的“肉香与钱响”，先紧着受苦的妻女/老娘吃饱穿暖，让门外偷看的偏心爷奶/刻薄大嫂馋得咬牙又占不到便宜。
  - **阶段跃迁**：解决温饱 → 摆摊/承包鱼塘山林 → 县城开厂/拿批条考大学 → 带动乡亲成为时代标杆。
- **台词质感**：带着泥土味与年代印记（“工分、供销社、粮票、万元户、大队长”），泼辣鲜活，严禁现代都市悬浮腔。

---

## 赛道 D：古装穿越 / 寒门权谋 / 玄幻空间脑洞（如《一身腱子肉做谋臣》《靠种地成皇室香饽饽》）

- **核心爽感引擎**：**“跨维认知碾压” + “外粗内细/微服私访身份错位”**。
- **最佳开局抓手**：
  - **绝境死局破题**：流放抄家现场、军帐问斩前夕、荒年断粮危机，所有人束手无策或等着看笑话时，主角用反常识的一招（现代农学/物理军工/毒辣阳谋/空间灵泉）当场止血翻盘！
- **中段推进关键**：权力的阶梯必须层层递进（村正/小校 → 县令/主将 → 节度使/皇子夺嫡 → 朝堂定鼎），每升一级换一批更高智商的对手，善用“借力打力”与“请君入瓮”，杜绝全员无脑喊打喊杀。
- **台词质感**：半文半白、短促有力，既有古风称谓礼制（某、大人、军法、圣谕），又通俗好懂不拗口。
