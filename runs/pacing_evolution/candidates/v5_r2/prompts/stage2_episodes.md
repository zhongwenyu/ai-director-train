# Stage 2：大纲与状态账本 → 跨集连载分集剧本（`hit-short-drama v6`）

依据《Stage 0.5 立项锁》、全剧大纲及上一批结尾，创作 {batch_range} 完整剧本。参考 `episode-craft.md`、`anti-patterns.md` 及同赛道真实 3 集连载范本。直接输出 Markdown 正文，不附分析、自评或说明。

## 一、写前五大硬核铁律（源自红果爆款实证：慢剥笋、真常识、零打架、活人话！）

1. **【单集动作做减法：演透“温情遮羞布→双标剥皮→寒心亮剑”的活人质感！】**
   - **1 集（约120秒）只推进同一核心事件的 1/3～1/4 切面，每集只打透 1～2 个交锋回合**！严禁在同一客厅十几分钟内连续硬塞“毁旧物+撕借条+停副卡+撤年费+查封账目+逼签赠与书+掏房本+拉闸锁表”七八个动作！
   - **每集写足 20～28 句有来有回的活人对话（台词总字数 350～520 字，预估时长 110～150 秒），控制在 1～2 个主场景内深挖**：
     - 开场前几句寒暄自然叫响每个人的准确亲属/社会称谓（核准内外姓氏，绝不把外姓外孙喊成本家独苗）；
     - **禁开场脸谱化咆哮与极端粗鄙套路**：反派算计时先端着“一家人不计较、紧着孩子、替你省心”的体面笑脸和稀泥（严禁一上来就无铺垫咆哮、在酒店主桌翘腿吐瓜子皮摔席卡，或密集堆砌踩画抢蛋糕骂街），被主角顶回后才层层变脸道德绑架；
     - **集尾停在同一场景冲突最紧绷的未决瞬间**，**下一集第 1 行在原场景下一秒无缝续接**！

2. **【跨集事实、认知、主体与时间线 100% 咬合：严禁前后集台词打架！】**
   - **四大跨集零矛盾红线**（写每集前必回看上一集台词）：
     - **事件节点不倒挂**：若争点是“尚未通过落户/报名初审需房主签字”，第1集绝不挂“升学录取庆功宴”横幅；
     - **动作主体不换人**：第1集说“陪她去医院结扎”，第2集绝不能变成“结扎是我自愿做的”；
     - **知情状态不失忆**：前集亲口讲过某政策/门槛的角色，后集绝不像初次听说般震惊变色；事前已串通换锁撕条的同谋，第1集绝不装不知情敲门或被屋内宴席漏请；
     - **经济口径不精分**：前集已交代主角有婚前房或积蓄贴补，后集反派绝不胡喊“吃我的住我的、让你净身出户喝西北风”（只能打人情牌耍赖不搬）。
   - **重生与隐名闭环**：重生局场 `1-1` 用 20～25 秒演明前世受骗真相，切回 `1-2` 时反派必须先满脸堆笑温情画饼；隐名托举局闪回绝不当面说“把公司交给你”，日常收支算术必须算平。

3. **【真实物权常识、物理时空与受挫反应 100% 守恒】**
   - **禁法盲伪底牌与降智圆场**：有房产证本就不怕撕借条，绝不把“居委会借住备案按手印”当致命反杀神兵（真底牌应是产权证及房户一致须产权人本人面签、或撤销未办结预约）；严禁第2集打电话报“YH-001主卡核销”逼反派强行嗤笑“找人演戏”水时长，一旦止付或产权当场核实，反派必须转为道德绑架耍赖或搬长辈施压！
   - **禁跨空间瞬移与预制百宝箱**：同场无缝续接时，刚被停卡的场外角色绝不能半分钟后从超市瞬移上楼砸门；前场约定后文必咬合；反派绝不揣打印版《无偿赠与/放弃协议》逼签；主角不在玄关设密码暗格掏房本、不从油围裙掏汇款单铁盒；不编造“银行客服秒退商户年费”或“私锁公共水电箱”。

4. **【去字幕拐棍与严控 VO：靠家常对质演前史，严禁剧透底牌！】**
   - **禁贴大佬标签字幕**：`[画面文字]` 仅作极简时间锚点（如`三年前`）或首秀亲属称谓，**严禁贴“隐退董事长、装病三年托举丈夫”等背景小作文**！
   - **严禁 VO 泄底与报账**：每集 `[VO]` 严格限 **0～1 句**极短当下反差心声（15字内，拿不准就写 **0 句**！），**严禁在 `[VO]` 里交代病史/隐退前史、严禁提前点破隐藏身份或反杀物证（留足第3集亮牌悬念）、严禁复述画面或做总结陈词**！过往付出与隐情一律融进当面对质的具体生活细节里带出。
   - **禁读心术**：在场角色听不见 `[VO]`，结盟对赌条件必须由主角亲口说出（每场主角有声台词占比 ≥ 30%），严禁哑巴签约或白送股份。

5. **【活人大白话短句：句均 12～22 字，单句 <= 50 字】**
   - 严禁喊“限72小时搬空”“启动最高核销权限”等AI公文口号，用真实生活狠话（如“招生办要房主本人签字，你们慢慢等”“礼拜天我带人换锁”）一剑封喉！

## 二、标准剧本格式

```markdown
# 第N集　集名
**预估时长**：约XXX秒

## N-1　内/外　具体场景　日/夜
**人物**：本场人物

[画面文字] 极简时间锚点或纯亲属称谓（选填，禁贴大佬身份背景！）
△ 简洁可拍的动作与有对象的神态反应（不写机位术语与抽象情绪总结）。
角色名：通俗扎心、带人情潜台词与清晰前因后果的活人口语短句。
[VO] 角色名：极短当下心声（每集0～1句，禁交代前史与剧透底牌，可全集0句！）。

【本集完】
```

完结标记 `【本集完】` 后不附任何备注，下一集另起 `# 第N集`。
