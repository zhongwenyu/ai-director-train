# Stage 2：大纲与状态账本 → 跨集连载分集剧本（`hit-short-drama v5`）

依据《Stage 0.5 立项锁》、全剧大纲及上一批结尾，创作 {batch_range} 完整剧本。参考 `episode-craft.md`、`anti-patterns.md` 及同赛道真实 3 集连载范本。直接输出 Markdown 正文，不附分析、自评或说明。

## 一、写前五大硬核铁律（源自红果爆款实证：3～5集共载一事！）

1. **【彻底废除“一集塞完一件事”，用多集连载把同一场面演透！】**
   - 仔细体会参考范本（如《唯独不给我女儿红包》连续 3 集都在同一张年夜饭圆桌上层层递进）：**1 集（120秒）只推进一个完整事件的 1/3～1/4 切面**！
   - **每集写足 20～28 句有来有回的活人对话（台词总字数 350～520 字，预估时长 110～155 秒），控制在 1～2 个主场景内深挖**：
     - 把在场每个人的亲属/社会称谓（“爸”“林叔”“双双”“楚师兄”“芊芊”“周厂长”）在寒暄与交锋前几句自然叫响（首次登场核心人物可辅以简洁 `[画面文字] 姓名·身份关系` 花字，但台词称呼也必须同步叫清！）；
     - 把前情起因、对方的虚伪铺垫、主角的试探反问、周围人的帮腔反应一步步演足，**绝不跳过拉扯过程直接甩结果**！
     - **集尾优先停在同一场景冲突最紧绷的未决瞬间**（如对方刚逼他落笔主角冷声反问、或刚亮出底牌对方变色欲扑），**下一集第 1 行在原场景下一秒无缝续接**！

2. **【前世今生与隐忍分叉：必有具体前世场面 + 当年先温情画饼再掀桌】**
   - 若是重生开局：第 1 集场 `1-1` 必须用 **20～25 秒（5～7 句对话）演明前世结局真相**（如十年后上市夜被夺方扫地出门，亲口点破“十年前毕业家宴信了你们的联营婚约画饼，白熬十年”）；
   - 切回当年现场（场 `1-2`）时，**反派一家开场必须满脸堆笑敬酒画大饼哄骗主角**，绝不能主角还没反抗反派就无故嫌弃赶人！等画饼铺足、纸笔推到眼前，主角才冷冷开口刺破假面（第 1 集在此断章，第 2 集原桌下一秒续接彻底撕破脸、撕方撤火）！

3. **【屏幕裸看零盲区：禁读心术、主角亲口主导谈判、禁无脑慈善】**
   - **观众看不见 `**人物**` 行，剧里其他角色绝对听不见 `[VO]`！**
   - 任何结盟或交易场次，必须把「对方遭遇什么同源反派打压（如原大厨刚被挖走、急聘掌勺）」→「主角亲口提出什么对赌军令状（保住大席才技术入股五五分，砸了白干抵损）」→「对方为何信任拍板」完整说清演透！**每个主场景主角有声开口句数占比不得低于 30%！**

4. **【物理与权限常识：禁围裙百宝箱、禁几十秒瞬移盖章、禁越级狂言】**
   - 端菜厨子绝不从油围裙里凭空掏出装 48 张汇款单的铁盒；反派绝不在几十秒内拿着客户重签盖章的大单瞬移回来；街边同行绝不口嗨“封杀全城原料”（只能针对共用供货商或具体客户施压）。

5. **【活人大白话短句：句均 12～22 字，单句 <= 50 字】**
   - 像真人在饭桌上、店门口吵架办事，一句顶一句，通俗扎心，绝不念商务法务报表或口号排比句！

## 二、标准剧本格式

```markdown
# 第N集　集名
**预估时长**：约XXX秒

## N-1　内/外　具体场景　日/夜
**人物**：本场人物

[画面文字] 必要的时间锚点或核心人物首秀身份关系（选填）
△ 简洁可拍的动作与神态反应（不写机位术语）。
角色名：通俗扎心、前因后果清晰的活人口语短句。
[VO] 角色名：简短内心认知差（切记在场旁人听不见！）。

【本集完】
```

完结标记 `【本集完】` 后不附任何备注，下一集另起 `# 第N集`。
