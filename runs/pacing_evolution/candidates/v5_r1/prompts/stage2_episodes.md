# Stage 2：大纲与状态账本 → 跨集连载分集剧本（`hit-short-drama v5`）

依据《Stage 0.5 立项锁》、全剧大纲及上一批结尾，创作 {batch_range} 完整剧本。参考 `episode-craft.md`、`anti-patterns.md` 及同赛道真实 3 集连载范本。直接输出 Markdown 正文，不附分析、自评或说明。

## 一、写前五大硬核铁律（源自红果爆款实证：慢剥笋、真常识、活人话！）

1. **【单集动作做减法：杜绝“同场八倍速报菜名”，演透人情双标与寒心递进！】**
   - 仔细体会真实爆款范本：**1 集（约120秒）只推进同一核心事件的 1/3～1/4 切面，且每集内部只打透 1～2 个交锋回合**！严禁在同一客厅十几分钟内连续硬塞“毁旧物+撕借条+停副卡+撤年费+查封账目+逼签赠与书+掏房本+拉闸锁表”七八个动作！
   - **每集写足 20～28 句有来有回的活人对话（台词总字数 350～520 字，预估时长 110～150 秒），控制在 1～2 个主场景内深挖**：
     - 开场前几句寒暄与交锋自然叫响每个人的准确亲属/社会称谓（“爸”“二叔”“小姑”“林叔”“楚师兄”，核准内外姓氏，绝不把外姓外孙喊成本家独苗）；
     - 把对方的虚伪人情遮羞布（如“一家人计较啥”“先紧着孩子”）、主角的克制求证、旁人的双标帮腔一步步演足，让寒心感层层累积后再亮出单一致命反制；
     - **集尾停在同一场景冲突最紧绷的未决瞬间**，**下一集第 1 行在原场景下一秒无缝续接**！

2. **【因果分叉与闪回严丝合缝：禁时间线悖论、禁闪回吃设定】**
   - 若是重生开局：场 `1-1` 用 **20～25 秒（5～7 句对话）演明前世受骗真相**；切回当年现场（场 `1-2`）时，**反派开场必须满脸堆笑温情画大饼哄骗**，等纸笔或要求推到眼前，主角才冷声反问刺破假面！
   - 若涉及过往隐退/暗中托举：闪回台词必须与当下的“不知情边界”100% 吻合（若设定配偶不知情，闪回中绝不能当面说“我把公司交给你”），且日常开销账目算术必须算平（绝不搞“月给5000买菜钱攒出38万年费”或“刷五年亲情副卡不知主卡是谁”）。

3. **【物理时空、日常道具与受挫反应 100% 守恒】**
   - **禁跨空间瞬移与吃设定**：同场无缝续接意味着现实时间只过了几秒钟！刚在电话里被停卡的场外角色，绝不能半分钟后就从超市瞬移到三楼门外砸门；前场说出口的安排（如约了木匠十点到、为何今天上门）后文必须咬合，严禁中途蒸发或一边揣逼签书一边赶人改天再来。
   - **禁预制逼签书、随身百宝箱与伪规则**：日常家宴或上门，反派绝不提前打印《房产无偿赠与书》《财产放弃书》揣兜里逼签；主角绝不无故随身带公证房本/大挂锁、不在玄关设“密码暗格”掏房本、不从油围裙掏汇款单铁盒；绝不编造“银行客服电话秒退已付商户年费”、“私锁楼道公共水电箱”或“街边店封杀全城原料”。
   - **禁见铁证强行失忆**：一旦红本产权、银行止付通知等铁证已当场验看，反派绝不能弱智嗤笑“找托儿演戏吓唬谁”，必须顺应人性转为撒泼耍赖、道德绑架或搬救兵施压。

4. **【屏幕裸看零盲区与克制 VO：禁读心术、禁报账总结式 OS】**
   - **观众看不见 `**人物**` 行，在场角色绝对听不见 `[VO]`！** 任何结盟或对赌必须由主角亲口说出条件（每个主场景主角有声台词句数占比 ≥ 30%），严禁哑巴签约或无脑白送股份。
   - **严控 `[VO]` 与花字**：`[画面文字]` 仅作极简时间锚点或首秀人物身份提示（不贴冗长背景小作文）；`[VO]` 每集精选 **0～2 句**真正当众不便明说的极短反差心声，**严禁在 `[VO]` 里背诵设定账单、复述画面动作或做“原来拿我当绝户肥羊”的功能性总结陈词**！

5. **【活人潜台词短句：句均 12～22 字，单句 <= 50 字】**
   - 像真人在饭桌上、屋门口拉扯过招，偏心者讲“体面话”办偏心事，绝不贴脸自报恶人、绝不念法务合同条款或排比口号！

## 二、标准剧本格式

```markdown
# 第N集　集名
**预估时长**：约XXX秒

## N-1　内/外　具体场景　日/夜
**人物**：本场人物

[画面文字] 极简时间锚点或核心人物首秀身份关系（选填）
△ 简洁可拍的动作与有对象的神态反应（不写机位术语与抽象情绪总结）。
角色名：通俗扎心、带人情潜台词与清晰前因后果的活人口语短句。
[VO] 角色名：极短认知反差心声（每集0～2句，禁报账与复述画面，旁人听不见！）。

【本集完】
```

完结标记 `【本集完】` 后不附任何备注，下一集另起 `# 第N集`。
