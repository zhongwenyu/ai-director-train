# Stage 2：大纲与立项锁 → 高张力跨集连载分集剧本（`hit-short-drama v6`）

依据《Stage 0 立项锁》、全剧大纲及前序剧集，创作 {batch_range} 完整分集剧本。参考 `episode-craft.md`、`anti-patterns.md` 及同赛道真实爆款 3 集连载范本。直接输出 Markdown 正文，不附任何解释或自评。

## 一、写作五大通用铁律

1. **【忠于原创意与大纲设定，借具体细节把人情冷暖写透！】**
   - 严格落实立项锁中的人物身份、关系网与本集核心回合，**严禁擅自删改核心设定，严禁把台词写成财务算账、法规背诵或干瘪喊口号**（禁喊“十年苦活全是我干”“今天让你受死”等脸谱台词）！
   - **用可感微物与体面拉扯外化情绪**：把恩怨、屈辱、温情与反杀落在一碗吃食、一件旧物、一张单据、一次护短挡伤或落锁拒客等具体动作细节上；写出偏心者或前任“替大局着想/死要面子/笃定主角会服软”的真实心理惯性，写出清醒抽身者的平静果决与同盟亲人的自然暖意，让每轮对话表面是家常事理、底下是利益与人心交锋。

2. **【沉浸连载厚度：单集 1～2 个回合演足现场感，拒绝八倍速PPT快进】**
   - **1 集（约 110～150 秒）只扎实打透同一事件切面的 1～2 个实质交锋回合**，铺展 **2～3 个** 自然衔接的场景（或高张力重场戏），写足 **25～36 句** 有来有回、带潜台词的自然对白（台词总字数 **420～650 字**）。
   - **做厚单场肌理，绝不跨阶段抢跑**：严禁每集只写两场十来句干瘪台词就匆匆翻篇，更严禁在前 3 集硬塞七八个桥段或跨入第二阶段事件；把笔墨花在冲突爆发前的利益试探、委屈蓄势、旁人双标嘴脸与反击落地的情绪余韵上。
   - **集尾切在悬念最紧绷、结果尚未落地的瞬间**，相邻集首尾无缝承接。

3. **【生活化称谓自然落地，严禁“户口本腔”机械报全名】**
   - 关键角色首次登场的前两轮对话内，用**符合亲疏尊卑的真实日常称呼**（如“妈/娘”“二叔”“哥”“师父”“林总”）配合当下具体争执，让裸看观众零障碍看懂关系。
   - **反非人话铁律**：**绝对禁止**违背口语常识的生硬姓名播报——严禁管自己长辈叫“我娘某氏”、严禁亲熟之人吵架或哄劝时句句硬缀全名（如“死丫头某某某”）、严禁对陌生人突兀自报姓名家门履历！角色全名仅借外人点名、文书单据或极简 `[画面文字]` 自然呈现。
   - 同一特权、资产或底牌在不同角色口中的归属措辞，必须严格贴合**该说话人当下的认知视角**，绝不说漏嘴或口径打架。

4. **【家境量级、实物台账与肉身物理尺度 100% 严密】**
   - **分时动机与时空常识自洽**：闪回/前世与当下的时间线、知情边界严格对齐；无跨空间几十秒瞬移，无随身预制奇葩夺产协议；大额合同付款或取证须有合理前置衔接。
   - **物资存取与贫富阶层守恒**：前场受冻哭穷，后场绝不能无故从屋里掏出私藏巨款厚衣；包袱、抽屉或储物异宝**只能取出前文已存入或合理携有的物件**，严禁凭空变道具；小门小户绝不凭空冒出家丁随从，断交后再生纠缠必有新利益诱因；异能或核心资源须守住可持续运转边界。
   - **伤病与武力尺度真实连贯**：抗寒、失血、骨伤须合乎人体极限；身手高强者若被弱者短暂拖住，必须写出怀抱幼童、顾忌伤人或暗算等具体掣肘，绝不忽强忽弱。

5. **【屏幕裸看零盲区、音画互补 `[VO]` 与鲜活口语短句】**
   - 观众看不见 `**人物**` 设定行，**场内旁人绝对听不见 `[VO]`**！关键交锋主角必须亲口有声主导局面。
   - **`[VO]` 贵精不贵直（每集 0～2 句）**：仅在“当众不便明说的底牌算计、表里反差或关键认知点破”时用极短 `[VO]`；**凡硬核动作与神态反应已足够传递寒心或决绝时，直接靠动作留白，绝不叠直白抒情 `[VO]` 或复述画面念设定账单**。
   - 台词贴合人物身份与时代语境，句均 **12～22 字**，单句 <= 50 字，短促鲜活、好念好演。

## 二、标准剧本交付格式

```markdown
# 第N集　集名
**预估时长**：约XXX秒

## N-1　内/外　具体场景　日/夜
**人物**：本场人物

[画面文字] 极简时间地点或首秀人物身份提示（选填）
△ 简洁可拍的动作与有对象的神态反应（不写镜头机位术语与抽象心理总结）。
角色名：贴合身份、带潜台词与情绪张力的自然口语短句。
[VO] 角色名：极短反差心声（每集0～2句，旁人听不见，禁报账与复述画面）。

【本集完】
```

完结标记 `【本集完】` 后不附任何备注，下一集另起 `# 第N集`。
