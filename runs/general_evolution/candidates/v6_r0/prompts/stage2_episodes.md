# Stage 2：大纲与立项锁 → 高张力跨集连载分集剧本（`hit-short-drama v6`）

依据《Stage 0 立项锁》、全剧大纲及前序剧集，创作 {batch_range} 完整分集剧本。参考 `episode-craft.md`、`anti-patterns.md` 及同赛道真实爆款 3 集连载范本。直接输出 Markdown 正文，不附任何解释或自评。

## 一、写作五大通用铁律

1. **【忠于原创意与大纲设定，把人情拉扯与情绪暗流写活！】**
   - 严格落实立项锁中的人物身份、关系与本集核心回合，**严禁擅自删改核心设定，严禁把台词写成财务算账、法规背诵或大纲口号**！
   - 写出真实的人性温度与刺痛感：例如习惯被迁就者的理所当然与端架子、吹牛者的捧高踩低、清醒抽身者的平静果决（越不纠缠不自证越有张力）、真诚盟友或亲人的暖心细节。让每一轮对话都既有表面人情话，又有底下的利益/情感交锋。

2. **【从容连载节奏：单集 1～2 个回合，拒绝八倍速快进报菜名】**
   - **1 集（约 110～150 秒）只扎实打透同一事件切面的 1～2 个交锋回合**，每集写 **20～28 句** 有来有回的自然对白（台词总字数 340～520 字，控制在 1～3 个场景内），严禁同场硬塞七八个反转制裁动作。
   - 关键角色首次登场的前两轮对话内，自然带出准确称谓或身份关系（如“爸”“学姐”“室友”“王爷”“师兄”），让裸看屏幕的观众零障碍看懂全员关系与争点。
   - **集尾切在悬念最紧绷、结果尚未落地的瞬间**，相邻集紧密咬合承接。

3. **【分时动机与常识逻辑严丝合缝】**
   - 闪回/前世与当下的时间线、知情范围必须 100% 自洽（若回到矛盾尚未撕破脸的早期节点，角色言行必须符合当时的真实关系状态，由主角的新选择引发连锁反应）。
   - 严守物理时空与日常常识：无跨城/跨楼几十秒瞬移、无预制奇葩夺产协议贴脸逼签、无随身百宝箱道具、无见铁证仍装瞎失忆。

4. **【屏幕裸看零盲区与点睛 `[VO]`】**
   - 观众看不见 `**人物**` 设定行，**场内其他角色绝对听不见 `[VO]`**！主角在关键抉择、拒绝、谈判或立威场次必须亲口发声主导局面（有声台词充分，不做哑巴背景板）。
   - `[画面文字]` 仅用于极简时空/身份提示；`[VO]` 每集精选 **0～2 句** 真正当众不便明说的极短心理反差或认知点睛，绝不拿 `[VO]` 念设定说明书或复述画面动作。

5. **【鲜活口语短句：句均 12～22 字，单句 <= 50 字】**
   - 贴合人物身份与时代语境（校园像大学生、市井像街坊、朝堂古风自然、修仙末世利落），短促有力、好念好演。

## 二、标准剧本交付格式

```markdown
# 第N集　集名
**预估时长**：约XXX秒

## N-1　内/外　具体场景　日/夜
**人物**：本场人物

[画面文字] 极简时间地点或首秀人物身份提示（选填）
△ 简洁可拍的动作与有对象的神态反应（不写镜头机位术语与抽象心理总结）。
角色名：贴合身份、带潜台词与情绪张力的自然口语短句。
[VO] 角色名：极短反差心声（每集0～2句，旁人听不见，禁报账与复述画面）。

【本集完】
```

完结标记 `【本集完】` 后不附任何备注，下一集另起 `# 第N集`。
