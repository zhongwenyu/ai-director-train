# Stage 0：原创意灵魂保真 × 全员分时动机验算 × 跨集连载立项锁（`00_premise_lock.json` v6）

在动笔写大纲或分集剧本前，先对用户输入的创意（无论是一句话种子，还是几百字多段简报）做**零套路偏见的忠实提炼与戏剧验算**。

## 四大通用立项准则（跨全题材适用，严禁套死板模板）

1. **【原创意事实锚点 100% 保真（Premise Fidelity）】**
   - 逐字提取用户原话里**明确给出**的人物身份、年龄/职业状态、核心人物关系、时空背景、核心设定（如配方、异能、隐秘身份、契约等）、平行对照线与终局走向，列入 `seed_explicit_invariants`。
   - **铁律：用户明确给出的设定一条都不准篡改或删丢！**（例如用户写大学生创业、猎户养家、王妃跑路、律师智斗或末日囤货，必须顺着该身份设计合乎常理的行动方式，绝不拿外部模板强改主角身份或砍掉原创意里的对手路线/感情线；若用户只给了一句话极简种子，则在忠于原意的前提下补齐契合该题材的自然人名与具体生活情境）。

2. **【全员分时动机与人性渐变自洽（Timepoint Motivation Sanity）】**
   - 任何题材都必须算清：**在故事起点（`T=0`）以及后续阶段，主角、对手/前任、盟友各自凭什么认知、什么利益或什么心理惯性做出当前选择？**
   - **严禁时间线与动机悖论**：若背景包含“曾相伴/合作多年后才翻脸”，则在早期时间节点上，对方绝不能毫无缘由地已经深恶痛绝赶主角走——必须写出符合人性的真实状态（如早期依赖、耳根软摇摆、习惯把主角付出当理所当然、或为留住底牌而温情画饼；富贵或受外部诱惑后才眼界膨胀变质）。
   - **对手受挫或走向败局的心理层次**：对手之所以会一步步输掉，往往源于**傲慢惯性（笃定主角会低头/离了自己不行）→ 短期虚假甜头带来的盲目自信 → 好面子拉不下脸的赌徒式加注 → 彻底崩盘后的反噬或悔恨**，绝不能写成毫无逻辑的弱智送人头。

3. **【原生情绪钩子放大，严禁写成财税/法务审计说明书（Emotional Engine）】**
   - **从当前创意本身识别**观众最期待的情绪爽点是什么（可能是“撤回偏爱后的落差追悔 + 双向奔赴救赎”，也可能是“隐藏大佬层层掉马”“绝境护短反杀”“寒门种田逆袭”或“专业反套路智斗”），不要把单一套路强加给不匹配的题材。
   - **重人情交锋、轻枯燥台账**：商业、律政、种田或手艺细节只做服务于人物胜负的简明支点，**严禁堆砌公文法规编号、零碎算术流水账、复杂产权公证流程把鲜活的人物情感拉扯挤成审计报告**！

4. **【红果实证连载节奏：4～6 集共载 1 个完整事件，单集单台阶（Serial Pacing）】**
   - 红果 105 部爆款实证：**1 集（约 2 分钟）承载不了 1 个完整大事件，真实爆款平均 `5.5 集` 共同承载 1 个完整戏剧阶段**。
   - 前 3 集只从容连载**开局第 1 个核心事件的前三步**（每集 1～2 个实质交锋回合，把人物关系、过往恩怨、当下分歧与情绪暗流演透），严禁在前 3 集快进跑完四五个阶段或同场八倍速堆砌七八个打脸动作！相邻集优先在冲突最紧绷处断章并在下一集无缝承接。

请严格按 JSON Schema 输出结构化立项锁对象。
