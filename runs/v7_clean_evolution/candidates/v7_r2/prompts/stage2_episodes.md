# Stage 2：大纲与立项锁 → 高张力连载分集剧本（`stage2_episodes.md`）

依据《Stage 0 立项锁》、全剧大纲及前序剧集，创作 {batch_range} 完整分集剧本。参考 `episode-craft.md`、`anti-patterns.md` 与 `dialogue-voice.md`。直接输出 Markdown 正文，不附任何解释或自评。

## 一、剧本创作六大通用铁律

1. **【锚定原生支点与具象视听行动，拒绝套路降级与静态嘴仗】**
   - 紧扣立项锁与大纲确立的**原生独特戏剧支点与情感张力源**展开场面，将反差与兑现落在可见的具体物件、实际损益、行动选择与处境翻转上，严禁滑向陈旧泛化的常规吵架模板或靠角色空喊概念口号。
   - **用视听行动推着剧情走**：每场戏必须赋予角色正在执行的具体可拍动作（如查验交割、封堵截留、当场实测、暗中转移、设局取证等），让对白在行动推进与受阻中迸发，严禁让人物杵在原地靠冗长口头争辩或说明性对谈交代矛盾。

2. **【真实利害权衡与细腻心理博弈，拒绝动机降智】**
   - 主角、阻力方及在场各方均须站在自身现实利益、体面顾虑与身心处境上自洽行事：用试探摸底、顺水推舟、借规矩施压、避重就轻或断尾止损展开拉扯，严禁把人物写成违背利害常识盲目冲动挑衅、叉腰自认作恶或喊口号宣泄的单薄符号。

3. **【层层蓄势递进与强悬念卡点，拒绝泄底快进与原地复读】**
   - 单集（约 110～150 秒，铺展 1～3 个自然衔接场景）扎实演透大纲规定的 1～2 个递进交锋回合（起势受阻→变招加码→逼出实质位移），严禁提纲式快进过早泄底；
   - **严禁同水平面复读吵架**：每一场戏结束时，双方的筹码、处境、权限或认知态势必须发生实质改变；上一场已摊牌定性的分歧，下一场必须切入实际后果或新筹码验证；
   - **集尾必须卡在压强最紧绷、结果未决的临界点**（关键动作悬停、底牌将掀未掀、可信新反制浮现或两难抉择逼到眼前），相邻集首尾逐秒紧密咬合。

4. **【跨场连续性闭环与单人认知边界铁律】**
   - **时序与状态严丝合缝**：跨场次与跨集的时间推进、空间动线、财务收支、物件存取归属、伤病体征及已发生事实必须严格连续守恒，无跨空间瞬移、无客观状态跳变、无缺乏前因铺垫的凭空机械降神。
   - **严守有限知情边界**：严格区分观众全知视角与各角色当下的认知范围——角色只能基于亲历所见或已获知渠道反应与推断，无证据来源绝不“开天眼”精准道破隐秘，也绝不出现已获知信息的记忆断层；场内旁人绝对听不见 `[VO]`，关键破局由角色有声行动主导。
   - 关键角色首次登场借符合亲疏尊卑的日常称呼配合眼前事由自然带出关系，不在熟人交谈中硬缀全名或生硬背诵文件书面全称。

5. **【潜台词交锋与错位话咬话，消灭设定播报与旁观传声筒】**
   - **开口只为当下目的，话留三分潜台词**：角色说话只为争取眼前结果、试探虚实或遮掩退路，严禁借角色之口朗读双方已知前史、堆砌冗长前置修饰定语、生硬播报精确量化明细或替大纲打逻辑补丁；能靠动作与半截话点透的绝不直白说穿。
   - **破除对联式回合制与传声筒**：用抢话截断（`——`）、抓字眼反问、答非所问或沉默动作顶替回答来构建真实交锋，消灭按序完整表述的对仗往返；在场旁观者或次要角色只从自身私心利害与本能顾虑出发反应，严禁沦为整齐划一解说局势、替观众总结胜负的播报器。

6. **【动态生理声纹、日常真语汇与音画互补】**
   - **声纹贴合心智阅历与当下生理情绪**：依据角色年龄心智、社会阅历及**当下的喘息、伤痛、惊惧、疲惫或隐忍状态**自然生成参差句式——急迫受创或心虚时自然落短促碎句、倒装、语塞重复与气口停顿，彻底消除全员字正腔圆、逗号对半开的舞台朗诵腔。
   - **拒绝生造概念与掉书袋术语**：使用贴合时代地域的生活真语汇，行业或特殊设定表达化为内行顺嘴的日常实操简称，严禁生造悬浮书面复合词、堆砌教科书术语或跨时代地域乱串违和词。
   - **音画分工明确**：视觉动作、神态与环境异象交由 `△` 呈现，严禁角色用台词充当画面解说员；`[VO]` 贵精不贵多，仅在画面无法外化的关键表里反差或暗藏底牌处极短点破，动作与潜台词已到位处直接留白。

## 二、标准剧本交付格式

```markdown
# 第N集　集名
**预估时长**：约XXX秒

## N-1　内/外　具体场景　日/夜
**人物**：本场人物

[画面文字] 极简时间地点或人物身份提示（选填）
△ 简洁可拍的动作与有对象的反应（不写机位术语与抽象心理总结）。
角色名：贴合身份语境与当下生理情绪、服务眼前目的的鲜活口语。
[VO] 角色名：极短反差心声（选填，旁人听不见，禁报账与复述画面）。

【本集完】
```

完结标记 `【本集完】` 后不附任何备注，下一集另起 `# 第N集`。
