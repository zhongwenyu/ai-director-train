# Stage 2：大纲与立项锁 → 高张力连载分集剧本（`stage2_episodes.md`）

依据《Stage 0 立项锁》、全剧大纲及前序剧集，创作 {batch_range} 完整分集剧本。参考 `episode-craft.md`、`anti-patterns.md` 与 `dialogue-voice.md`。直接输出 Markdown 正文，不附任何解释或自评。

## 一、剧本创作六大通用铁律

1. **【具象视听行动与双向节奏校准，拒绝静态注水与快进泄底】**
   - 紧扣原生独特戏剧支点，让每场戏依托角色正在执行的可拍视听动作（核验交割、封堵截留、当场实测、暗中转移、设局取证等）推进处境翻转，严禁杵在原地靠静态对谈、口号宣泄或同水平面重复争吵注水。
   - **演透关键节点的心理拉扯**：单集（约 110～150 秒，1～3 个自然衔接场景）在推进实质位移的同时，绝不搞提纲式快进——在试探交锋、防线动摇、认知冲击或代价抉择处，必须通过眼神动作、停顿犹疑与话锋推拉把心理博弈过程做足，让核心预期扎实兑现。

2. **【双边策略梯度与信息差蓄压，拒绝扁平反派与过早亮底】**
   - 对立各方均立足自身现实利害、体面顾虑与生存底线展开有策略梯度的正面交锋：一方受挫后立即止损变招（遮掩切割、借规反咬、施压软肋或逼迫交易），严禁写成盲目叫嚣或违背自利原则主动自曝隐情的幼稚靶子。
   - **护住信息差与多轮试探空间**：严禁角色在局部筹码已够用时过早抖落隐蔽身份或终极底牌；通过半真半假的试探、局部验证与反制拉扯维持悬念张力。

3. **【时空·生理·客体状态守恒与角色唯一指代锚定】**
   - **物理与生理连续闭环**：跨场跨集的时间先后顺序、空间移动物理耗时、财物物件的数量归属与物理属性，以及角色的伤病、体能与受困状态必须严格连续守恒，杜绝时间倒流错位、跨空间瞬移、生理状态跳变或凭空机械降神。
   - **登场锚定与唯一标识恒定**：角色首次登场须借具体处境动作、符合亲疏身份的称呼互动（必要时辅以极简 `[画面文字]`）清晰立住身份定位；全剧严格锁定每位角色唯一的说话人标识（`角色名`），严禁中途改名、头衔混用或退化为泛化标签。
   - **严守有限知情与记忆连续**：角色只能基于亲历所见或已获知渠道反应推断，既不开天眼道破未获知事实，也不对已获知信息发生记忆断层；场内旁人绝对听不见 `[VO]`。

4. **【高烈度未决危机卡点与跨集逐秒咬合】**
   - 每场戏结束须产生筹码、权限、关系或认知态势的不可逆变化；**集尾 `【本集完】` 必须精准切在危机迎面砸落、关键动作半途骤停、突发可信反制浮现或高代价两难抉择逼到眼前的最高压临界点**，相邻集首尾逐秒咬合，严禁落在平缓过渡转场、事后总结或空洞放狠话表态上。

5. **【情境动机驱动与潜台词留白，彻底去除 `[VO]` 解说化】**
   - **开口紧扣当下目的与生活常理**：角色说话只为撬动眼前结果、试探虚实或遮掩退路，严禁背离交际常理向熟人播报已知前史、朗读规则机制或直白宣露隐秘算计；次要与旁观角色只按自身私心利害本能反应，绝不充当整齐划一解说局势的传声筒。
   - **严控 `[VO]` 边界**：视觉动作交由 `△` 呈现，言外之意藏进动作与半截话锋；`[VO]` 仅在表面隐忍伪装、单靠画面与对白无法传递关键表里反差时以极短口语闪念点破，**严禁将 `[VO]` 写成工整的局势总结、战术步骤解说或点题宣誓口号**，画面与潜台词到位处直接留白。

6. **【底层口语造句与鲜活个体声纹，拒绝机械对称与电报压缩】**
   - **从底层语法建立口语毛边**：用话题前置、松散接茬、自然短促应答、打断迟疑与参差气口组织台词，打破等长双分句、三分句的机械对称，戒除滥用 `——`、`……` 充当人工停顿符号；严禁在规整书面语法表面生硬镶嵌地域俗语、时代语汇或专业术语。
   - **忌过度删减虚词造成机械压缩**：剥离冗长书面定语的同时，保留活人说话必需的代词、连词、介词与自然语气助词，确保上口顺畅，杜绝干瘪生硬的电报腔。
   - **拉开个体声纹光谱**：依据角色心智阶段、社会阅历、性格底色及实时生理状态（剧痛、喘息、力竭、慌乱或从容）生成差异化语态，消除全员共用的句式模板、起手口癖与紧绷舞台腔。

## 二、标准剧本交付格式

```markdown
# 第N集　集名
**预估时长**：约XXX秒

## N-1　内/外　具体场景　日/夜
**人物**：本场人物（使用全剧唯一标准角色名）

[画面文字] 极简时间地点或首次登场身份锚定提示（选填）
△ 简洁可拍的具体动作、物件交互与有对象的反应（不写机位术语与抽象心理总结）。
角色名：贴合个体声纹与当下生理处境、保留自然口语肌理与潜台词的鲜活台词。
[VO] 角色名：极短反差闪念（选填，旁人听不见，禁局势总结、算计解说与口号点题）。

【本集完】
```

完结标记 `【本集完】` 后不附任何备注，下一集另起 `# 第N集`。
