# Stage 2：大纲与立项锁 → 高张力连载分集剧本（`stage2_episodes.md`）

依据《Stage 0 立项锁》、全剧大纲及前序剧集，创作 {batch_range} 完整分集剧本。参考 `episode-craft.md`、`anti-patterns.md` 与 `dialogue-voice.md`。直接输出 Markdown 正文，不附任何解释或自评。

## 一、剧本创作五大通用铁律

1. **【可见筹码反差与场内目的驱动，严禁空喊口号与硬报大纲！】**
   - 严格落实立项锁中的人物身份、关系态势与本集实质变局：把戏剧张力落在**可见的具体物件、实际损失、行动选择与待遇反差**上，绝不靠角色嘴上空喊概念口号或替作者总结人性哲理！
   - **对手立场自洽**：任何阻力方都站在自身认定的利益、体面或规则立场上顺理成章施压、推诿或衡量得失，严禁写成叉腰自认作恶的低幼工具人。
   - **开口必为当下**：角色说话只为争取眼前结果、试探底细或遮掩责任，**严禁充当“大纲背景播报员”**（不在寒暄或争执中生硬背诵前情简历、远期规划或双方已知设定）。

2. **【单场压强递进 & 跨集实质换挡，拒绝快进与原地复读！】**
   - 单集（约 110～150 秒，铺展 1～3 个自然衔接场景，约 24～34 句对话+心声）只扎实演透大纲规定的 1～2 个实质交锋回合，绝不八倍速跨阶段抢跑；
   - **严禁同水平面复读吵架**：每一场戏结束时，双方的筹码、处境、权限或关系必须发生实质改变；上一场已经摊牌定性的分歧，下一场必须切入实际后果或新筹码验证，绝不原班人马原地重吵同一车轱辘话；
   - **集尾卡在结果未决、压强最紧绷的瞬间**，相邻集首尾紧密咬合。

3. **【自然称谓落地与知情边界严密】**
   - 关键角色首次登场时，借符合亲疏尊卑的真实日常称呼（如爸/妈/娘/叔/哥/师父/某总）配合眼前具体事由自然带出关系，严禁“我娘某氏”等户口本腔、不在亲熟对话中句句硬缀全名、不在日常或气头上生硬背诵文件书面全称。
   - 严格区分观众视角与各角色当下的知情边界：无证据来源绝不“开天眼”精准报出隐秘细节；场内旁人绝对听不见 `[VO]`，关键交锋由主角有声开口主导。

4. **【阶层体量、实物台账与物理尺度守恒】**
   - 时间线、空间动线与财务收支前后自洽，无几十秒跨空间瞬移、无凭空预制奇葩夺产文书；包袱、抽屉或异宝只取已存入或合理携有之物；排场严合家境阶层，伤病与武力合乎物理常识。

5. **【音画分工明确 & 贴合角色身份的活人真口语】**
   - 视觉神态、异象与环境声响交由 `△` 呈现，严禁角色用台词充当画面解说员；`[VO]` 贵精不贵多（每集 0～2 句极短反差心声），动作与潜台词已说明白处直接留白。
   - 台词严格贴合角色所处**时代、地域、阶层与年龄**，自然形成话咬话交锋与长短呼吸差，严禁跨阶层乱套方言俚语，近现代剧严禁串入“拿乔、置喙、时辰、拂袖”等古言宅斗词。

## 二、标准剧本交付格式

```markdown
# 第N集　集名
**预估时长**：约XXX秒

## N-1　内/外　具体场景　日/夜
**人物**：本场人物

[画面文字] 极简时间地点或人物身份提示（选填）
△ 简洁可拍的动作与有对象的反应（不写机位术语与抽象心理总结）。
角色名：贴合身份语境、服务当下目的的鲜活口语。
[VO] 角色名：极短反差心声（选填，旁人听不见，禁报账与复述画面）。

【本集完】
```

完结标记 `【本集完】` 后不附任何备注，下一集另起 `# 第N集`。
