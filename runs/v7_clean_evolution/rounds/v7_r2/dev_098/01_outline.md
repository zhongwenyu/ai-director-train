# 《死不离婚：锁死家产送她入狱》全剧故事引擎与分集大纲

## 一、项目定位与原生张力引擎
- **定位与规模**：现代都市婚姻博弈与设局反杀剧｜共45集（8阶段闭环）。
- **原生支点**：破除“捉奸起诉离婚仍须依法分走数千万共同财产”死局，确立**“死不离婚+婚内合规锁死现金流与资产使用权”**引擎。凭实控人对经营还债、职务任免与房产长租的合法权限断敌粮草，逼贪急对手越界踩实敲诈勒索、虚假诉讼与盗窃侵占，达成**零分产离婚+送入监狱**终局。
- **追更承诺**：逼离抢产的林婉、赵凯撞上陈建国与沈律“关门断粮、引敌入瓮”反猎杀，恶人每次变招皆为刑期加码。

## 二、连续性台账、唯一指代锚定表与信息差博弈图谱
1. **唯一标准角色称谓与登场锚定**（全剧恒定指代，严禁混用）：
- **陈建国**（42岁，建国机械实控人）：沉稳守法、压怒语缓；第1集回别墅撞破奸情、攥碎茶杯割伤右虎口登场。
- **林婉**（36岁，陈建国法定妻、挂名副总）：虚荣尖利；第1集在别墅衣衫不整甩分产协议登场。
- **赵凯**（34岁，宏远采购总监，林婉情夫）：油滑阴鸷；第1集捏续约函登门挑衅登场。
- **沈律**（35岁，律所合伙人，专案顾问）：腹黑清冷、卡死刑民要件；第1集末拦离婚诉状登场。
- **周副总**（40岁，财务副总）：惜身摇摆，受赵凯旧账胁迫后反水；第5集查门禁异常慌乱登场。
- **孙行长**（48岁，城商行授信负责人）：严守风控；第3集进厂核3000万授信登场。
- **韩董**（52岁，宏远董事长）：唯品质论；第6集临检测室监督盲测登场。
- **陆总**（45岁，盛泰精密实控人）：阴狠同业死敌；第7集助赵凯造空壳假债登场。
2. **时空生理与核心客体台账**：1～12集咬合**D1至D12**；陈建国右虎口伤伴胃痉挛贯串D1～D4，周副总D9夜护盘左臂挫伤挂三角巾贯串D10～D12。资产流转：**1800万共管活期**（D2九点合规清偿到期机床尾款归零）→**名下江景别墅与3张副卡**（D2停卡、别墅备案长租抵技工宿舍）→**3000万授信与续约**（D3停、D4复）→**涉刑标的**（500万勒索未遂→600万假婚债及挪用货款→二号仓800万进口钢坯）。
3. **信息差与策略梯度**：1～6集林婉、赵凯误判陈建国怕丢单必割肉，不知活钱已空且设取证局，受挫借“家事纠纷”躲刑拘转投黑料卡授信；7～12集升级“假债冻卡+盗仓填坑”，不知沈律借听证穿透赃款并布控跨红线抓捕离间局。

## 三、全剧分阶段主线脉络（共45集，8大阶段闭环）
- **阶段一（1～6集·拒离断粮与首轮勒索）**：林婉偕赵凯逼分产；陈建国采沈律计拒离锁空1800万、停卡腾房。两人勒索500万凭配偶委托书躲刑拘并投黑料停贷；陈建国策反周副总盲测翻盘，赵凯被宏远开除退守城中村。
- **阶段二（7～12集·虚假婚债与盗仓裂变）**：赵凯投陆总造600万假婚债冻卡；沈律逼补流水诱其挪用供应商货款，听证穿透解冻并将假债反锁林婉。赵凯骗林婉夜盗800万钢坯嫁祸被抓，林婉反水，赵凯携陆总拿倒签《专利排他书》封产线。
- **阶段三（13～18集·拆解假授权与死绑互咬）**：陈建国暂缓报捕，策反林婉带录音笔密会赵凯；林婉录造假实锤却图两头索财，沈律凭公章色差与双取证击碎排他书。陆总追讨600万垫资，林婉与赵凯互殴决裂却因共背巨债绑死作恶。
- **阶段四（19～24集·苦肉诬告与自残社死）**：赵凯教林婉回厂自残申保护令起诉离婚，递《800万私了书》。陈建国凭云端监控自证，待其坐实要挟后放出赵凯打伤林婉造假的行车记录；保护令驳回，林婉谎报警情拘留十日社死。
- **阶段五（25～30集·买断假饵与洗钱截胡）**：林婉联手陆总买通旧人伪造“婚前出资”阻扩产。沈律抛“1500万共管买断离婚”假饵；两人欲甩陆总独吞，勾结钱庄交割夜掉包U盾强划监管金，陈建国联动风控网安锁死轨迹端掉洗钱链。
- **阶段六（31～36集·毁机勒索与批捕收网）**：两人盗宏远招标底价并毁母机芯片要挟，限两小时打1000万至不记名户并签免责离婚书。陈建国启隔离备机稳住韩董开标，赴废仓以编码本票诱两人坐实三轮勒索主谋与非法占有故意，刑警破门批捕。
- **阶段七（37～41集·狱中互攀与黑手覆灭）**：陆总诱赵凯推全责给林婉并做空供应链；沈律补交赵凯私吞林婉积蓄养情人流水，林婉崩溃检举赵凯与陆总窃密、串标与假诉讼全案，陆总被经侦带走，建国机械揽宏远亿元长单。
- **阶段八（42～45集·重刑宣判与零分产终局）**：刑庭林婉求谅解遭拒；赵凯判十二年、林婉七年并处罚金。沈律提民事离婚，凭重大过错、毁损转移财产及罚金抵扣，法院判全部家产归陈建国，林婉零分产入狱。

## 四、逐集连载细纲（第1～12集｜①承接与知情边界 ②具象行动与拉扯 ③不可逆实质变局 ④危机卡点与首秒咬合）

### 第1集：捉奸遭逼宫，毒计破死局
- ①承接：D1傍晚，陈建国回江景别墅取续约章，未知妻林婉正与赵凯偷情并预谋逼离。
- ②交锋：陈建国撞破奸情，赵凯反拿宏远续约函顶他胸口登门挑衅，林婉甩协议逼分半数家产否则断单。陈建国盯婚照忍恨压胃痛、攥碎茶杯割伤右虎口，连夜询三律所皆叹起诉仍分走数千万；撕状绝望时沈律拦路。
- ③变局：婚姻崩裂，陈建国弃常规诉讼与沈律结盟。
- ④卡点：沈律盯他渗血虎口：“谁让你离婚了？死不离婚，才能把他们一分不留送进大牢！”下集首秒接D2十点林婉开香槟等签字。

### 第2集：撕协议拒离，锁资遭黑料要挟
- ①承接：D2十点，林婉与赵凯备香槟等签字，不知九点陈建国已合规清空共管活期。
- ②交锋：陈建国缠虎口纱布携沈律推门，撕碎协议宣布“深爱妻子绝不离婚”，拍出1800万到期机床还款回单与林婉副总罢免书。林婉见余额归零失控；赵凯稳住阵脚，亮偷拍剪辑的排污次品伪证索要500万封口费。
- ③变局：陈建国锁死1800万活钱夺回人事权；升级为持伪证敲诈。
- ④卡点：赵凯拿手机贴他鼻尖：“明早孙行长尽调，不给500万让你连厂带人赔光！”下集首秒接林婉携赵凯进车行刷卡。

### 第3集：停卡腾房断粮，闯司勒索入瓮
- ①承接：D2下午，两人自恃仍有副卡与别墅，不知生活线已断且孙行长正进厂尽调。
- ②交锋：林婉提豪车刷三副卡皆止付，回别墅撞见十名技工搬高低床——领班亮三年宿舍长租备案合同请两人出门。断粮的两人趁孙行长茶歇闯董事长室堵门逼转500万；沈律假劝和，诱赵凯亲口坐实勒索私人款要件并视听固证。
- ③变局：林婉失卡失房彻底断粮；两人踩实当面强索财物取证闭环。
- ④卡点：赵凯抓茶歇室门把倒数，陈建国右指悬转账键、左指抵桌下固证报警键！下集首秒接按落报警弹1元风控锁。

### 第4集：家事挡箭脱壳，黑料突袭停贷
- ①承接：D2傍晚警笛抵楼，陈建国已锁转账，不知赵凯进门前拉林婉预留避罪文书。
- ②交锋：民警进门，林婉腿软欲招，赵凯暗掐她腕亮林婉预签《配偶财产代收委托书》狡辩讨家务钱。因婚姻存续交叉，警方仅做训诫笔录列待查未刑拘；沈律点破须剥离配偶讨债壳方能钉死共犯。当夜赵凯将黑料投孙行长与宏远邮箱。
- ③变局：对手借未离婚身份躲过首轮刑拘留案底；黑料引爆停贷解约危机。
- ④卡点：手机同弹孙行长暂停3000万放款与宏远24小时解约函！下集首秒接D3晨陈建国封检测室查门禁。

### 第5集：封厂揪内鬼，恩威攻心策反
- ①承接：D3距解约死线剩20小时，陈建国吞胃药顶上，断定赵凯必有内鬼放行。
- ②交锋：筛出监控检修15分钟内周副总刷卡记录，叫入留样室摆倒影铁证。周副总死咬盘点，沈律指商业诋毁刑责，陈建国拍出当年垫其母手术费旧单攻心；周副总防线崩塌跪招因虚开发票把柄被迫放赵凯进室摆拍废件。
- ③变局：策反周副总固证，确认双锁柜原始留样完好。
- ④卡点：赵凯突来电逼周副总半小时内强酸毁原始留样否则举报涉税！下集首秒接陈建国按住他颤手示意免提诱敌。

### 第6集：盲测当众打脸，开除退守城中村
- ①承接：D4九点半，周副总昨夜假复已毁样，赵凯信真随韩董、孙行长进检测室问罪。
- ②交锋：赵凯举残件逼废约抽贷，林婉厂门直播哭诉。待赵凯签军令状，陈建国取原始铅封留样盲测，巨幕投出残件底层钢印属盛泰精密废品；周副总出列放赵凯指使毁证录音。韩董当场开除赵凯拉黑，孙行长签放3000万，林婉直播被封逃离。
- ③变局：授信续约落袋；赵凯丢职携林婉搬入城中村出租屋。
- ④卡点：林婉摔碗痛骂，赵凯拨陆总电话摊空白婚内借据：“用夫妻共同债务冻死他！”下集首秒接陈建国收冻卡裁定。

### 第7集：假债冻卡反扑，设饵逼补流水
- ①承接：D6上午，赵凯借陆总空壳公司与林婉配偶身份伪造600万借条冻陈建国卡；陈建国暂不知陆总入局。
- ②交锋：林婉携赵凯堵大堂甩裁定逼割让千万换解冻。陈建国识破补签笔迹欲报警，沈律按住他——无流水借条难定重罪，反交《资金交付真实性审查申请》，逼对方72小时补交银行真实流水否则移送虚假诉讼。
- ③变局：陈建国卡暂冻，转入司法假债战；架起72小时补流水火坑。
- ④卡点：陆总拒借真钱过桥，赵凯盯未注销的宏远旧供应商结算群起歹念！下集首秒接D7赵凯冒余威截留承兑款。

### 第8集：挪赃款造闭环，抛诱饵账引蛇
- ①承接：D7至D8距听证剩48小时，赵凯截留原供应商600万货款倒手造假流水，唯缺建国机械往来账套科目。
- ②交锋：赵凯夜堵周副总逼偷往来明细。周副总密报，陈建国与沈律连夜造微缩暗记虚构科目诱饵账令其拍发；赵凯与林婉按虚构科目补齐协议上传法院系统坐实举证。
- ③变局：赵凯背上挪用600万真窟窿，上传伪证完成虚假诉讼既遂。
- ④卡点：D9傍晚谈判前，赵凯放大账页核税号惊觉系陷阱，而林婉已关机进包厢见陈建国！下集首秒接赵凯掉头扑周副总家。

### 第9集：茶楼诱签死契，深夜夺盘肉搏
- ①承接：D9晚七点半，林婉关机防干扰不知账页有诈；陈建国捂胃装焦灼诱她自缚。
- ②交锋：林婉逼质押30%股权，陈建国示弱求同签《债权真实性及双倍连带赔偿函》；林婉疑虑验完草案后贪念压倒戒心按指印。同时赵凯带打手踹周副总家门，扭伤其左臂抢加密U盘欲毁证。
- ③变局：林婉签死假债连带契；升级暴力毁证，周副总左臂挫伤。
- ④卡点：赵凯踩周副总举铁锤砸U盘一瞬，陈建国带安保撞门强光直射！下集首秒接踢落铁锤夺盘、赵凯翻窗逃。

### 第10集：当庭穿透赃款，假债反锁恶妻
- ①承接：D10十点开庭，周副总挂三角巾出庭；赵凯躲街对面车内观望，以为过桥款查不穿。
- ②交锋：对方亮回单求续冻，沈律连抛诱饵暗记比对、周副总抢盘证言、韩董协查穿透600万系赵凯前天挪用的供应商赃款！法官当庭解冻移送假诉讼；空壳公司自保凭赔偿函反手向林婉个人追索600万。
- ③变局：账户解冻完胜；600万假债反锁林婉，供应商限次日午还钱否则报案。
- ④卡点：供应商围车追债，赵凯死攥崩溃的林婉盯她包里旧副总门禁卡：“今晚台风偷二号仓800万钢坯卖陆总填坑！”下集首秒接货车滑入后门。

### 第11集：雨夜盗仓嫁祸，跨红线合围弃逃
- ①承接：D11台风夜，两人不知旧门禁早设静默报警且每根合金钢坯嵌定位芯片。
- ②交锋：林婉刷开二号仓装运800万钢坯；赵凯借手沾油哄心慌的林婉在出库单与废料收据独签盖私章，暗销同车记录。陈建国忍冲动依沈律卡死货车驶出厂界红线既遂一瞬亮灯三重卡封路！赵凯狠推林婉倒泥水锁门翻渠独逃。
- ③变局：钢坯零损截回；盗窃既遂与赵凯推林婉顶罪铁证成立，同盟崩裂。
- ④卡点：暴雨灯下沈律将独签阴阳单拍林婉泥脸：“八百万十年起步，赵凯把你卖净了！”下集首秒接林婉抓烂单据嘶吼供出交割仓。

### 第12集：攻心同盟崩裂，专利禁令绝命反扑
- ①承接：D11深夜至D12晨，林婉困值班室崩防；逃亡的赵凯知窝点暴露，携底牌投陆总。
- ②交锋：陈建国平静放赵凯推她慢镜与单人离境机票记录，林婉信仰尽碎，签《指认主谋悔过书》求缓送警并供废船厂交割点。清晨扑空船厂，急电传来：赵凯竟随陆总与执行员杀到厂门，亮林婉任副总时偷盖真章倒签的《核心专利排他书》，索赔2000万并查封产线！
- ③变局：断粮破债撕裂狗男女承诺兑现，林婉成受控棋子；跃迁专利生死与团伙清算战。
- ④卡点：封条逼近车间，赵凯躲陆总后逼24小时割产销监控，陈建国身后车窗降下——林婉正怨毒死盯赵凯！下集首秒接接传票启动反间录音局。
