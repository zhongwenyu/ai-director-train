# 《你说讲规矩，断交你急啥》全剧故事引擎与逐级变局分集大纲

## 一、项目定位与原生张力引擎

- **题材语境与篇幅规模**：现代北方农村现实伦理剧｜45集×每集约2分钟（8大变局阶段，首轮付费卡点落于第10～12集）。熟人乡情与基层规范执法交织，大棚菜农高度仰仗农机运力与深井水源维系生计。
- **原生独特戏剧支点**：“你拿规矩砸碎十年恩情，我便守死规矩断你全部白嫖”。全剧摒弃悬浮身份反转，紧扣农村硬核生产资料（厢式货车、深井主泵、田埂地界、陈年借据）与基层实证规则展开博弈。
- **核心矛盾与情绪承诺**：厚道老农`赵建国`“坦荡认罚守规、寸步不再让利”的清醒底线，与双标邻居`孙有才`一家“挥舞法条背刺恩人、又妄图照旧吸血”的贪婪正面碰撞。平行铺设准法学生`赵磊`（以法护善、实证维权）与法学毕业生`孙倩`（教条双标、滥诉立威）的镜像对照，让对手每一次恶意举报都化作精准砸断自家生计的回旋镖，持续兑现极致解气感。

## 三、全剧分阶段主线脉络（共 45 集 / 8 阶段）

- **阶段一（第1～5集）：两千罚单碎旧恩，当众断交断运力**
  - **困局与交锋**：`赵建国`帮孙家卸肥清秆遭`孙倩`举报顶格罚两千，旧恩被辱；`赵建国`认罚当众断交，次日锁车拒运鲜菜、拒载`孙倩`。同村避嫌拒借车，孙家鲜菜暴晒贱卖，`孙倩`偷拍油钱分摊画面举报黑车拦路逼宫。
  - **不可逆变局**：十年无偿托举彻底终结，孙家在村内陷入首轮孤立，双方转入执法核查正面交锋。
- **阶段二（第6～9集）：互助油票证清白，锯管改道断水源**
  - **困局与交锋**：`赵建国`亮出村委备案互助协议与加油税票自证清白；`孙有才`强开农用三轮超载抢运被交警扣车罚款、雇社会车遭坐地起价。`孙倩`夜测地界抓出赵家水管越界30公分，钉桩逼赔钱或免费拉菜，`赵建国`当场挥镐锯管、自费绕荒坡重铺并拆走分水三通阀。
  - **不可逆变局**：孙家丧失运力后又亲手斩断免费深井水源，伏旱危机悬顶。
- **阶段三（第10～14集）：伏旱烧泵求借难，夜半偷水抓现行**
  - **困局与交锋**：橙色伏旱突袭，孙家浅井抽干烧毁水泵，求借全村无门，高价租泵雇水车仍难救干裂菜棚；`刘翠花`躺门前装晕绑架被`赵磊`亮急救旧单拆穿。`孙有才`深夜撬阀偷水被父子抓现行，经派出所训诫赔阀立字据，头茬菜枯死过半。
  - **不可逆变局**：孙家现金流重创，从占便宜方沦为村内失信戒备对象。
- **阶段四（第15～20集）：陈年借据亮明牌，统收质检封退路**
  - **困局与交锋**：孙家资金链紧绷公然赖掉3800元陈欠；`赵建国`亮出`周大伟`见证的学费收条与医院押金单正式催告。抢收尾期孙家将裂果混装试图蹭合作社统收车，`赵建国`严按客商农残与品相规矩当场验退，保住全村合作社招牌。
  - **不可逆变局**：债务事实钉死，孙家试图绑架集体利益翻盘的路径被彻底封堵。
- **阶段五（第21～26集）：普法材料露马脚，乡邻联名断赊账**
  - **困局与交锋**：`孙倩`将举报邻居包装成“普法先进个人”申报镇司法所留用，却因连续两次无效恶意举报触发执法队异常回访；五户互助乡亲联名出具实情证明，农资店老板怕孙家赖账当众取消其赊购资格。
  - **不可逆变局**：`孙倩`实习留用亮红灯，孙家连化肥农药都须现钱结算。
- **阶段六（第27～32集）：宗族施压图翻盘，双单并列碎伪善**
  - **困局与交锋**：孙家搬出族老摆和解酒施压“得饶人处且饶人”，暗藏免债通水条款；`赵建国`将两千元秸秆罚单与当年闯红灯记12分重考单并列拍在桌上，`林淑芬`逐笔算清十年免费油费工时，族老羞愧离席，孙家内部为破财爆发激烈内讧。
  - **不可逆变局**：宗族人情牌彻底失效，孙家陷入内外众叛亲离。
- **阶段七（第33～39集）：巨石堵路逼签字，准法学生取铁证**
  - **困局与交锋**：尾茬菜面临烂棚绝境，`孙有才`铤而走险用拖拉机拉巨石堵死机耕道唯一出口，躺车前讹诈“延误费”逼签免费运菜协议；`赵建国`护住妻儿绝不动手，`赵磊`启用双机位录像、激光测距固定侵占通道事实，并同步记录全车受阻鲜菜折损差价。
  - **不可逆变局**：冲突从邻里纠纷升级为违法阻断交通与强迫交易铁案。
- **阶段八（第40～45集）：规则亮剑清算毕，堂堂正正踏征途**
  - **困局与交锋**：派出所、执法队与司法所联合到场，`孙倩`强辩“相邻通行争议”试图脱罪，`赵磊`条分缕析援引治安管理处罚与民事排除妨害、债权清偿规则呈交完整证据包；`孙有才`被依法行政拘留并强制清障赔付鲜菜损失、结清3800元陈欠，`孙倩`失掉实习鉴定灰溜溜离村。
  - **不可逆变局**：双标恶邻彻底付出代价，`赵建国`开着干净敞亮的货车送`赵磊`前往政法大学报到。

## 四、逐集连载细纲（第 1～12 集）

### 第1集：恩将仇报·顶格罚单引爆
- **① 承接态势、物理状态与知情边界**：盛夏D1傍晚，`赵建国`刚无偿帮`孙有才`卸完十袋复合肥扭伤左腰，顺手将两家地界处带病虫的玉米残秆拢堆点着除虫；`赵建国`视孙家如自家亲邻，浑然不知刚回村的`孙倩`正急于抓现行攒普法实习政绩。
- **② 具象行动与双边拉扯回合**：`孙倩`领着`陈正平`直奔地头，指着残烟背诵大气污染防治法条款，`周大伟`赶来求情念初犯从轻，`孙倩`却当场掏手机威胁拨打上级督察热线施压，`陈正平`依规开出两千元顶格罚单。`林淑芬`赶来扶住忍痛的丈夫，气极重提十年前带头凑1800元供`孙倩`读书、三年前`赵建国`半夜连闯红灯送`刘翠花`急救心梗的旧恩；`孙有才`缩脖装傻，`刘翠花`与`孙倩`却理直气壮回怼：“救人是情分，违法是本分，讲规矩就别拿旧恩道德绑架！”
- **③ 本集不可逆实质变局**：十年乡邻温情被两千元顶格罚单当众砸碎，孙家“用完即弃、拿规矩背刺恩人”的双标嘴脸彻底暴露。
- **④ 高烈度危机钩子与下集首秒咬合点**：围观乡亲一片哗然，`孙有才`还伸手去拍`赵建国`肩膀劝他“交钱消灾明早接着帮拉菜”，`赵建国`猛地格开他的手，攥紧那张两千元罚单当众沉声开口——切集（下集首秒紧接`赵建国`震彻地头的断交宣言）。

### 第2集：当众断交·清晨堵门碰壁
- **① 承接态势、物理状态与知情边界**：紧咬上集末秒地头对峙，`赵建国`左腰渗汗、手攥罚单；孙家三人仍笃定老实人抹不开面子，以为风头一过照旧能白使唤他。
- **② 具象行动与双边拉扯回合**：`赵建国`当着`陈正平`与全村人面掏手机扫码缴清两千元罚款，抓起铁锹铲土彻底覆灭残灰完成整改，随即钉截铁宣布：“规矩我认！从今往后咱两家恩断义绝，全按规矩办，谁也别占谁一分便宜！”孙家老小嗤之以鼻，回院还在盘算明早头茬西红柿抢市。D2清晨五点，`孙有才`照旧推着满三轮带露鲜菜堵到赵家院门，熟稔拍打货车厢板催促：“建国哥快开门装车，晚了赶不上镇集早市头价！”
- **③ 本集不可逆实质变局**：`赵建国`完成合规认罚与当众关系切割，孙家从“受惠邻里”正式变为无任何帮衬义务的外人。
- **④ 高烈度危机钩子与下集首秒咬合点**：`赵建国`贴着腰膏走出院门，将自家菜筐搬进车厢后，当着抬筐欲塞的`孙有才`面，“咔哒”一声拉下后厢铁门插死栓锁，冷脸横身挡在车尾回绝——切集（下集首秒紧接`孙有才`伸手硬拽车栓遭拒）。

### 第3集：断供兑现·全村避嫌孤立
- **① 承接态势、物理状态与知情边界**：紧接D2清晨五点零五分赵家门前，`赵建国`锁死后厢；`孙有才`与刚拎包出门的`孙倩`仍以为稍加施压就能蹭上车。
- **② 具象行动与双边拉扯回合**：`孙有才`伸手拽栓被`赵建国`沉声喝止；`孙倩`走上前敲副驾车窗要求顺路搭她去镇司法所报到，`赵建国`直接按下中控落锁：“私人车辆不拉外客，按规矩请自便”，一脚油门径直驶离，首次兑现硬核运力断供！日头渐毒，满车西红柿暴晒发软，`孙有才`慌了神挨家敲门向村东三轮户借车，乡亲们昨日亲睹孙家恩将仇报罚恩人两千，怕沾上白眼狼惹祸上身，纷纷借口车坏关门落锁。`孙倩`顶着烈日步行误了报到点遭训，傍晚返村撞见村东户主往`赵建国`手里塞一张百元钞票。
- **③ 本集不可逆实质变局**：硬资源断供全面生效，孙家在村内遭遇实质性信用孤立，一车鲜菜滞留家中面临烂损。
- **④ 高烈度危机钩子与下集首秒咬合点**：村口槐树后，`孙倩`举起手机拉近焦距，清晰录下`赵建国`收下百元钞并卸空菜筐的画面，嘴角勾起冷笑低声道：“无证收费拉货，这回看你不求饶！”手指重重点下保存——切集（下集首秒紧接`孙倩`拿视频拦住父亲定计）。
