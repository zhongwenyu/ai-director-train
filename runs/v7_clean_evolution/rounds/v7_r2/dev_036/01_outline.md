# 《超售夺婴后，王牌女律掀翻航司》全剧故事引擎与分集大纲

## 一、项目定位与原生张力引擎

- **题材与篇幅**：现代都市现实维权爽剧｜共45集（8阶段闭环，每阶段4～7集）。
- **原生支点与追更承诺**：直击商业航司“奖励超售+专挑弱势旅客清退”黑幕，咬合双重错位——护9月幼女返乡的单亲妈妈对撞强抱幼婴致伤的乘务组与冒名假贵宾；上位者误把航空侵权顶流律所合伙人当软柿子捏，从买水军泼脏到天价封口步步踢中铁板。凭“锁原片→破伪证→拒封口→穿黑账→证据会掀桌→股价崩盘董事局互咬”的实证升级，兑现极致护女与掀翻黑幕链的解气爽感。
