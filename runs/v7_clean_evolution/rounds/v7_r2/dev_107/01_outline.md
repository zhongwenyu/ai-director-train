# 《穿成农家团宠，拒捡白眼狼男主》全剧故事引擎与分集大纲

## 一、项目定位与原生张力引擎

- **题材与篇幅**：七十年代末（1977年腊月起）农家穿书反套路爽剧，共 **48 集**（8 阶段×每阶段 5～6 集闭环，第 10 集为首轮付费兑现锚点）。
- **原生世界筹码**：缺衣少粮的红旗公社樟树湾大队，细粮现钱、过冬药材、集体工分、公社介绍信与熟人风评是决定生死的硬通货。
- **独特戏剧支点**：现代搏击好手穿成老林家大房团宠独女 **林穗穗**，开局拒走“救回重伤男主 **沈砚舟** 却被其与堂妹 **林娇娇** 吸血害死全家”的冤种剧情。她不靠嘴炮揭秘，而是顺着 **林娇娇** 贪慕城里富贵又不想掏钱的算计，用大队字据将重伤白眼狼与医药费死死砸进二房怀里。
- **核心矛盾与追更承诺**：二房与 **沈砚舟** 企图道德绑架老宅当免费血包，撞上 **林穗穗** 联手护短至亲铁腕断账、进山猎富。追更爽感源于“捧杀恶人接盘放血、锁死毒虫互相撕咬”的精准反制，以及老宅一家热腾吃肉、一致护犊的浓烈亲情对照。

### 2. 跨集时空、生理与核心客体连续台账
- **严密时间轴**：第1～2集（腊月初十午后至子夜）→ 第3集（腊月十一）→ 第4～5集（腊月十二至十四）→ 第6～10集（腊月十五至十九，严扣“五日赌债宽限期”与“三日采药比拼期”）→ 第11～12集（腊月二十至廿一）。
- **生理延续账**：**沈砚舟** 右腿骨折高烧（1～2集）→退烧拄拐（3～4集）→缺药化脓（5集）→滚水二次烫烂（10～11集）；**林老根** 寒冬心悸需老山参护脉（贯穿前12集）；**林建国** 第7～8集鹰嘴崖擦伤小腿休养；**林建业** 第9～10集右手掌被捕兽夹咬穿挂脖。
- **关键客体流转**：① **百年老山参**（1支，锁于 **周桂兰** 樟木匣，第2集夜盗未遂，第12集仅切参须交易、留主根护 **林老根**）；② **省城钢印信封与梅花表**（第1集 **林娇娇** 藏信封，第5集梅花表在委托行拆穿系铅块假芯，第12集查明信封系 **沈砚舟** 盗自省城机械厂表哥的空白公函）；③ **《独救独享字据》与《分宗断账契》**（第2、5集 **赵铁柱** 盖章，持续阻断二房转嫁债务）；④ **现钱账**（第3集 **林穗穗** 猎狍换28元与40斤粮票；第9集掌30元公社代购周转金）。

### 3. 信息差蓄压与策略梯度图谱
- **知情差锁控**：观众与 **林穗穗** 知晓 **沈砚舟** 实为欠债空壳知青且会恩将仇报，但 **林穗穗** 绝不提前说破，故意保留 **林娇娇** 的“省城少奶奶幻觉”以锁死二房放血；第5集假表爆雷后，**沈砚舟** 用真实的《病退返城申请表》画饼，利用沉没成本将 **林娇娇** 二次绑上贼船。
- **双边变招梯度**：二房与 **沈砚舟** 受挫后依次升级：雪坡讹诈→夜撬药匣→向市管会举报投机→匿名信卡政审→盗猎图毁药源→迷烟盗公款栽赃→滚水烫腿骗病退→弃女独逃反咬盗信。

## 三、全剧分阶段主线脉络（共 48 集 / 8 阶段）

1. **阶段一（第1～5集）：雪坡拒捡立铁契，断门清账掏空二房**
   - 困局与交锋：二房欲把重伤 **沈砚舟** 塞给老宅耗参养伤、自己独吞城里信物恩情。**林穗穗** 拒背黑锅，借 **赵铁柱** 立《独救独享字据》锁死二房接盘，夜擒偷参贼砌死隔院门，再凭合法猎证反杀 **林建业** 的市管会举报，逼签《分宗断账契》。
   - 不可逆结果与引子：老宅切清连坐风险并攒下猎肉现钱；二房嫁妆自留地赔光，**林娇娇** 典当梅花表拆穿铅块假芯，引来邻社债主堵门。
2. **阶段二（第6～10集）：假表爆雷毒虫绑死，山货代购与公款反杀**
   - 困局与交锋：债主逼讨五十块烂账，**沈砚舟** 抛出《病退返城申请表》诱 **林娇娇** 签连带担保。为夺公社代购员三十块预支金填债，两人先投匿名信卡政审，再雇外猎盗图抢采，落败后竟吹迷烟夜盗老宅公款企图栽赃 **林穗穗** 坐牢。
   - 不可逆结果与引子：**林穗穗** 盲摸辨药、绝壁救父、苦草坑敌夺下代购印章，捕兽夹夜擒 **林建业** 送办，逼二房卖猪保人并与 **沈砚舟** 首次狗咬狗撕裂；绝境 **沈砚舟** 狠心烫烂伤腿去公社医院骗病退章。
3. **阶段三（第11～16集）：骗伤作废独逃被截，省城寻参专班破局**
   - 困局与交锋：骨科旧冤家与 **林穗穗** 铁证拆穿二次烫伤，病退表作废。**沈砚舟** 夜逃被截，恰逢省城专班追查被盗厂办信封并重金寻参；**沈砚舟** 嫁祸 **林娇娇** 盗信，转头巴结县供销社干姐卡压老宅代购线。
   - 不可逆结果与引子：**林穗穗** 以冰涧新参签下省城特供约、切老参须换名医治好 **林老根** 寒疾，凭进销铁账扳倒县干姐；**沈砚舟** 罚下林场清淤。
4. **阶段四（第17～22集）：冬闲建坊添置新产，假孕夺方调包反噬**
   - 困局与交锋：**林穗穗** 办起大队药材烘烤坊盖新瓦房；**林娇娇** 伪造孕单逼婚，伙同 **沈砚舟** 往交货仓混入霉药企图让老宅赔穿。
   - 不可逆结果与引子：**林穗穗** 凭双仓留样锁死罪证，假孕当众败露，恶侣在公社互殴后被迫领证锁死泥潭。
5. **阶段五（第23～28集）：恢复高考准考证战，考场药理陷阱定胜负**
   - 困局与交锋：高考恢复，**沈砚舟** 哄 **林娇娇** 卖血供考，暗扣 **林穗穗** 政审表并偷抄复习笔记。
   - 不可逆结果与引子：**林穗穗** 携功勋证闯县招办夺回准考证，借反手留错的偏方笔记令偷抄的 **沈砚舟** 专业卷惨败落榜，**林穗穗** 夺省城中医大魁首。
6. **阶段六（第29～34集）：录取通知书截留案，极品亲家破院互撕**
   - 困局与交锋：**林娇娇** 勾结邮递表亲企图冒领通知书被当场拿获；省城沈父赶来，非但不是高干，反因贪墨被开除、欲搜刮二房填窟窿。
   - 不可逆结果与引子：两家极品打断鼻梁；**林穗穗** 摆升学席带爷奶风光进省城。
7. **阶段七（第35～42集）：省城药膳联营拓业，黑市假药嫁祸收网**
   - 困局与交锋：**林穗穗** 办国营联营药膳堂带富大房；流窜回城的 **沈砚舟** 与 **林娇娇** 造假参丸冒充林家字号坑人。
   - 不可逆结果与引子：**林穗穗** 联手药检工商端窝，**沈砚舟** 锁门弃妻顶罪，**林娇娇** 彻底黑化当庭举报其全部诈骗旧账。
8. **阶段八（第43～48集）：公审入狱恶果自食，团宠新宅红火终局**
   - 困局与交锋：**沈砚舟** 拒捕摔残双腿，法庭之上恶侣互咬揭穿所有底裤。
   - 不可逆结果与终局：二人获刑入劳改场互相折磨半生，二房孤苦悔恨；**林穗穗** 药堂挂牌，**林老根** 与 **周桂兰** 坐镇新宅阖家美满。

## 四、逐集连载细纲（第 1～12 集）

### 第 1 集：雪坡拒当冤大头，踹猪捧杀反遭赖
- **① 承接态势、物理状态与知情边界**：1977年腊月初十午后后山雪坡，**林穗穗** 穿书即面临原书死局节点；**沈砚舟** 右腿骨折昏迷雪窝；**林娇娇** 刚偷将 **沈砚舟** 怀里的省城钢印信封塞进自己内兜（以为捡到高干子弟），表面装柔弱哄 **林穗穗** 背人回老宅耗 **林老根** 的救命百年老山参；**林穗穗** 握原书先知与搏击好身手，深知救人必致全家惨死。
- **② 具象行动与双边拉扯回合**：**林穗穗** 后撤半步果断拒背，笑劝 **林娇娇** 自己背回二房享福。灌木丛突窜出百斤野山猪直扑二人，**林娇娇** 尖叫推 **林穗穗** 挡灾，**林穗穗** 旋身避让、凌空一记重侧踹正中野山猪耳根将其踹翻滚落山沟。未等 **林娇娇** 回神，**林穗穗** 冲山下路过社员高嗓报喜，盛赞 **林娇娇**“发誓倾尽二房家底独救落难知青”。闻讯跑来的 **王翠花** 一听要贴钱粮当场变脸。
- **③ 本集不可逆实质变局**：**林穗穗** 破除原书捡人死局并展露强悍武力，“二房救人”之名在社员众目睽睽下被钉上台面。
- **④ 高烈度危机钩子与下集首秒咬合点**：**王翠花** 眼珠一转与 **林娇娇** 对视，母女俩猛扑上前死死拽住 **林穗穗** 背篓带，当众哭嚎诬陷是 **林穗穗** 推 **沈砚舟** 下坡，逼老宅出山参赔医药费！（下集首秒紧咬 **王翠花** 指甲抓向 **林穗穗** 脸颊的瞬间）。

### 第 2 集：拧腕立威定铁契，夜半黑手撬药匣
- **① 承接态势、物理状态与知情边界**：雪坡众人围观，**王翠花** 扑抓讹诈，**沈砚舟** 冻得唇紫低吟；社员不明就里，**林娇娇** 死捂内兜信封盼老宅吃哑巴亏出钱。
- **② 具象行动与双边拉扯回合**：**林穗穗** 扣住 **王翠花** 手腕顺势单手反拧，将其干脆摔进厚雪堆。**林老根** 拄猎叉、**周桂兰** 抄枣木棍携扛扁担的 **林建国**、**陈秀英** 赶到，将 **林穗穗** 严护身后霸气骂退二房。**林建业** 赶来打官腔逼老宅顾全林家名声出参救人；**林穗穗** 当众点破 **林娇娇** 内兜鼓囊紧攥城里贵重信物、分明想独揽省城报恩，顺势请赶来的 **赵铁柱** 执笔立《独救独享字据》：人抬进二房独救，日后城里富贵归二房独享，老宅分文不沾。**林娇娇** 在“眼下掏药钱”与“放走省城金龟婿”间咬唇权衡，怕老宅抢功，狠心拽 **王翠花** 按下红手印。当夜 **孙半夏** 诊出 **沈砚舟** 高烧骨裂急需十五块药费与老参吊命，二房翻遍家底不舍掏钱。
- **③ 本集不可逆实质变局**：大队红章字据锁死二房独救责任与老宅免责权，**沈砚舟** 正式抬入二房西屋成为烫手血包。
- **④ 高烈度危机钩子与下集首秒咬合点**：风雪子夜，二房不肯出钱，**王翠花** 与 **林娇娇** 摸黑溜过两房月亮门，握着铁扁铲撬向 **周桂兰** 屋里锁百年老山参的樟木药匣！（下集首秒紧咬药匣铜锁崩开的脆响）。

### 第 3 集：瓮中擒贼封院门，猎狍包饺馋白狼
- **① 承接态势、物理状态与知情边界**：子夜老宅堂屋漆黑，铁铲刚别开铜锁，母女俩以为老宅熟睡；实则听觉敏锐的 **林穗穗** 早已醒来守在门后。
- **② 具象行动与双边拉扯回合**：**林穗穗** 疾步拧住 **王翠花** 胳膊、一脚勾倒 **林娇娇** 按在条案上，拉亮煤油灯人赃并获！**周桂兰** 震怒敲锣喊来 **赵铁柱**，不听二房哭求，当场由 **林建国** 搬青砖泥浆砌死两房互通的月亮门，**赵铁柱** 依规罚扣二房三百工分补老宅惊扰费。**孙半夏** 堵门催费，走投无路的 **王翠花** 只得含泪将 **林娇娇** 压箱底的两匹的确良嫁妆布低价典当，才凑齐十五块保命针药。次日 **林穗穗** 持 **林老根** 猎叉进冬山，循兽迹一叉猎回六十斤肥狍子，交公社收购站换回二十八块现钱与四十斤细粮票，当晚老宅包起白面鲜肉饺哄得爷奶眉开眼笑；一墙之隔苏醒的 **沈砚舟** 端着照见人影的糠菜粥当场摔碗发飙。
- **③ 本集不可逆实质变局**：两房物理隔院门彻底封死，二房工分与嫁妆大出血；老宅现钱细粮落袋，白莲与白眼狼首轮互相放血引爆。
- **④ 高烈度危机钩子与下集首秒咬合点**：**沈砚舟** 挟省城背景逼 **林娇娇** 弄肉弄参，嗅到墙外浓烈肉饺香后眼神阴鸷，撑起木拐指着老宅屋顶冷声下令明日上门“提点”大房！（下集首秒紧咬 **沈砚舟** 铁拐重重杵在老宅院门槛上）。
