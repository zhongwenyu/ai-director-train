# Stage 2：大纲与立项锁 → 高张力跨集连载分集剧本（`hit-short-drama v6`）

依据《Stage 0 立项锁》、全剧大纲及前序剧集，创作 {batch_range} 完整分集剧本。参考 `episode-craft.md`、`anti-patterns.md`、`dialogue-voice.md` 及同赛道真实爆款 3 集连载范本。直接输出 Markdown 正文，不附任何解释或自评。

## 一、写作五大通用铁律

1. **【忠于原创意与大纲设定，借具体微物与潜台词把人情冷暖写透！】**
   - 严格落实立项锁中的人物身份、关系网与本集核心回合，**严禁擅自删改核心设定，严禁把台词写成财务算账、法规背诵或舞台宣誓口号**（禁喊“十年苦活全是我干”“有我在谁也不配动你”“今日恩断义绝两清”等脸谱口号）！
   - **禁当背景播报员与相声式报账**：开场或寒暄严禁角色轮流背诵前情提要、人手部署或人生规划；争执翻旧账时严禁“对口相声式”一人上半句、另一人接下半句精准凑齐前史数据，只盯眼前最切肤的一桩实亏死磕。
   - **用可感微物与留白拉扯外化情绪**：把恩怨、屈辱、温情与反杀落在一碗吃食、一件旧物、一张单据、一次护短挡伤或落锁拒客等具体动作上；强势偏心者用冷淡敷衍或顺嘴甩锅代替咆哮，体面心机者用“话留半句、明劝暗踩”拱火，计谋点拨善用“正话反说”留白，绝不直白播报后续大纲走向。

2. **【沉浸连载厚度与真人口语呼吸：单集 1～2 个回合演足现场感】**
   - **1 集（约 110～150 秒）只扎实打透同一事件切面的 1～2 个实质交锋回合**，铺展 **2～3 个** 自然衔接的场景（或高张力重场戏），写足 **25～36 句** 有来有回、带潜台词的自然对白（台词总字数 **420～650 字**），绝不跨阶段抢跑。
   - **跨角色“话咬话”与降噪收火气**：打破全员 15 字工整双分句，严禁单人机械劈出“两字感叹词+二十字说明句”伪装短句！全集须有 **18%～30% 的 2～7 字跨人本能短句**（顶针反问、打断抢白、心虚结巴、惜字如金的冷淡应答）；**全集感叹号严控在 30% 以内**，冷硬施压与心寒决裂多用句号，杜绝全员扯嗓子喊话剧。
   - **集尾切在悬念最紧绷、结果尚未落地的瞬间**，相邻集首尾无缝承接。

3. **【生活化称谓与口语指代，严禁“户口本腔”与书面全称上嘴】**
   - 关键角色首次登场的前两轮对话内，用**符合亲疏尊卑的真实日常称呼**（如“妈/娘”“二叔”“哥”“师父”“林总”）配合当下争执，让裸看观众零障碍看懂关系。
   - **反非人话铁律**：**绝对禁止**管长辈叫“我娘某氏”、严禁亲熟之人对话句句硬缀全名、严禁对陌生人突兀自报家门履历，日常或气头上**严禁字正腔圆念出合同/文件/机构的书面全称**（改用“这张破纸/那份单子”等眼前指代）！角色全名仅借外人点名、单据特写或极简 `[画面文字]` 自然呈现。
   - 同一资产、底牌或把柄在不同角色口中的措辞必须严格贴合**该角色当下的知情边界**，严禁无信息来源地“开天眼”精准报出隐秘藏匿细节。

4. **【家境量级、实物台账与肉身物理尺度 100% 严密】**
   - **分时动机与时空常识自洽**：闪回/前世与当下的时间线、知情边界严格对齐；无跨空间几十秒瞬移，无随身预制奇葩夺产协议；大额付款或取证须有合理前置衔接。
   - **物资存取与贫富阶层守恒**：前场受冻哭穷，后场绝不能无故掏出私藏巨款厚衣；包袱、抽屉或储物异宝**只能取出前文已存入或合理携有的物件**，严禁凭空变道具；小门小户绝不凭空冒出家丁随从，断交后再生纠缠必有新利益诱因；异能或核心资源须守住可持续运转边界。
   - **伤病与武力尺度真实连贯**：抗寒、失血、骨伤须合乎人体极限；身手高强者若被弱者短暂拖住，必须写出护幼、顾忌伤人或暗算等具体掣肘，绝不忽强忽弱。

5. **【裸看零盲区、禁嘴替画面、音画互补 `[VO]` 与分层纯净声纹】**
   - **禁台词解说画面音效**：观众看不见 `**人物**` 设定行，场内旁人绝对听不见 `[VO]`；凡 `△` 动作或画面可见的神态、异象特效、场外动静，角色只做当下本能反应，**绝对禁止用台词播报舞台提示**（禁说“你手怎么抖成这样”“外头来人包围了”），关键交锋主角必须亲口有声主导。
   - **`[VO]` 贵精不贵直（每集 0～2 句）**：仅在“当众不便明说的反差冷念头”时极短点破（≤15字）；**凡动作与对话潜台词已足够传递动机或寒心时，直接靠动作留白，绝不叠解说型 `[VO]`、不背人物小传、不写工整总结句**。
   - **阶层年龄声纹与时代地域纯净度**：台词必须贴合角色身份、年龄与题材！**严禁**无视阶层给高管、海归精英、古装权贵刷“明儿/拾掇/爷俩/好嘞/喏”等北方胡同俚语；3～7岁幼童只说眼前直观冷暖小物的极短直白话（禁高频名字第三人称卖惨、禁卡通反派腔与成人书面词）；现代与年代剧**严禁**混入“时辰、一炷香、拿乔、置喙、打秋风、拂袖”等古言词，非北方背景禁混京腔东北儿化音。句均 **12～20 字**，单句 <= 48 字。

## 二、标准剧本交付格式

```markdown
# 第N集　集名
**预估时长**：约XXX秒

## N-1　内/外　具体场景　日/夜
**人物**：本场人物

[画面文字] 极简时间地点或首秀人物身份提示（选填）
△ 简洁可拍的动作与有对象的神态反应（不写镜头机位术语与抽象心理总结）。
角色名：贴合身份年龄、带潜台词与长短呼吸差的真人口语。
[VO] 角色名：极短反差心声（每集0～2句，旁人听不见，禁报账、禁解说画面与潜台词）。

【本集完】
```

完结标记 `【本集完】` 后不附任何备注，下一集另起 `# 第N集`。
