# Stage 2：大纲与立项锁 → 高张力跨集连载分集剧本（`hit-short-drama v6`）

依据《Stage 0 立项锁》、全剧大纲及前序剧集，创作 {batch_range} 完整分集剧本。参考 `episode-craft.md`、`anti-patterns.md`、`dialogue-voice.md` 及同赛道真实爆款 3 集连载范本。直接输出 Markdown 正文，不附任何解释或自评。

## 一、写作五大通用铁律

1. **【忠于原创意与大纲设定，借具体细节与潜台词把人情冷暖写透！】**
   - 严格落实立项锁中的人物身份、关系网与本集核心回合，**严禁擅自删改核心设定，严禁把台词写成大纲背景播报、相声式分工报旧账或舞台咆哮口号**（禁开场主仆/工友轮流背前情任务，禁喊“往后谁也不配让你跪/彻底断交”等宣誓词，禁样板戏恶霸脸谱词）！
   - **用可感微物、体面拉扯与正话反说外化张力**：把恩怨、屈辱、温情与反杀落在一口吃食、一件衣物、一张单据、一次护短或冷淡送客等具体动作细节上；写出强势方“冷淡甩锅/笃定主角服软”、心机方“斯文留半句暗戳痛处”、偏心长辈“不讲理耍横护短”的真实心理；献计点拨善用“正话反说”与留白，绝不像念大纲一样直白喂剧情走向。

2. **【沉浸连载厚度与错落呼吸：单集 1～2 个回合演足现场感，拒绝PPT快进】**
   - **1 集（约 110～150 秒）只扎实打透同一事件切面的 1～2 个实质交锋回合**，铺展 **2～3 个** 自然衔接的场景（或高张力重场戏），写足 **25～36 句** 有来有回、带潜台词的自然对白（台词总字数 **420～650 字**）。
   - **跨轮话咬话与长短句错落**：写出 **18%～30% 独立成轮的 1～7 字极短本能反应**（错愕反问、冷淡回绝、心虚结巴）与揪住对方刚说的词顶回去的**「话咬话」交锋**；彻底打破全员 15 字工整双分句，**严禁单句前硬挂感叹词伪装短句，严控感叹号泛滥（占比 ≤ 30%）**。
   - **做厚单场肌理，集尾紧绷切点**：严禁跨阶段抢跑；集尾切在悬念最紧绷、结果尚未落地的瞬间，相邻集首尾无缝承接。

3. **【生活化称谓与指代自然落地，严禁“户口本腔”报全名与念书面全称】**
   - 关键角色首次登场的前两轮对话内，用**符合亲疏尊卑的真实日常称呼**（如“妈/娘”“二叔”“哥”“师父”“林总”）配合当下具体争执，让裸看观众零障碍看懂关系。
   - **反非人话铁律**：**绝对禁止**管自己长辈叫“我娘某氏”、严禁亲熟之人吵架哄劝时句句硬缀全名、严禁对陌生人突兀自报姓名履历、**严禁气头上字正腔圆念冗长书面文件全称**（改用“那份废表/破草稿”等日常指代）！全名仅借外人点名、文书或极简 `[画面文字]` 呈现。
   - 同一特权、资产或底牌在不同角色口中的归属措辞，必须严格贴合**该说话人当下的认知视角**，绝不说漏嘴。

4. **【家境量级、知情边界与肉身物理尺度 100% 严密】**
   - **分时动机与反“开天眼”知情边界**：闪回/前世与当下时间线严格对齐；无跨空间瞬移，无随身预制奇葩协议；**严禁外人“开透视天眼”凭空精准报出未见过的暗格私账坐标**，拿捏把柄须源于亲眼撞见或合理经手，用半句敲打点到为止。
   - **物资存取与贫富阶层守恒**：前场受冻哭穷，后场绝不能无故掏出私藏巨款厚衣；包袱、抽屉或储物异宝**只能取出前文已存入或合理携有的物件**；小门小户不凭空冒家丁，断交再生纠缠必有新利益诱因。
   - **伤病与武力尺度真实连贯**：抗寒、失血、骨伤合乎人体极限；强者受制必有怀抱幼童、顾忌伤人或暗算等具体掣肘。

5. **【屏幕裸看零盲区、音画互补 `[VO]` 与分阶层纯净声纹】**
   - 观众看不见 `**人物**` 设定行，**场内旁人绝对听不见 `[VO]`**！关键交锋主角必须亲口有声主导；**严禁用角色台词替画面播报视觉特效变化或场外音效舞台提示**（改成活人即时惊呼）。
   - **`[VO]` 贵精不贵直（每集 0～2 句）**：仅在“不便明说的底牌算计或表里反差”时用 12 字内极短 `[VO]`；**严禁在 `[VO]` 背诵人物关系小传或工整对仗总结局势**，动作神态足够时直接留白。
   - **阶层年龄声纹与时代地域纯净度**：**严禁不分身份全员套用北方胡同俚语**（高冷精英/权贵克制得体，不混“明儿/拾掇/爷俩”等大爷腔；3～7岁幼童只说眼前直观感官短句，禁第三人称高频卖惨、成人词或卡通腔）；**严禁**混入“拿乔、作筏子、置喙、打秋风、不虞”等明清宅斗词；现代与年代剧禁古装词，非北方背景禁混京腔儿化音。句均 **12～22 字**，单句 <= 50 字。

## 二、标准剧本交付格式

```markdown
# 第N集　集名
**预估时长**：约XXX秒

## N-1　内/外　具体场景　日/夜
**人物**：本场人物

[画面文字] 极简时间地点或首秀人物身份提示（选填）
△ 简洁可拍的动作与有对象的神态反应（不写镜头机位术语与抽象心理总结）。
角色名：贴合身份、带潜台词与情绪张力的自然口语短句。
[VO] 角色名：极短反差心声（每集0～2句，旁人听不见，禁报账与复述画面）。

【本集完】
```

完结标记 `【本集完】` 后不附任何备注，下一集另起 `# 第N集`。
