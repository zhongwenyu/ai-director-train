# 《抽梯之日，苏总请签字》全剧故事引擎与分集大纲

## 一、项目定位

- **题材赛道**：男频都市情感 · 隐退创始人护女 · 抽梯追夫火葬场（赛道A核心引擎 + 商业股权与核心专利撤回实操）
- **篇幅规格**：60集 × 单集 1.8～2.5 分钟
- **核心一句话钩子**：百店庆功夜，自诩白手起家的总裁妻子纵容岳母拆掉亲生女儿的儿童房去讨好归国初恋父子，幕后创始人丈夫当晚带女儿搬离，按合同与章程一件件抽走她脚下的专利授权、供应链授信与表决权，看误把平台当本事的她在公开场合一步步踩空崩塌。
- **主要情绪承诺与尺度**：
  1. **护女不隔夜、绝不拿孩子试探底线**：开局女儿房间被拆、度假名额被夺，男主第1集当场止损带走女儿住进自有顶层公寓，绝不让女儿在储物间睡一晚，更不靠反复虐娃攒怒气；创意里的“前期压抑感”转化为苏晚晴一家对男主过往五年付出的傲慢抹杀、对抚养权与财产分割的嚣张卡脖子，以及男主在法律与商业规则框架下冷静克制、步步收网的冷冽张力。
  2. **体面抽梯、商业实锤**：男主不靠大吼大叫自证身份，而是用每一份到期不续的排他授权、每一笔撤回的连带担保、每一次董事会合规表决，让苏晚晴从“离了你我照样上市”的嘴硬，走到“原来连公司名字和核心配方都不属于我”的彻底破防。
  3. **绝不回头、无廉价原谅**：离婚程序、抚养权锁定、商业剥离步步不可逆；后期苏晚晴看清白月光骗局、众叛亲离跪求复婚时，男主已完成新商业版图跃迁与女儿的温暖重建，体面决绝切割。
- **为何能支撑60集**：
  本剧不靠“我是幕后老板—你不信—再骂三集”的水戏拖延，而是将60集建立在**四层递进的不可逆实质冲突**上：
  - **第一层（1～12集）**：家庭切割与首轮权限撤回（护女离家→云顶庄园反客为主→撤回百店庆功宴核心供应商账期担保与专属场地特权，首轮付费点打穿苏晚晴的“百店风光”）；
  - **第二层（13～26集）**：离婚冷静期博弈与核心技术/供应链抽底（苏晚晴误信周明远能用海外资本替代顾沉→顾沉按约终止无偿专利排他许可、收回婚前实控代工厂产能→苏晚晴抢抚养权反被坐实忽视儿童权益）；
  - **第三层（27～44集）**：身份揭晓后的控制权与资产保卫战（第26集末顾沉真正身份在盛川临时股东会彻底公开，悬念从“他是谁”正式切换为“苏晚晴与周明远联手用早期代持瑕疵、竞业反咬及海外对赌协议强抢公司实控权，顾沉如何在保住盛川老员工心血的同时彻底清洗寄生虫”）；
  - **第四层（45～60集）**：白月光资本骗局引爆、火葬场崩盘与终局清算（周明远掏空苏晚晴个人资产跑路→苏家内讧破产→苏晚晴为救危机揭发周明远却难赎前愆→领证离婚生效与盛川母公司敲钟并行收官）。

## 二、戏剧引擎

### 1. 初始困境与人物弧光起点
五年前，顾沉创立底层供应链与生物护肤研发母公司“澜山控股”，因苏晚晴在创业初期曾在他重病急性过敏休克时背他送医（实为阴差阳错的认知偏差，也为后续情感残余清理留钩），且苏晚晴极度渴望证明自己不输豪门本家，顾沉便在婚后隐去澜山实控人身份，出资并注入三项核心活性肽专利、开放自有工厂零押金账期，扶持苏晚晴担任“盛川美业”台前CEO，自己以“家庭主夫兼后勤顾问”身份照顾早产体弱的女儿顾可可（5岁）。
五年间，盛川做到全国百家直营店、估值三十亿。苏晚晴在鲜花与吹捧中彻底膨胀，认定盛川全是自己熬夜跑市场拼出来的，顾沉只是个靠她养活、连社交场合都上不了台面的窝囊赘婿。恰逢苏晚晴初恋学长周明远携6岁儿子周子轩归国，顶着“华尔街生物医药基金合伙人”光环示好，苏晚晴与岳母蒋玉梅迅速失衡，在百店庆功前夕越过顾沉的护女底线。

### 2. 主角优势、来路与现实限制（边界与代价）
- **主角优势与可追溯来路**：
  1. **澜山控股100%实控人及核心专利原始发明人/权利人**：盛川美业主打爆品“焕颜修护系列”依赖的3项底层专利，均由澜山实验室研发，五年前签署的是《五年期零特许权使用费排他许可协议》（期限至本剧开局第10天届满）。
  2. **盛川美业隐名控股架构**：澜山控股通过旗下全资子公司“青禾投资”持有盛川美业68%股权，苏晚晴仅持有32%创始激励股并担任法定代表人、执行董事兼总经理；五年前顾沉签署了《表决权委托协议》，将青禾投资所持68%股权的日常经营表决权委托给苏晚晴行使。
  3. **顶级私人圈层信用**：云顶半山庄园业主、盛川三大原料商及银行授信的实际连带担保方。
- **主角的真实限制与代价（为何不能第1集一秒捏死苏晚晴）**：
  1. **法律程序周期限制**：协议离婚需30天离婚冷静期（【待核：中国民法典第1077条规定自婚姻登记机关收到离婚登记申请之日起三十日内任何一方不愿离婚可撤回，诉讼离婚无冷静期但一审审理周期通常数月】）；苏晚晴作为生母，若不同意协议放弃抚养权，顾沉走诉讼争5岁女儿单独抚养权，必须收集充分的“生母严重失职/不利于子女身心健康”及“自身独立稳定抚养条件”的扎实证据链，不能有任何暴力抢夺或违规操作。
  2. **商业反噬与员工连带代价**：盛川美业有1200名基层员工和数十家合规加盟/联营商，且青禾投资是68%大股东。如果顾沉采取非法断供或直接恶意搞垮盛川声誉，不仅自己持有的68%股权价值归零，还会引发大规模商业违约诉讼与员工失业。因此顾沉必须走**“精准剥离苏晚晴管理权与寄生利益，合规切换供应链与接管经营”**的路径。
  3. **五年放权留下的经营壁垒**：苏晚晴担任法定代表人五年，掌控公章、财务U盾、中高层人事任免及直营店店长渠道，在股东会正式改选生效并完成工商变更前，她具备现实的行政阻挠力。

### 4. 双方资源与动态信息差流转
- **开局阶段（1～12集）**：
  - **观众知道**：顾沉是澜山实控人，盛川靠澜山输血；可可有轻度过敏性哮喘，需要洁净通风房间与云顶庄园疗养。
  - **顾沉知道**：商业底牌与时间节点，但他起初尚不知周明远归国的真实目的是用空壳基金骗取盛川账面现金流填补自己在海外的亏空。
  - **苏晚晴与蒋玉梅误信**：盛川背后的神秘资方“青禾陆总（顾沉副手陆铮）”是看中苏晚晴的个人商业才华才无条件投钱；顾沉离开苏家连房租都交不起，不出三天必定带着孩子回来跪求原谅；周明远是手握百亿美金的华尔街金融巨鳄。
- **首次认知撕裂（11～15集）**：
  - 云顶庄园与百店庆功宴现场，陆铮当众拒绝苏晚晴续签零费率专利协议，并宣布撤回三个亿供应链授信担保。苏晚晴发现陆铮对顾沉毕恭毕敬，但她与周明远更新判断为：**“顾沉以前给陆总当过司机/跑腿，手里捏着陆总的人情或把柄狐假虎威”**，进而改变策略——不再等顾沉饿死，而是试图跳过陆铮直接找澜山最高大老板，并加速用周明远的“海外新配方”去澜山化。
- **中盘彻底揭穿与战场转移（25～27集）**：
  - 临时股东会现场，顾沉以澜山控股唯一自然人股东身份坐上主位。身份悬念彻底终结！
  - **对手策略升级（不降智退回“演戏”）**：苏晚晴震惊崩溃后，在周明远和苏家法务怂恿下，不再否认顾沉身份，而是改打**“婚姻存续期间股权增值分割+指控顾沉利用关联交易掏空盛川侵害小股东利益”**的商业诉讼牌，企图冻结青禾投资表决权、把顾沉拖入泥潭。故事无缝接棒进入“控制权攻防与白月光收割局”。

## 三、核心人物

### 1. 顾沉（32岁）｜隐于幕后的澜山控股创始人 / 盛川真正托举者
- **身份前史**：白手起家的生化研发与供应链投资奇才，26岁创立澜山控股。当年在城中村实验室连续熬夜突发急性过敏性休克，醒来时见苏晚晴守在病床前（实为苏晚晴当时去医院看望别人顺手帮护士扶了一把，苏晚晴自己也半推半就认下了这份“救命情分”），加之婚后早产女儿可可体弱，顾沉遂退居幕后五年，包揽女儿一切照料，暗中用澜山资源把苏晚晴推上盛川美女总裁宝座。
- **欲望与软肋**：唯一核心欲望是让女儿可可在绝对安全、被珍视的环境里健康长大；软肋是对女儿可可的心理创伤极度敏感（可可最初还会小声问妈妈为什么不要她的房间，让顾沉心如刀割但从不在女儿面前诋毁母亲，只用行动给足安全感）。
- **控制资源**：澜山控股100%股权、盛川68%底层控股权（青禾投资）、3项核心底层专利、三大原料代工厂实控权、云顶半山1号庄园产权。
- **自我辩护**：承认自己过去五年的无底线隐忍与托举是一种“自以为深情的纵容”，亲手喂大了苏晚晴的傲慢，最后差点伤及女儿，因此抽梯时毫不手软，认为收回不属于她的东西是对规则和女儿最基本的交代。
- **怕被谁看见**：不怕外人嘲笑他吃软饭，唯一怕女儿看见成年人撕破脸的丑陋嘴脸。
- **说话策略**：从不提高声调，不说废话狠话，习惯用具体数字、日期、合同条款和已经执行完毕的动作说话；对方越歇斯底里，他越像在核对一张逾期账单。
- **情境化代表台词**（第2集，苏晚晴指责他为了一间房小题大做拿离婚威胁时）：
  > “可可三岁哮喘住院那晚你在陪客户喝酒，我就跟自己说过，这屋里只要还有她一扇干净窗户，我就能替你把盛川的底兜住。昨晚窗户没了，苏晚晴，你的兜底也没了。”

### 2. 苏晚晴（30岁）｜被捧上神坛的盛川台前CEO
- **身份前史**：苏家旁支出身，自幼被主家堂兄姐轻视，极度渴望出人头地。大学时暗恋风云学长周明远未果，毕业后嫁给当时看似普通的顾沉。接手盛川五年间，由于澜山在幕后扫平了最难的研发、账期与渠道准入，她每次出面谈判都顺风顺水，久而久之真心相信自己是百年一遇的商业女王。
