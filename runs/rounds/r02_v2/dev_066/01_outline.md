# 《抽梯》全剧故事引擎与分集大纲

## 一、项目定位

- **题材赛道**：都市情感 / 隐退大佬 / 抽梯断供 / 护女抚养权博弈
- **总集数与时长**：60集 × 单集1.5～2.5分钟
- **核心一句话钩子**：百店庆功夜，自诩白手起家的女总裁把亲女儿赶进无窗储物间讨好海归初恋，幕后托举她六年的丈夫当晚注销全部授权，带女儿抽走她脚下每一块踏板。
- **主要情绪承诺与尺度**：
  - **情绪承诺**：前期不靠男主无底线下跪挨打蓄压，痛感来自“六年心血与女儿的安全感被妻子当成廉价顺水人情送给外人”；爽感来自“精准、合规、一环扣一环的商业与生活抽梯”——不是喊口号亮百亿余额，而是每一次收回授权、专利、授信与客户背书，都让苏晚晴引以为傲的“个人能力”在现实经营成本面前原形毕露，同时女儿可可在父亲身边立刻获得具体、安稳的保护与尊重。
  - **尺度边界**：商业断供严格保护基层员工薪资、门店消费者预付款与供应商正常货款，所有反制精准锁定苏晚晴的高管控制权、个人连带授信与违规利益输送；涉未成年人冲突严守底线，女儿可可在第1集即被顾沉带离苏宅妥善安置，绝不拿孩子反复受虐、淋雨或被绑架充当情绪工具；终局绝对不回头、不复婚。
- **为何能支撑60集**：
  本剧不靠“反派连续60集不信男主有钱”拖延篇幅，而是按照**真实商业剥离与家庭切割的四个不可逆阶段**推进：
  1. **生活与特权剥离（1～12集）**：从搬离苏宅、收回顶级度假与医疗教育名额，到百店庆典现场终止无偿专利授权与供应链账期托底，揭开顾沉“深澜实业实控人”身份。
  2. **控制权与现金流攻防（13～28集）**：身份揭开后，苏晚晴不再怀疑顾沉是谁，而是误以为“盛川百店招牌和运营团队认的是我苏晚晴，离了深澜照样转”，联手初恋周明远引入外部对赌资本替代顾沉，双方围绕盛川经营控制权、核心店长去留与商标授权展开正面交锋。
  3. **抚养权与职务侵占追责（29～46集）**：商业受挫叠加周明远项目暴雷后，苏晚晴与岳母试图打亲情牌争夺女儿抚养权以要挟和解，同时周明远掏空盛川采购款的连带责任爆发，战场转向家庭抚养资格庭前调查与公司法务审计。
  4. **破产重整与彻底出局（47～60集）**：周明远卷款潜逃被拦截追赃，苏晚晴看清六年真相试图自救弥补，却发现信任与托举早已耗尽，最终在破产重整与离婚终审中失去盛川控制权与抚养权，顾沉携女开启新篇。

## 二、戏剧引擎

### 1. 初始困境与关系错位
六年前，深澜实业（主营高端冷链物流、食品研发专利与商业地产投融）创始人**顾沉**因救治早产体弱的女儿**顾可可**（小名可可，现6岁，轻度哮喘需恒温通风环境），退居幕后全职照料家庭。为成全妻子**苏晚晴**“不靠男人、独立创业”的自尊心，顾沉通过深澜实业旗下的全资子公司与信托通道，将自研锁鲜技术专利以“1元/年公益扶持价”授权给苏晚晴创立的**盛川生鲜连锁**，并以深澜不动产隐名提供银行授信担保、协调核心商圈免租期铺位。
六年过去，盛川扩张至第100家直营店。苏晚晴长期只能接触到深澜派驻的职业经理人林峥，误以为一切优待都是自己凭借商业魅力和个人信誉谈下的“战略大客户礼遇”，将顾沉在家的精算复盘、税务风控建议与育儿付出视为“跟不上时代的家庭煮夫唠叨”。
百店庆功前夕（11月15日），苏晚晴的大学初恋**周明远**携7岁儿子**周子轩**回国。苏晚晴不仅聘任周明远为盛川战略副总，还在岳母**蒋玉梅**撺掇下，趁顾沉带可可复诊时，拆掉可可带新风系统的儿童房给周子轩改建钢琴房，把可可的哮喘雾化机与绘本塞进一楼楼梯下无窗储物间，并将顾沉提前半年用深澜理事身份锁定的“云顶雪山儿童哮喘疗养营（含国际呼吸科专家会诊）”家属随行名额，擅自改成周明远父子的滑雪度假礼。

### 2. 主角优势、限制与代价
- **主角优势**：
  1. **底层资产实控权**：顾沉持有深澜实业100%表决权，掌握盛川赖以维持高毛利的三大命门——①“微晶锁鲜”核心专利排他许可权；②盛川62家核心盈利门店的二房东转租权及1.8亿元供应链银行授信的第三方担保函；③盛川早年创业时，顾沉通过深澜创投出资占股51%（由职业经理人林峥代为行使股东会表决权，苏晚晴持股49%任执行董事兼法定代表人，享有日常经营管理权）。
  2. **行业精算与运营老手**：盛川早期的单店盈利模型与冷链损耗率红线均由顾沉亲手搭建，他比苏晚晴更清楚哪家店在靠深澜补贴输血。
- **能力限制与真实代价**：
  1. **合规与商誉边界**：顾沉是盛川51%间接大股东，若粗暴断货导致盛川门店停摆，不仅会砸毁自己投资的资产包，还会连累盛川1200名基层员工和数万储值卡客户。因此他不能违法强封门店，必须按合同约定触发“违约/到期不续签/召开临时股东会罢免执行董事”等法定程序（注：有限责任公司持股10%以上股东可提议召开临时股东会，代表1/10以上表决权股东可自行召集主持，修改章程外的一般决议如罢免执行董事需按公司章程规定，本剧设定盛川章程规定过半数表决权即可更换执行董事与法定代表人；涉及具体登记变更周期以工商实务为准【待核：各地市场监管局在原法定代表人不配合交出公章营业执照时的强制涤除/变更登记时限】）。
  2. **婚姻财产与抚养权约束**：顾沉婚后为照顾可可，个人社保挂靠在深澜旗下工作室且日常流水极简，苏晚晴初期据此认为顾沉“无独立抚养经济能力”；同时，离婚冷静期（协议离婚30天）或诉讼离婚排期意味着婚姻关系无法当天一秒解除，顾沉必须先做分居取证、财产隔离与授权撤回。
  3. **情感代价**：亲手拆穿六年托举，意味着承认过去六年对妻子的纵容间接造成了女儿今日受委屈，顾沉必须直面可可对“妈妈为什么不要我”的心理创伤，并耗费大量精力安抚陪伴。

### 4. 核心专业机关拆解（经受反驳设计）

#### 机关一：三年期《技术排他许可与冷链补贴补充协议》到期与违约即停条款
- **归属与触发条件**：深澜科技（顾沉实控）与盛川生鲜签定的3年扶持期协议，恰好于11月18日（百店庆典当日）24:00到期；且协议第9条规定，盛川高管层变动或将深澜核心冷链数据开放给第三方竞品关联人时，深澜有权立即终止优惠费率（原1元/年象征性许可费+冷链运费7折补贴），恢复市场公允牌价（年许可费1200万+冷链全价结算，预付季度押金）。
- **证据与执行路径**：苏晚晴在11月15日未做背调便任命周明远为副总，并开通其ERP冷链后台权限；深澜风控后台自动抓取异地导出记录并公证固定，由深澜总裁林峥向盛川发送《到期不续签优惠条款及恢复公允结算函》。
- **对手最强反驳**：苏晚晴反击称“生鲜行业冷链供应商多得是，深澜店大欺客，盛川换周明远推荐的‘捷讯冷链’还能省15%运费！”——这正是第6～15集的核心交锋：顾沉无需靠违法手段封杀她，苏晚晴自己主动换用周明远吃回扣的劣质冷链，结果失去“微晶锁鲜”温控参数匹配后，第10集高端海鲜与有机果蔬损耗率从3%暴增至38%，引发连锁客诉。

#### 机关二：1.8亿供应链银行授信的《最高额保证合同》单方不续保与抽贷防御
- **归属与触发条件**：盛川向商业银行申请的1.8亿循环授信额度于11月25日面临年度重检，此前全靠深澜实业提供连带责任保证担保。顾沉作为深澜实控人，提前向银行发函明确“存量已用额度（8000万）深澜履行担保责任到底绝不逃废债，但自即日起对新增提款及年度续期不再提供任何担保”。（注：担保人不能单方撤销已发生债务的担保，但有权拒绝为尚未发生的新增循环贷款及续期合同提供担保，符合《民法典》担保制度逻辑）。
- **证据与执行路径**：银行风控收到深澜《不续保告知函》后，立即冻结盛川剩余1亿元未提用授信额度，并要求盛川在10个工作日内补足8000万存量贷款的增信抵押物，否则到期直接扣划盛川基本户资金。
- **对手最强反驳**：周明远趁机引入海外壳公司“瑞丰资本”，提出注资1亿置换银行贷款，但要求苏晚晴签署个人无限连带责任对赌协议，并将她名下49%股权质押给瑞丰，把苏晚晴一步步套进深渊。

#### 机关三：股东知情权审计与临时股东会罢免执行董事
- **归属与触发条件**：深澜创投持有盛川51%股权。当初签署的《一致行动与委托管理备忘录》约定：若执行董事（苏晚晴）发生损害公司利益的关联交易、或连续单月经营性净现金流恶化超2000万，深澜创投有权收回委托管理权，按《公司法》召集临时股东会改选执行董事、接管印鉴。
- **对手最强反驳**：苏晚晴藏匿公章、拒绝配合工商变更，甚至煽动不知情的中层员工抗议“资本野蛮夺权”。顾沉的破局方式不是带保镖砸门，而是公开周明远通过“捷讯冷链”虚增35%报价套取盛川1400万现金导致年终奖池亏空的铁证，并由深澜先行设立“员工薪资与储值卡兑付共管专户”，瞬间瓦解苏晚晴的内部人心基础。

### 5. 动态信息差演进
- **第1～8集（误判期）**：观众从第1集就知道顾沉是深澜幕后实控人；苏晚晴和蒋玉梅坚信顾沉每月靠苏晚晴给的2万家用过活，把顾沉收回资源的警告当成“吃醋撒泼的男版一哭二闹”；周明远则以为苏晚晴真是独立富婆，急于上位捞钱。
- **第9～12集（身份揭破节点）**：百店庆典暨续约谈判现场，苏晚晴备好大礼去求见从未露面的“深澜顾董”，结果推门见到带着可可签字的顾沉。**信息差在此处消耗完毕，绝不强行让反派继续喊“顾沉是深澜请来的演员”**。
- **第13～28集（归因错位期）**：苏晚晴确认了顾沉是深澜老板，但她的自我辩护机制迅速切换为——“就算你出过钱和专利又怎样？100家店是我熬夜跑出来的，团队和市场认的是我苏晚晴！你想用撤资逼我低头认错，我偏要靠自己把盛川做上市给你看！”新的信息差变成：**苏晚晴不知道周明远其实是背负海外赌债与商业欺诈调查的空心老赖，而顾沉已通过海外背调拿到线索，但周明远正用伪造的投行Term Sheet诱骗苏晚晴签下个人连带赔偿协议**。
- **第29～46集（利益撕咬期）**：周明远的劣质供应链与过桥资金骗局爆雷，苏晚晴发现当初所谓“轻松谈下的免租铺位、零账期供货商、甚至百店选址模型”全都有顾沉批注的底稿。信息差彻底反转，争点变成“如何保住苏晚晴的股权不被瑞丰资本吞掉、谁有资格抚养可可、以及周明远职务侵占的刑事报案红线”。

## 三、核心人物

### 1. 顾沉（32岁）｜盛川幕后奠基人 / 深澜实业实控人
- **身份前史**：白手起家建立深澜冷链与生鲜科技体系的青年实业家。六年前与大学学妹苏晚晴结婚，因女儿可可早产患哮喘，加之苏晚晴渴望创业证明自己，他退居二线，一边在家远程统筹深澜战略，一边包揽可可的饮食起居与康复护理。
- **欲望与软肋**：最大愿望原本是家人平安、女儿健康成长；唯一软肋是对可可的愧疚——他发觉自己的低调退让养大了苏晚晴的傲慢，最终让女儿在自己家里受了委屈。
- **控制资源**：深澜实业100%股权、微晶锁鲜核心专利、盛川51%母公司控股权、云栖壹号顶层住宅、医疗与教育理事席位。
- **自我辩护**：从不把过去六年的付出挂在嘴边邀功，认为“给出去的感情如果是喂了狼，及时止损就是对女儿最大的负责”。
- **怕被谁看见**：怕被女儿可可看见父母歇斯底里地互相咒骂，因此在孩子面前永远保持温和笃定，所有雷霆切割都在谈判桌与合同章上完成。
- **说话策略**：从不威胁“我要让你跪着求我”，只陈述客观事实、截止时间和违约成本，给过一次确认机会后立刻执行。
- **情境化代表台词**：“苏晚晴，这六年我站在台阶下面扶着梯子，是因为你在上面。现在可可连间有窗户的卧室都没了，这把梯子，我收回来给女儿搭秋千。”

### 2. 苏晚晴（29岁）｜盛川生鲜连锁CEO（前）
- **身份前史**：普通中产家庭出身的校花学霸，极度好强，毕业后创立盛川生鲜，在顾沉隐形保驾护航下六年开出百家直营店，获评“江城十大杰出青年女企业家”。
- **欲望与软肋**：极度渴望被商界认可为“不依附任何人的商业女王”；软肋是虚荣心极强、极度抗拒承认自己的成功源于丈夫的施舍，以及母亲蒋玉梅常年的精神绑架。
- **控制资源**：盛川49%股权、CEO管理权限、媒体光环、2400万账面流动现金。
- **自我辩护**：“我每天工作十四个小时应酬喝酒的时候，顾沉只在家里炖汤接孩子！明远刚回国需要人帮一把，可可才六岁，让几天房间怎么了？顾沉就是大男子主义容不下我比他优秀！”
- **怕被谁看见**：最怕在商界同行、下属和初恋周明远面前露出“离开丈夫就转不动公司”的窘态，因此越是被抽梯，前期越是赌气硬撑。
