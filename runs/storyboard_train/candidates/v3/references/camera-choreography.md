# 运镜调度：信息收益与空间可执行性

## 一、先问观众需要看见什么
每拍先确定新增证据、关系或心理变化。固定构图能清楚表达时，写“固定＋观看意图”，让入画、遮挡、停顿和声响承担力量。人物走动不自动要求跟拍；移动只用于揭开遮挡、维持必要空间关系或使决断首次可见。“有气场”“更紧张”不是新增信息。

开场前5秒优先显出原稿已有的异常或利益反差，压缩摸袋、藏袋、移位等重复准备；不得提前搬运后续事件。高潮检查“动作发生→证据可见→承受者反应→权力结果”是否可读，这是观看职责，不是强制四镜。接触过程可用固定近插镜，碰撞落定后再决定是否推近反应。集尾守住原稿尚未解决的威胁、选择或动作临界点，不以微笑、风景替代钩子，不增写宗族规则等新设定。

对白覆盖按心理变化组织：受辱、识破偏袒、断情各有不同职责；若听者没有新变化，合并重复的“说话镜→沉默反应镜”。L-cut用于连续声音与注意力交接，不能成为每句后的固定套路。关键决断允许留白，不强加摄影机动作。

## 二、移动四要素＋几何验算
句式：
`[单一主运动＋单档速度]：[可定位触发]；摄影机从[位置、构图]沿[方向、幅度]至[位置、构图]停稳；新增信息＝[终点首次可见的具体变化]`。

- 触发定位到可见动作阶段或台词重音。收药已完成后，才在转头看定对手的瞬间启动；终点写“首次显出的决断眼神”，不能把启动前的收药冒充移动收益。
- 每场共用一套坐标，先标摄影机、人物、门墙及障碍。逐项核对起点、方向、距离、终点；再核对画面对象能否进入视野。门在北，摄影机向南后退只会增加门距，不能同时写门距从3米缩至1.5米。
- 跟拍写前／后／侧、人物方向、可通行路线和停止线；固定点摇摄只能看见真实视线可达区域。门内看不到楼梯底，就拆为投掷动作与洞口落地，不用文字穿透楼板。
- 速度选缓／中／快，并在镜长中留出启动、移动及观看落点的时间。不要用精确米数装饰未经验证的路径；若起止构图难以兼容，缩短移动或切镜。
- 落点仍是同一张无变化的脸，优先固定；推到物证微距跨度过大，改为小幅推近后切独立特写。

## 三、语法合规不等于动作可拍
按独立运动分量识别复合运镜，不按“＋”号判错。“横移＋缓速”是一种运动与速度；“平行跟拍／横移”若描述同一路径也是一种。推近同时摇摄、横移同时变焦是两种，须拆镜。景别变化、固定俯仰机位、切镜不算机身运动。

| 方式 | 适用职责 | 执行边界 |
|---|---|---|
| 推近 | 决断或证据首次显形 | 明确变化发生时刻与终点，避免轮流推脸 |
| 跟拍／横移 | 离场、拖行、揭开遮挡 | 先建立抓握关系，再跟单向位移 |
| 摇摄／俯仰摇 | 从动作或目光引出新对象 | 固定机身位置，标起止对象、角度及无遮挡视域 |
| 后拉 | 显出孤立或全局反差 | 拉开必须增加关系信息 |
| 升降 | 高度变化带出新关系 | 垂直位移，不同时叠加仰摇 |
| 小幅弧移 | 位置变化揭示局势 | 角度≤30°，核对刚体、轴线与终点 |
| 转焦 | 同框前后信息交接 | 固定机身，写触发、起止焦点、速度及可用时窗 |

摄影机震动须有成立的视点或直接受力依据。门撞墙、拍杯不会自然传导到独立摄影机；优先固定，让声音、物体震颤和入画速度承担冲击。确需主观冲击效果，单列为后期效果，写方向、幅度、持续时间与停稳画面，不算主动运镜收益。

动作负载另查：单一下摇仍可能叠加工具接触、灯架脱落、碎片弹跳与扬尘。可从灯架已松脱起拍，或拆开拆卸与撞击，用声音衔接。运动语法通过不能替代此检查。

## 四、统计只诊断，不驱动创作
从正文分别统计位移、摇摄、摄影机震动、转焦和后期冲击。主动运镜率＝含位移或摇摄的唯一子镜数／全部唯一子镜数；同镜不重复计数，震动与转焦单列。与旧口径比较时明确分母和排除项。12%～26%仅供复查，不作通过线，不补运动凑比例。

联读运镜、画面、动作列：标固定却要求从手追到脸、跟人穿门是“假固定”；改为人物进出固定画框，或如实写移动。最后检查移动是否抢走接触动作、完整对白或落点的观看时间。
