# 运镜调度：由信息变化决定动静

主动运镜占比12%～26%仅作既有样本的观察参照，不是验收配额。先把戏拍顺，再统计；禁止为达比例补推镜、拆镜或把运动改名为固定。

## 一、逐镜决策

先问：观众此刻必须多看清什么？
- 固定构图已能呈现证据、对峙或犹豫，就用固定；备注写具体意图，如“固定保留父亲说完威胁后的沉默”。演员移动不等于摄影机必须跟随。
- 只有移动能揭开遮挡、建立因果、改变观众与人物的距离或展示权力位置变化时才动。触发必须是可见动作、声音节点或台词重音。
- 开局前5秒尽早呈现原稿已有的危机或异常行为；压缩重复准备，不提前执行后续事件。结尾落在尚未解决的威胁、选择或证据上，不能让豪车风景稀释清算，也不能替原稿发明悬念。
- 爽点可按“证据出现→他人接收→权力反应→后果或悬念”分配注意力。它是职责检查，不要求四镜；不能重复执行同一次动作。
- 高潮可用固定蓄力、关键处一次移动、固定承接形成呼吸。连续镜若都以推镜表达同一种气场，保留有新增信息的一处，其余交给表演或切镜。

## 二、主动运镜必须写齐四要素

句式：
“单一运动＋速度：具体节点触发；机位从何处沿何方向移动多远或转多少角；由何构图到何构图；停在何处，新增何信息。”

1. 触发：如“锁扣合拢声响起”，不用“气氛紧张”。
2. 路径与幅度：写机身起点、方向、终点与空间参照；起止景别不能代替路径。跟拍须写摄影机在人物前后哪侧、与门或障碍物的关系及停止线。
3. 速度：缓／中／快只取一档。快不等于自由乱晃；运动时间须容纳启动、行程与落定。
4. 落点：实际可见的证据、距离或关系变化；“加强气场”不算新信息。

示例：
“中速后退跟拍：人物冲向电梯触发；机位在其前方门外走廊，沿走廊朝门退约1米，止于距门槛1米标线；停在人物被拦住、距门缝半米的中景，不入轿厢。”
“短促受撞震动：踹门声触发，机位原地水平左右低幅摆动约1°，中速单次摆回后锁定门框；落在闯入者站稳、看向左下方的构图。”

## 三、按职责选择单一路径

| 方式 | 适用信息 | 执行边界 |
|---|---|---|
| 前推 | 物证显露、决定落下、承受者变化 | 小跨度收紧；避免环境全景一路推到微距 |
| 后拉 | 孤立、局部与全局反差 | 终点必须有新的空间关系 |
| 跟拍／横移 | 离场、遮挡后揭露、单向拖行 | 锁定工作侧、距离与停止线 |
| 摇摄／俯仰摇 | 目光因果、画外来者 | 机位不平移，明确方向与转角 |
| 升降 | 人物高度或权力位置变化 | 区别机身升降与仰摇，锚定背景 |
| 受撞震动 | 突发受击 | 交代方向、幅度、速度及回稳构图 |
| 小弧线 | 局面翻转的空间重排 | 小幅且有刚体参照，不为高光例行环绕 |
| 转焦 | 同框前后层信息切换 | 机身固定，单列焦点变化，不计机身主动运镜 |

一个子镜只用一种主运动，不叠加推摇、横移变焦或变速。植物变形、精细持物与大跨度移动叠加时，优先固定，分别确认变化与结果。

## 四、从正文反查“假固定”

扫描画面、动作和构图列：若写“始终跟住”“绕到背后”“从手摇到脸”，即使运镜列写固定也须纠正。固定允许人物出入画，不能暗中维持追随构图。景别、仰拍、切到门口均不是运镜。

统计主动运镜子镜数／全部子镜数，转焦另列；比率合格不能抵消无路径、无落点、穿门、背景漂移或重复强调。
