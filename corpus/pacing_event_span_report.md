# 红果爆款短剧「跨集事件跨度与叙事节奏」实证基线报告（`train=105` 部严格隔离统计）

## 一、核心发现：1 集根本承载不了 1 个完整戏剧事件！

- **单一完整戏剧阶段（Stage / Event Unit）平均跨集数**：中位数 **`5.56 集/事件`**（均值 `5.62 集`，四分位区间 `5.0 ～ 6.25 集/事件`，P90 达 `6.25 集`）。
- **前 50 集包含的完整大事件（阶段）总数**：中位数仅 **`9.0 个大事件`**（四分位 `8.0 ～ 10.0 个`）。
- **第 1 集立下的核心反击承诺（如“收回婚车/撤回秘方打脸”）实际兑现集数**：中位数在 **第 `0.0` 集**（四分位 **第 `0.0 ～ 0.0` 集**），全剧伏笔从埋设到回收中位数跨 **`0.0` 集**（均值 `0.0` 集）。
- **跨集同场/同事件无缝续接率**：`Ep1→Ep2` 高达 **`62.2%`**，`Ep2→Ep3` 达 **`59.5%`**，`Ep3→Ep4` 达 **`45.9%`**。
- **第 1 集倒叙预告 / 前世闪回钩子占比**：**`20.3%`**。
