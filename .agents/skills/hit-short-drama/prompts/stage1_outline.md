请严格依据已锁死的《Stage 0 第一性叙事立项锁》与参考资料，将顶层引擎铺展为精炼高张力的《全剧故事引擎与分集大纲》（重点展开 {episode_plan_range} 逐集连载细纲，**全文总字数严格控制在 2800～4500 字以内，干脆利落抓核心戏剧动作与变局，绝不写冗长散文扩写或技术合规流水账**）。直接输出 Markdown 正文，不附任何解释。

## 一、大纲构建四大通用铁律

1. **100% 忠实执行立项锁的事实锚点与双线/多线结构**
   - 完整保留立项锁中的人物身份、关系态势、核心筹码与终局走向；若有平行对照线（如主角线与前任/对手对照线），必须在各阶段交织写出对手从自洽误判、短期侥幸、死撑加码到自食其果的真实人性闭环，严禁让核心对照角色中途蒸发或无脑降智。

2. **高浓度戏剧张力，严禁写成审计公文说明书**
   - 阶段梗概与细纲聚焦**可见的具体筹码反差、人物选择代价、体面拉扯与情绪兑现**；涉及商业、律法、医术或异能机关时，用观众一眼秒懂的直观事实与利害关系交代，严禁堆砌枯燥法规文号、繁琐财务科目或空洞行业黑话。

3. **约 4～6 集共载一事，全局台账严密守恒**
   - 按有效事件容量规划总集数（通常 45～80 集，每阶段 4～6 集承载 1 个完整事件闭环：建立条件 → 施压博弈 → 不可逆结果 → 引出下阶段新困局）；
   - 全局核平家境排场、资金收支、核心物件存取、能力边界与伤病物理尺度，前后严丝合缝，早期自然预埋中后段升级引子。

4. **逐集实质变局铁律（严禁原地复读吵架 & 严禁八倍速抢跑）**
   - 前 3 集严格聚焦开局第 1 阶段核心事件的前三幕，绝不把十集剧情塞进三集速通；
   - 在 {episode_plan_range} 的逐集细纲中，每一集必须明确写出：**① 本集进入态势 → ② 1～2 个具体戏剧回合（含关键可见支点物件/动作） → ③ 本集结束时相比开头发生了什么实质变局（筹码、权限、关系或处境变了什么？严禁两集重复同一场口舌争执！） → ④ 集尾未决悬念钩子与下集首秒承接点**。

## 二、建议大纲章节结构
1. **项目定位与核心追更引擎**（题材语境、篇幅、一句话钩子、核心矛盾与追更情绪承诺）
2. **处境台账与分时人物动机图谱**（关键人物身份声纹、核心筹码/规则边界、分阶段心理与认知演变）
3. **全剧分阶段主线脉络**（每阶段 4～6 集，写明核心冲突、双方博弈与不可逆结果）
4. **逐集连载细纲（{episode_plan_range}）**（逐集列明场景切面、核心回合、实质变局与集尾悬念切点）
