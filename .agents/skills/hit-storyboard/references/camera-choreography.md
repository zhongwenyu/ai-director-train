# 运镜调度：先确定信息，再决定摄影机是否移动

## 一、固定与移动的决策
先写本拍观众必须看清的证据、关系或变化。固定构图配演员微动作、景别切换已能表达时，写“固定＋意图”；人物走动不等于摄影机必须跟动。只有移动能揭开遮挡、维持必要空间关系或改变观众对权力的感受，才启用主动运镜。常规问答不因人物“有气场”反复缓推。

开场前5秒尽早显出原稿已有的异常行为或利益反差，压缩重复准备，不提前搬运后续事件。高潮可用固定蓄力→一次有信息收益的移动→固定承接；不强制套用。揭晓按“动作发生、证据可见、承受者反应、权力结果”分配注意力，可合并已有清楚表达的拍点。集尾落在未解决的威胁、选择或动作临界点；有台词仍须给完整声音窗口，不为短钩子截句，也不拉成车辆风景。

主动运镜率＝含摄影机位移、摇摄或震动的子镜数／全部子镜数。转焦单列，不计主动运镜；切镜、景别、俯仰机位不计。12%～26%仅作复查参考，偏离时检查动机，不为达标添运动或把移动改名“固定”。比例合格不能证明可拍。

## 二、每次移动必须写清四要素
句式：`[方式＋单档速度]：[可见动作或台词重音]触发；摄影机从[空间位置、起始构图]沿[方向、幅度]到[终点位置、构图]停稳，新增信息＝[具体可见事实]`。

1. 触发必须可定位：“门被踹开的撞击”可用，“紧张气氛”不可用。
2. 路径同时约束摄影机与人物、门墙的关系；写机身移动距离或角度，或起止景别范围。跟拍注明位于人物前／后／侧、运动方向及停止线。不能后退穿过闭合电梯门，也不能穿桌、穿墙。
3. 速度只选缓、中、快之一；停止是终点，不另加加速、甩摇。快慢由事件决定，不设每集必用次数。
4. 落点是新增证据或关系：“包口露出证件”有效；“更有气场”无效。移动后仍是同一张脸且无变化，优先固定。

一个子镜只用一种主运动；推＋摇、移＋变焦须拆镜。转焦可单独写起止焦点与触发，不借转焦偷加机身运动。中景推到微距跨度过大时，改为小幅推近后独立物证特写；保证观众先辨认对象，再确认细节。

## 三、按职责选择方式
| 方式 | 适用职责 | 必须约束 |
|---|---|---|
| 推近 | 逼近证据、决断显形 | 起止构图与具体落点；避免轮流推眼镜包装气场 |
| 跟拍／横移 | 跟随离场、揭开遮挡 | 摄影机工作侧、人物行进方向、停止线与障碍 |
| 摇摄／俯仰摇 | 从目光或动作引出新对象 | 机位不平移；起止对象及角度范围 |
| 后拉 | 从局部证据显出孤立或全局反差 | 拉开后必须多出关系信息，避免稀释清算威胁 |
| 升降 | 跟随高度变化、揭示权力关系 | 机身垂直位移与人物终态；不叠加仰摇 |
| 短促震动 | 受撞、受击的瞬间体验 | 一次、方向、幅度、持续时间和停稳构图 |
| 小幅弧移 | 位置变化确能揭示局势翻转 | 角度≤30°、背景刚体、轴线与终点 |
| 转焦 | 同框前后层信息交接 | 固定机身，明确起止焦点，不计主动运镜 |

震动示例：“门板受踹触发，一次中速水平低幅震动（约1°、0.3秒），停稳在门框内来人站定、视线指向左下方孩子的中景。”不写“手持急晃抓拍后迅速停稳”。

## 四、逐镜反查
联读运镜、画面、动作三列：写“固定”却要求持续重构图、跟随人物穿门或从手摇到脸，属于假固定；要么锁定取景让人物进出画，要么如实补全运动四要素。检查相邻承重拍是否重复推进同一情绪，移动是否抢走证据与表演的观看时间。
