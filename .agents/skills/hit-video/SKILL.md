# 通用短剧视频生成与连续性闭环技能（hit-video）

本技能针对多模态参考音视频一体生成模型（`Pika-H3-Flex` `Ref2VA` + Spark `MiniMax H3 Image`）沉淀**跨年代、跨题材（现代、古装、悬疑、动作、言情通用）、零剧集过拟合**的工业化生成与场记质检规范。

---

## 一、核心生成与守恒铁律（Universal Invariants）

1. **输入参考图强制 `≤ 1K` 等比预压缩（资产库保留 `2K` 原片）**
   - 项目资产库中的人物五格主图、单人正面图（`#front`）、场景图与道具图保持 `2K` 原图不变。
   - 提交给视频生成接口的所有参考图必须先行 Lanczos 等比缩放至 `max(width, height) <= 1024`，禁止拉伸或裁切。

2. **全题材“零人物外貌/服饰/年龄文本”铁律（Zero-Appearance Text Rule）**
   - 视频提示词严禁描述任何人物五官、年龄数字/年龄段、发型长短颜色、服装品类/材质/颜色、鞋帽配饰（涵盖现代装、古装袍服/盔甲/发簪等全品类），100% 由 `<Picture N>` 参考图锁定角色外观。
   - 若上游文学剧本含外观描写，编译视频提示词时必须剥离；涉及服饰配件的物理交互（如扯断挂绳、交接信物）一律抽象为通用动作与独立道具引用。

3. **局部空间稳态区（Spatial Epoch）母图锚定与状态跃迁重锚（State-Transition Re-Anchoring）**
   - **按「局部空间稳态区（Spatial Epoch）」划分锚点，严禁按“场”机械一刀切**：
     - 当镜头序列处于**同一局部刚体拓扑且环境未发生结构突变**（如室内外固定区域对手戏）时，先用 Spark `MiniMax H3 Image`（`scripts/spark_h3_image.py`）建立 1 张 `Spatial Epoch Master Plate`，该稳态区内**全部镜头（含单人近景，杜绝孤儿首帧）**的首帧均以该母图为 `<Picture 1>` 派生，并在多切镜视频中挂载该母图作为 `<Picture 2>` 锁死家具几何与 180° 轴线；
     - 一旦发生**连续长距离空间位移**（行进跟拍、追逐转场）或**环境结构不可逆剧变**（桌椅掀翻、起火断电、门窗破损），必须立即结束旧 Epoch 并切换/重绘新状态锚点，严禁拿旧静态母图强锁移动或已破坏场景；
     - **严禁盲目用 `480p` 上一镜特写尾帧链式生下一镜全景首帧**（背景缺失必致越轴翻转与画质逐代劣化）。
   - **初始在场集（Initial Presence）铁律**：`t = 0.0s` 首帧只允许绘制该时刻已在画内的角色与初始前态（Pre-Action），`t > 0s` 才入画的角色严禁提前出现在首帧中（其外观由 `<Picture K>` 参考图提供）。
   - **不可逆状态跃迁重锚律**：由于 `Ref2VA` 参考图潜变量在每一步采样中持续重注入，凡发生跨镜可见的**离散物理状态跃迁**（随身物穿脱、物品易手、容器开闭、物体损毁/染色），跃迁完成后的镜头必须先用生图服务生成**已显式抹除旧位置状态、确立新唯一归属的新首帧/母图**，禁止依赖视频扩散模型顶着旧状态参考图自行“脑补抹除”（否则极易产生双份道具复制）。

4. **音色绑定、画外音双轨隔离（`vo_split`）与神经网络 VAD 完整性门禁**
   - 说话或发心声角色绑定 `≤ 3.0s` 干净原声样本（`<Audio 1..3>`）。`<d>[Chinese] 台词原文</d>` 标签内严禁混入说话人姓名或舞台括号提示。
   - 所有内心独白（OS）/旁白（VO）严禁送入主画面生成：主画面闭口生成，独立生成短干声 VO 经人声提取与闪避（Ducking）按毫秒级目标起点混入。
   - **单组时序容量硬预算**：单条 5–15 秒生成组若末镜包含完整句子对白，严禁在同一组内叠加过多前置慢动作或长段静默发呆；说话子镜按常态 `4.8 字/秒`（急促怒吼 `5.6 字/秒` + 句尾闭口锁）留足至少 `0.8s` 句尾余量，超载镜头组必须拆分为两条独立组。
   - **零分贝阈值过拟合的神经网络 VAD 门禁（`scripts/check_audio_integrity.py`）**：严禁使用固定分贝阈值判断静音或截断（在风雨/街头/爆破等高底噪场景必误判）；统一采用 `Silero-VAD` 神经网络人声概率曲线校验三项指标：
     1) **尾句截断（`SPEECH_TRUNCATED`）**：片尾最后 `0.22s` 人声概率仍处于激活态；
     2) **漏念台词（`MISSING_SCHEDULED_SPEECH`）**：计划对白时间窗内无人声激活；
     3) **非计划人声杂音（`UNSCHEDULED_VOCAL_NOISE`）**：无台词动作区间出现干呕、闷哼或尾部胡话。

5. **分离式背景配乐（`audio-library`）与双层字幕轨（保障无损超分）**
   - 严禁将字幕/花字烧录进视频帧，严禁将跨镜配乐硬混入单镜视频音轨（保障下游 `2×` 扩散超分零文字伪影、单镜重抽不断乐）。
   - 统一由 `scripts/post_bgm_subtitles.py` 基于逐镜实测时长输出自动闪避人声的整集独立 `bgm.mp3` 与三态 `.vtt`/JSON 字幕轨（`caption` / `dialogue` / `vo`）。

## 二、多模态场记连续性审计与四路最小破坏重修闭环

### 1. 切点拓扑三级门控（3-Tier Cut Topology）
审计相邻镜头（集内 `Shot i-1 -> Shot i`，跨集边界先判别 `上集末镜 -> 下集首镜` 切点拓扑）时，严禁机械一刀切，必须先分类：
- **类型 A（同稳态区零时差连续切，`Δt ≈ 0s`）**：严格核查空间刚体一致、180° 视线轴线匹配、动作因果闭环与实体状态守恒（包括跨集悬念同场顺接）。
- **类型 B（邻接空间动线切 / 同场微省略切，`Δt ≈ 1–30s`）**：不要求室内外背景相同，重点核查角色外观/手持物状态连续与运动方向合理。
- **类型 C（跨时空平行切 / 隔夜省略切）**：**严禁拿上一镜站位或陈设强审新场景首帧**！只继承全局剧情不变量，直接切入新场景展开态，仅核查本镜内部无因果倒置与音画异常。

### 2. `gemini-4-hydrogen` 开放式实体账本场记子 Agent（Script Supervisor）
- **禁止仅做孤立两镜文本对比**；场记子 Agent 必须直接读取原生 `.mp4` 视频流（同时审动态画面与原生音轨），并维护**开放式无固定槽位的动态实体状态账本（Open Entity-State Ledger：`[{entity, state, scope, since_shot}]`）**，从而精准捕获跨多镜（K-hop）的非相邻道具/状态穿帮。
- 每镜输入四元组：`当前 Spatial Epoch 锚点图（若有）` + `动态实体状态账本` + `Prev_Shot.mp4（类型 A/B 跨集时取上集末镜）` + `Curr_Shot.mp4 与本镜剧本目标`。

### 3. 四路故障归因与最小破坏重修派发（4-Way Fault-to-Action Dispatch）
根据 `MiniMaxH3ReferenceToVideo` 底层机制（参考视频全帧 24fps VAE 潜变量每步重注入且不降噪、带音轨参考视频会自动抢占 `<Audio 1>` 序号），发现穿帮后**严禁盲目把动作/节奏出错的问题视频塞回 `reference_video` 加文字建议重跑**，必须按根因四路派发：

| 故障根因枚举 | 执行原语 | 底层工程依据 |
|---|---|---|
| `ANCHOR_OR_STATE_DRIFT`<br>（首帧/母图含残留旧陈设、时代穿帮物或状态跃迁未抹除旧道具） | `REBUILD_ANCHOR_IMAGE`<br>先用 Spark `H3 Image` 重绘干净锚点图，再重生成视频 | 纯改视频 Prompt 无法推翻 `<Picture 1>` 首帧潜变量的像素级强锁定 |
| `ACTION_OR_TIMELINE_FAULT`<br>（动作未到位、干站超时挤断尾句、中途误松手/越轴） | `REWRITE_PROMPT_TIMELINE`<br>收紧/拆分时间窗并改写动作指令，从干净静态锚点重生成（**禁传问题视频**） | 若传入问题视频，其错误动作与停顿的 24fps 潜变量每步重注入会锁死旧错误，且原坏音轨会冲乱 `<Audio j>` 配音映射 |
| `AUDIO_ONLY_DEFECT`<br>（画面表演与切镜完全达标，仅存在非对白区杂音或独立 VO 偏移） | `PATCH_AUDIO_ONLY`<br>保留原视频流（`-c:v copy`），仅无损修补环境音窗或重混 VO | 避免重抽视频带来的画面退化风险与算力浪费 |
| `APPEARANCE_SWAP_ONLY`<br>（运镜、动作轨迹与时长 100% 理想，仅需替换角色外观或局部静态小元素） | `MUTE_REF_VIDEO_RECAST`<br>先 `ffmpeg -an` 剥离音轨后作为 `<Video 1>` 驱动重生成 | 唯一适合挂载参考视频的场景；剥离音轨防止挤占角色 `<Audio j>` 序号 |

## 三、配套工具脚本（`scripts/`）

| 脚本 | 功能 |
|---|---|
| `scripts/compress_1k.py` | 批量将 `2K` 资产/关键帧等比压缩至 `max(w, h) <= 1024`（Lanczos），保留原图不变 |
| `scripts/spark_h3_image.py` | 调用 Spark `MiniMax H3 Image` 多图参考编辑，生成 `Spatial Epoch` 母图与状态跃迁首帧 |
| `scripts/pika_runner.py` | 全题材零外貌词校验、`≤1K` 校验、`Pika-H3-Flex` 视频生成与 `vo_split` 双轨混音 |
| `scripts/check_audio_integrity.py` | 基于 `Silero-VAD` 神经网络人声检测的尾句截断、漏词与非对白人声杂音零阈值过拟合门禁 |
| `scripts/check_transitions.py` | 提取全集（含跨集切点）首尾过渡拼板，辅助整集动态连播验收 |
| `scripts/post_bgm_subtitles.py` | 编译自动人声闪避的分离式 `bgm.mp3` 与双层 `.vtt`/JSON 字幕轨 |
| `scripts/upload_to_studio.py` | 上传验收通过的关键帧、纯净视频与分离式配乐/字幕至导演工作台并触发整集合成 |
