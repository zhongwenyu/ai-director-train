# Stage 1：戏剧段落分镜与声画节奏规划指南

将输入的 `8.5s–12.5s` 戏剧段落拆分为 `3` 到 `6` 个（仅全段连贯大幅位移时可 `2` 个）连续子镜头（`clips`），消除长镜停滞与跳切断层：

1. **紧凑正反打与倾听反应切镜（破除站桩长镜）**：
   - 每个子镜头 `duration_s` 为整数秒（`2` 到 `8` 秒，常规切镜以 `2`–`3` 秒为主导），所有子镜头时长之和严格紧贴 `target_duration_s`。
   - 凡单段对话超过 `3.5s`、含多句交锋或长句语义转折时，必须按气口拆分为 `2s–3s` 正反打过肩/近景切镜，或在关键锋芒台词后穿插 `2s` 无声倾听反应近景镜（此时 `speaking_role_ids` 为空），严禁单一机位原地站桩硬撑到底。

2. **L-Cut 声桥交叠与时长气口精算**：
   - `lcut_audio_hold_over_next_s` 默认填 `0.0`；当本镜台词切向下一镜的 `2s` 无声倾听反应镜，或切向听话人先反应后开口的承接镜时，优先设为 `0.3`–`0.8`，使尾音自然延入下镜起幅表情形成声画交叠。
   - 按自然紧凑语速（约每秒 3.5–4.5 字，含句间换气微顿）并预留 `0.3s–0.5s` 收尾余韵核定 `duration_s`，严禁台词超载造成尾字硬截断，亦严禁短句配长镜导致首尾呆滞注水。

3. **戏剧动作属性决定景别与机位规划**：
   - **言语点睛与心理暗涌收紧**：犀利交锋、潜台词试探、无声倾听反应与内心顿悟，规划为 `MCU`、`CU` 或紧凑 `OTS`，聚焦眼神层次。
   - **肢体位移与时空转场放宽**：凡涉及角色跨空间走动离开、拉拽转身、鞠躬逃离、起身离席等大幅肢体动作，或时空意境空镜转场，必须规划为 `MS` 或 `WS`（位移时配平滑跟摇），完整交代肢体动势与空间关系，严禁机械套用近景/特写吞没肢体调度。
   - **防跳切与动作顺接**：相邻镜头切换须具备明确机位角度变化（越过 30° 夹角或正反打切换）或跨级景别反差，杜绝同轴线近似景别跳切；切点对齐动作发力点或呼吸气口，保持跨镜姿态连续。

4. **出镜、发声与内心独白（`inner_os`）严格分离**：
   - 准确标注本镜画面实际可见的角色 ID（`visible_role_ids`，含过肩前景出镜角色）及画内张口说台词的角色 ID（`speaking_role_ids`）。
   - 若台词为内心独白或画外音（`mode == "inner_os"`），**严禁**放入 `speaking_role_ids`，必须填入该镜头的 `inner_os: {"speaker_id": "...", "text": "...", "start_s": 0.2, "mode": "inner_os"}`，画内角色按无声潜台词微表情（或全段唯一极点缓推凝视）处理。
