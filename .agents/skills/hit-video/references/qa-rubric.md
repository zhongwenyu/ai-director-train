# hit-video 多模态审片质检与迭代细则（7 维诊断表）

每条 `Pika-H3-Flex` 生成视频完成后，先运行 `scripts/inspect_video.py` 提取高密度秒点采样拼板（`contact_sheet.jpg`）与音轨参数，再对原 MP4 视频及拼板做完整多模态观看与听音核验。以下任一核心项不合格，必须先定位根因、修订提示词或占位关键帧并升级技能规则，再重抽该镜头。

---

## 一、七大审片维度（Pass Gate）

| 维度 | 核验内容 | 一票否决 / 必返工情形 |
|---|---|---|
| **1. 剧情与动作完整性** | 导演稿每个子镜 `[Shot k]` 的核心推进动作是否按时序做全、因果是否清晰可读 | 漏做关键动作（如没倒奶油、没拍钥匙、没扣包起身）、动作顺序颠倒、多出违背剧情的人物或举动 |
| **2. 运镜与切镜准确性** | 推/拉/摇/移方向与幅度是否符合分镜设计，组内硬切点 `[Shot k]` 是否干净切换且不越 180° 轴 | 切镜变成诡异变形融化转场、正反打左右越轴导致两人视线同向、无故剧烈晃动或慢动作漂浮 |
| **3. 人物五官与服装还原度** | 出镜角色五官身份与全套服装是否与输入的 `≤1K` 角色参考图 100% 一致，跨切镜是否保持同一套衣服 | 衣服颜色/款式漂移（如西装变厨师服、T恤变衬衫）、切镜后换脸或串衣服、把五格拼图白边/多格带入画面 |
| **4. 音色、台词与口型同步** | 说话角色声线是否贴合挂载的 `reference_audio`（`<Audio N>`），`<d>` 台词是否逐字清晰完整，口型是否给对说话人 | 台词尾字被截断、串嘴（A 的台词由 B 张嘴说）、画外音/OS 期间画面人物跟着动嘴念心声、出现刺耳电音杂音 |
| **5. 场景与关键道具连续性** | 空间布局、光源冷暖、桌面高度与关键道具（铭牌、汤锅、车钥匙、线装书、催缴单）形态数量是否稳定 | 道具凭空消失/翻倍融化、坐姿人物被桌面淹到胸口、室内外光影跳变 |
| **6. 解剖结构与物理真实感** | 四肢手部结构是否正常，拿放推拉是否有真实重量感与正常生活速度 | 主体人物脸崩、多手多腿、身体粘连穿模持续 >0.5 秒、全片像水下慢动作平移 |
| **7. 短剧观感与观众吸引力** | 画面是否明亮通透有电影质感，冲突拍情绪（震惊、讥讽、冷漠切割、重逢惊喜、悬念定格）是否抓人 | 画面灰暗糊闷、演员面瘫像木偶站桩念白、集尾钩子平淡缺乏追更冲动 |

## 二、常见缺陷根因 → 技能与提示词修复映射（Self-Improving Loop）

1. **切镜后人物服装或站位左右互换**
   - **根因**：`[Shot 2]` / `[Shot 3]` 只写了 `<Subject N>` 名字，漏重写画面左右位置与场景刚体锚点，或首镜为特写导致多人镜缺少构图锚。
   - **修复**：若多人同框出现在 `[Shot 2]`，为 `[Shot 2]` 单独生成并绑定占位关键帧（`<Picture 1> is the composition keyframe for [Shot 2]`）；每个 `[Shot k]` 首句强制重写 `on screen-left / on screen-right` + 场景锚点 + `from the same side of the 180-degree axis`。
2. **台词说不完被视频结尾截断，或语速拖沓像慢动作**
   - **根因**：单句字数与子镜窗口比超过 `5.5 字/秒`，或提示词混入 `slowly`、`calmly`、`gently`、`softly`。
   - **修复**：删净一切慢速副词，给 `<d>` 显式标注起止秒窗（留出尾端至少 `0.3s` 余量）并写明 `at a brisk, energetic conversational pace`。
3. **多人同框时听话人跟着张嘴或台词串嘴**
   - **根因**：说话句未指明说话人的画面方位，或未写清听话人的闭口反应。
   - **修复**：每条 `<d>` 句式固定为 `<Subject A> (Sx), on screen-left, speaks briskly: <d>[Chinese] ...</d> His lips move clearly with the line while <Subject B> on screen-right listens with lips completely closed.`
4. **动作漏做或手物粘连崩坏**
   - **根因**：同一 2 秒内塞入两个以上精细手部动作，或用结果态代替动作过程。
   - **修复**：拆为“单一接触点 + 起止秒数”（如 `at 0.2-1.0s slams palm onto tabletop`），简化过碎手指微操为清晰可读的中近景肢体动作。
